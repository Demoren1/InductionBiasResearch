# Правила работы в этом репозитории

- Не создавать новые тесты, если пользователь явно не попросил их добавить.
- Не выполнять лишние или повторные проверки результата. Ограничиваться минимальной проверкой, необходимой для конкретного изменения.
- Повторять проверку только при обнаруженной ошибке, существенном изменении после предыдущей проверки или по явному запросу пользователя.

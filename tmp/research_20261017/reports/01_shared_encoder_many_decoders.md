# Один encoder и несколько decoder

17 октября 2026. Тот же банк 1536 MLP, split 96/16/16 на задачу; три инициализации 4213/4214/4215. Все новые файлы находятся в tmp. Никакой пересборки банка.

## Сравнение

| Модель | Параметров | IoU bank-test, mean ± SD |
|---|---|---|
| 12E / 1D | 10,311,328 | 0.9316 ± 0.0094 |
| 1E / 12D | 1,918,240 | 0.8979 ± 0.0020 |
| 1E / 1D | 940,736 | 0.7382 ± 0.3413 |

IoU сравнивает выход с ближайшей аналитической маской, а не с индивидуальной IMP-маской учителя. Bank-test — новые seeds учителей **в source-задачах**, не четыре отложенные задачи. Ширины NF 8/encoder 64/z16/decoder 128 одинаковы, число параметров различается; это не сравнение при равном бюджете параметров. Checkpoint выбирался по source-validation IoU, максимум 100 эпох, patience 20. Исходный seed 4213 использует сохранённый checkpoint, остальные модели обучены заново.

**Главная диагностика:** у обратной модели IoU почти не меняется при замене posterior на код другой семьи. Приватный decoder сам задаёт семью структуры. Это не доказательство общей семантики latent space. NF действительно инвариантен к перестановке колонок: максимальная ошибка mu 4.8e-07.

Общая модель имеет неудачный seed 4214: ранняя остановка после 31 эпох. Отдельный source-only контроль до 100 эпох без ранней остановки восстановился до IoU **0.9406**, лучший checkpoint71. Он не подменяет основной результат и не имеет отдельной итоговой оценки переноса.

## Перенос

Для новой задачи нет своего обученного decoder. Основной протокол: выбрать ветвь среди 12 по source-validation на z=0, затем 80 шагов Gumbel-поиска z и оценка двух held-out задач каждой семьи с тремя свежими MLP. Полный meta-search выполнен для фиксированного seed 4213; другие seeds имеют prior-контроли, а не повторения meta-search.

| Модель | IoU A / B | Test BCE A / B |
|---|---|---|
| 12E / 1D | 0.9394 / 1.0000 | 0.55952 / 0.54540 |
| 1E / 12D | 0.8824 / 1.0000 | 0.56554 / 0.54540 |
| 1E / 1D | 0.9394 / 1.0000 | 0.55964 / 0.54540 |

Чувствительность routing: дополнительный контроль выбирает ветвь и случайный старт по source-validation среди 12×8=96 предложений, **без градиентного поиска**:

| Seed | IoU A / B | Test BCE A / B |
|---|---|---|
| 4213 | 1.0000 / 1.0000 | 0.54858 / 0.54540 |
| 4214 | 0.9394 / 1.0000 | 0.55995 / 0.54540 |
| 4215 | 1.0000 / 1.0000 | 0.54858 / 0.54540 |

Это исследовательская проверка недостатка zero-routing с большим бюджетом кандидатов, не честное превосходство над 8 стартами исходной модели. Решения принимались по source-данным; повторное использование тех же held-out задач не является новой независимой репликацией.

**Вывод:** общий encoder уменьшает модель, но приватные decoder несут существенную часть prior. Результат зависит от выбора ветви и остановки. Оснований заменить основную архитектуру только по этому опыту нет. Не проверялось amortized применение encoder к картам новых задач: перенос здесь использует decoder и поиск z, без новых банков held-out учителей.

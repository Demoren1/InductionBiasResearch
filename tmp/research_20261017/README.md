## Воспроизведение

Из корня репозитория или другого каталога:

```bash
./tmp/research_20261017/run.sh
./tmp/research_20261017/run.sh reports
DEVICE=cpu ./tmp/research_20261017/run.sh probes
```

MPS выбран по умолчанию, Python — из текущего окружения. Нужны готовые банки и checkpoint в путях исходного проекта. Они не собираются автоматически. Веса сначала читаются с `map_location="cpu"`, затем переносятся на выбранное устройство: это предотвращает попытку восстановления MPS-тензоров при ограниченном CPU-запуске.

`experiment.py` — модели, обучение, перенос; `pattern_probe.py` — контроль начального z и выравнивания; `latent_probe.py` — зависимость decoder от encoder; `report.py` — графики/CSV и численные сводки. Текст отчётов — отдельно проверенный датированный снимок; генератор графиков его не переписывает. Протоколы, веса, истории и результаты — в `runs/`; они исключены из Git. Численные результаты прежних ассетов перенесены в [RESULTS.md](reports/RESULTS.md); PNG/SVG и дублирующие CSV/JSON удалены 20 октября 2026.

Три фиксированных seed инициализации: 4213/4214/4215. Градиентный meta-search новых моделей выполнен для заранее выбранного seed4213, остальные — контроль prior. Исходный seed4213 и его meta-оценка переиспользуют сохранённый baseline от13 октября; остальные модели обучены заново. Это явно отмечено в отчётах, а не выдаётся за15 новых независимых полных экспериментов.

Существующие завершённые результаты повторно не считаются. Для новых настроек обучения нужен новый suffix/каталог, чтобы не затереть этот снимок. Не выдавать запуск с изменёнными настройками за воспроизведение исходных отчётов. У baseline/новых моделей разные размеры параметров; известный family condition cVAE — дополнительная информация; reverse-routing имеет дополнительный бюджет выбора ветви. Все настройки выбирались по source-данным, не по меткам четырёх held-out задач.

## AGOP

Дополнительное сравнение — `./tmp/research_20261017/run.sh agop` (MPS по умолчанию).
`agop.py` вычисляет AGOP логита на старых unlabeled probe без обучения MLP.
Основная архитектура: NF от W/G и отдельная MLP от полного AGOP; конкатенация
перед posterior VAE. Два контроля той же архитектуры/числа параметров получают
функциональную карту или нули вместо AGOP. Проверяются Multimask и Pattern.

Первоначальный срез 17 октября: три seeds обучения, полный Gumbel-перенос
только seed4213. Дополнение 18 октября включает полный поиск для4214/4215
на тех же весах и с прежними настройками. Старые prior-контроли сохранены
отдельно. Для запуска только переноса: `agop.py transfer --optimize --seeds 4214 4215`.
По дополнительной просьбе пользователя также проверяется evolution для всех
трёх seeds: `agop.py transfer --optimize --z-method evolution`.
Методы сохраняются в разных каталогах `transfer_gumbel/transfer_evolution`.
Оба используют8 стартов и80 шагов; evolution проверяет4 кандидата на шаг
с радиусом0.3, Gumbel — два relaxed samples и три масштаба Adam-направления.
Это одинаковый бюджет итераций, а не одинаковый FLOP-бюджет. Wall time
справочный: независимые оценки выполняются параллельно на одном MPS.
Предварительные проекции AGOP в третий
NF-канал сохранены отдельно и не подменяют основной эксперимент.
Кэши производных данных, новые веса и сырые результаты находятся в `agop/`,
исключённом из Git. Численные результаты — [RESULTS.md](reports/RESULTS.md), отчёт —
[AGOP](reports/05_agop.md). Генераторы `report.py` и `agop_report.py` при явном запуске сохраняют временные графики/CSV/JSON в игнорируемый `.cache/report_assets/` и не переписывают датированные Markdown-снимки.

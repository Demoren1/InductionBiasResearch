# Latent-adapter между независимо обученными pattern-VAE

Независимых VAE-пар: **32**. Для каждой пары обучены оба направления. Единица статистического повторения — VAE-пара; два направления сначала усреднены внутри пары.

Decoder заморожены. Adapter обучался только по agreement мягких exact-32 масок с per-example Hungarian; Gold и task labels не участвовали в обучении, validation или выборе checkpoint.

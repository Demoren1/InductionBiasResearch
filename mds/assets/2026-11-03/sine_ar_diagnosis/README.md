# Диагностика банка и температуры AR

[Отчёт](../../../SINE_AR_FILTER_DIAGNOSIS_2026-11-03.md).
Рисунки SVG и PNG построены из завершённых измерений в
`experiments/sine_ar_current_v1/results/diagnosis_20261103/`.

| Рисунок | Данные |
| --- | --- |
| `bank_threshold` | Все сохранённые случайные source-попытки и их эмпирические ошибки |
| `temperature` | Точные вероятности по всем 65536 бинарным маскам, среднее трёх MADE |
| `pair_probabilities` | Частоты 16 полных пар в банке и безусловные вероятности AR |
| `calibration` | Средняя query MSE решателя при выборе порога и температуры |
| `fresh_functions` | Новые функции 12031/12032, 384 поиска на метод и условие |

Графики полных пар не учитывают успех более широких масок; график
решателя оценивает его независимо по окончательной population MSE.
Отложенные пары определены относительно исходных задач. При мягком
фильтре их маски могут уже встречаться в обучающем банке.

Пересборка из корня репозитория, без обучения моделей:

```bash
MPLCONFIGDIR=/tmp/induction-mpl python -m experiments.sine_ar_current_v1.diagnosis_report
```

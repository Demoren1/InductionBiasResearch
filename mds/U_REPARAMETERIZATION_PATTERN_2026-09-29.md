# Бинарная U на pattern длины 11: итог проверки

Дата: 2026-09-29. Генеративная модель не обучалась; MNIST8m не запускали.

Отдельная проверка переноса общей U с 12 паттернов на 4 новых: [результаты 12/4](U_HOLDOUT_12_4_PATTERN_2026-09-29.md).

## Постановка

Все 16 паттернов длины 4 обучались совместно. Вход имеет длину 11, скрытый слой — 8 нейронов, поэтому первая матрица весов `W` имеет форму `11×8`. Идеальное решение — четыре диагональные полосы прямоугольной теплицевой матрицы, то есть 32 активные связи из 88. Во всех основных разреженных опытах бюджет равен **ровно 32 связям суммарно**. Ограничения на число связей отдельного нейрона нет.

Параметризация `vec(W_t)=U v_t` общая для 16 задач. Для прямой бинарной `U` каждый из 88 элементов назначается одному из пяти кодов: нулевой код означает отсутствие связи, остальные четыре делят обучаемые значения `v_t` между связями. Это дает `U` размера `88×5`; `v_t` обучается отдельно для каждой задачи. Для оценки правильной структуры скрытые столбцы переставляются по максимальному перекрытию с эталоном **после обучения**; эталон не участвует в выборе контрольной точки или обучении.

Обучаемая функция потерь — `binary_cross_entropy_with_logits` предсказаний паттерна, оптимизатор Adam с `lr=1e-3`, 5000 шагов, батч 128 на задачу. Дискретное назначение `U` получает straight-through градиент. Validation BCE выбирает лучшую контрольную точку; test BCE и accuracy служат проверкой обучаемости, а не критерием выбора представления.

## Теплицевость

Главный показатель ниже — доля энергии `W`, объяснённая проекцией на пространство четырёх теплицевых диагоналей. Перед проекцией каждый скрытый столбец нормирован по длине, чтобы допустимое масштабирование нейрона не портило сравнение. `1` означает точную теплицеву структуру. IoU сравнивает только расположение 32 ненулевых связей; group F1 проверяет, насколько верно связи с одинаковым сдвигом получили общий код. Поэтому высокий IoU сам по себе не означает правильную `U` или `W`.

| Представление | Запусков | Средняя энергия теплицевой `W` | Средний IoU связей | Средний group F1 |
|---|---:|---:|---:|---:|
| Аналитическая бинарная `U`, контроль | 1 | 1,000 | 1,000 | 1,000 |
| Прямая бинарная `U`, 4 ненулевых кода | 33 | 0,284 | 0,566 | 0,222 |
| Общий балл связи по сдвигу `i−j`, прямые коды `U` | 33 | 0,289 | 0,549 | 0,268 |
| Свободные баллы связей, прямые коды | 3 | 0,273 | 0,588 | 0,214 |
| Бинарная факторизация Кронекера с отдельным gate | 3 | 0,098 | 0,549 | 0,000 |
| Прямая бинарная `U`, 40 ненулевых кодов | 3 | 0,142 | 0,614 | 0,047 |
| Случайная бинарная `U`, 4 ненулевых кода | 3 | 0,245 | 0,444 | 0,260 |
| Внешнее произведение баллов связей | 3 | 0,129 | 0,393 | 0,127 |
| Ранг 3 для баллов связей | 3 | 0,180 | 0,393 | 0,148 |

Матрица с баллом по `i−j` в двух из 33 запусков дала **точную геометрию связей** (IoU 1,000), но доля теплицевой энергии `W` для них составила только **0,442 и 0,556**. Значит, задача не сводится к правильной маске: важно также выучить совместное использование четырёх коэффициентов. Среднее преимущество одного из двух лучших вариантов по энергии `W` мало относительно разброса между запусками; уверенного победителя нет. Простая факторизация Кронекера в испытанной конфигурации дала худшую теплицевость `W`.

Разброс IoU у прямой `U`: 0,455–0,730; у варианта со сдвигом: 0,333–1,000. У прямой `U` средний test BCE равен 0,510 и test accuracy 0,736; у варианта со сдвигом — 0,525 и 0,725. Точная аналитическая `U` достигает единицы по структурным метрикам, то есть емкости архитектуры достаточно. Оставшийся разрыв свидетельствует прежде всего о трудности поиска структуры через ошибку классификации; это вывод по данным этих запусков, а не доказательство единственной причины.

## Стабильность BCE

Во всех 66 основных запусках двух вариантов значения лучшего validation BCE и test BCE конечны. Для прямой `U` validation BCE лежит в диапазоне 0,477–0,531, для варианта со сдвигом — 0,486–0,559. Дополнительно повторены полные 5000 шагов seed 42 с проверкой BCE и нормы градиента на каждом шаге:

| Вариант | Диапазон train BCE | Максимальная норма градиента | Нечисловых шагов |
|---|---:|---:|---:|
| Прямая `U` | 0,474–0,694 | 0,064 | 0 |
| Балл по сдвигу | 0,508–0,693 | 0,074 | 0 |

В обоих повторах получились те же итоговые BCE, что и в исходном seed 42. Эти данные не показывают взрывов градиента. Пошаговый аудит проведён для двух запусков, поэтому он не доказывает отсутствие кратких скачков во всех остальных 64.

## Что сохранять для будущей генеративной модели

Сохраняем **полную бинарную `U` размера `88×5`**, а также эквивалентный компактный массив из 88 категориальных кодов `0…4`. Это представление не теряет распределение кодов по связям. Выравнивание скрытых столбцов выполняется по центру их ненулевой поддержки; перестановка четырёх ненулевых кодов — по среднему сдвигу `i−j`. Эти операции не используют эталонную теплицеву матрицу и сопровождаются согласованной перестановкой `v_t` и параметров скрытого слоя. Для каждой записи проверено точное восстановление исходной `W`.

Подготовлены два набора: [33 прямых `U`](../pattern/outputs/u_reparameterization_length11/canonical_dataset/records.pt) и [66 полных `U` из прямой модели и модели со сдвигом](../pattern/outputs/u_reparameterization_length11/canonical_dataset_direct_and_offset/records.pt), с метками способа получения. Среди 66 записей 65 разных масок. Средняя попарная IoU выровненных масок равна 0,339: неоднозначность и разброс значительны. Глобальное голосование по частотам связей среди 66 `U` даёт IoU 0,778 с эталоном; это диагностическая сводка, **не** новая обученная `U` и не результат генеративной модели. Две модели со сдвигом, имеющие идеальную геометрию маски, входят в набор.

Для будущего перехода к MNIST8m бюджет 5% у матрицы `784×64` означает 2509 активных связей из 50176 при округлении до ближайшего целого, без квоты на нейрон. Пока сохраняем полную категориальную `U` на pattern и не обучаем VAE, flow matching или диффузию. По нынешним данным сначала нужно улучшить восстановление **значений и общего кодирования диагоналей**, а не только их положения.

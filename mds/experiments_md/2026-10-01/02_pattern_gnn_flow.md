# Pattern: короткая проверка GNN и GNN + flow matching

**Графовая модель научилась предлагать почти правильные окна, но преимущества над функциональным средним не показала.** Проверены два прежних банка по 960 решений, 128 support-примеров и фиксированные 32 связи из 88. Матрица $U$ не используется.

| Метод | Test balanced BCE, меньше лучше | Выбор маски по query новой задачи |
|---|---:|---|
| Функциональное среднее | **0,5143** | Нет |
| GNN: одно предложение | 0,5229 | Нет |
| GNN + flow: один сэмпл | 0,5377 | Нет |
| GNN: поиск среди 8 | 0,5255 | Да |
| GNN + flow: поиск среди 8 | 0,5260 | Да |
| Функциональные scores: поиск среди 8 | 0,5274 | Да |
| Dense: общий режим | 0,7043 | Нет |

GNN получает функциональные признаки банка и статистики support-данных. Столбцы банка явно выровнены по центру функциональной sensitivity; это пространственный prior. Полные признаки сначала агрегируются в mean/std по 960 решениям, поэтому опыт проверяет графовый decoder с этим представлением, а не обучаемый encoder всех отдельных решений. Канал учительского качества исключён из входа. Сам исходный банк ранее отбирался по source-query качеству.

Обучающие маски выбираются по **реальному качеству после обучения с новых весов** на исходных задачах. На каждую задачу сохранены 28 оценённых предложений; четыре различных лучших маски образуют общий взвешенный набор для GNN и flow. GNN обучается через BCE масок, flow — через MSE поля скорости от независимого Gaussian noise к бинарным маскам. Градиент через top-K отсутствует. Это distillation найденных полезных ограничений; превосходство над лучшими решениями банка не обеспечивается самим objective.

Архитектурный ориентир — [Permutation-Equivariant Flow Matching for Alignment-Free Neural Weight Generation](https://arxiv.org/html/2609.32833v1): GNN параметризует поле скорости и учитывает перестановки скрытых нейронов. В той работе генерируются веса; здесь генерируются scores связей по utility-отобранным маскам, с явным функциональным выравниванием банка. Это адаптация идеи, а не воспроизведение экспериментов статьи.

У всех кандидатов и итоговых сетей одинаковые 1400 обновлений Adam и терминальные веса; query не выбирает checkpoint или число шагов. В поиске среди восьми масок query выбирает предложение по двум инициализациям, после чего качество измеряется на четырёх других инициализациях. Test-входы не участвуют в отборе.

Восемь означает число предложений, а не гарантированно различных масок: в test-пулах GNN было 3–8 различных масок, flow — 4–8. В одном meta-validation пуле flow все восемь сэмплов дали одинаковую маску. Дубликаты сохранены и учтены в аудите; бюджет различных кандидатов не выровнен.

Основное обучение заняло около **2–2,2 минуты на банк**, итоговая проверка — около **20 секунд**. Все **2032/2032** основных дочерних обучений и **4/4** финальных графовых моделей прошли заданный критерий эмпирического плато. Начальные flow-этапы достигли лимита 600 шагов; потребовались короткие продолжения, сохранённые отдельно. Плато не доказывает стационарность или оптимальность.

После первого основного сравнения отдельно проверена настройка dense на 12 комбинациях LR/L2 по двум meta-validation задачам. Она выбрала прежние параметры. Dense с дополнительным query-выбором checkpoint дал BCE 0,6932; это отдельный query-aided контроль. У 17 из 192 невыбранных комбинаций не достигнуто плато в коротком бюджете; 32/32 выбранных итоговых dense-обучений прошли критерий. Этот контроль не устанавливает максимально возможное качество dense.

**Ограничения.** Прежний test-split уже изучался; четыре паттерна относятся к одной reversal/complement-орбите. Meta-validation содержит только 0000 и 1111. Эти результаты исследовательские; абсолютные числа нельзя напрямую сопоставлять с прежними протоколами обучения. Графовый prior, алгоритм выравнивания и обучение по найденным utility-labels пока не отделены друг от друга контрольными опытами.

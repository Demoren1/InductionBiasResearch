# Теория для текущей статьи

Справочные материалы к постановке в
[Preliminary](../../paper/sections/preliminary.tex) и теоретическому вкладу,
заявленному в [Introduction](../../paper/sections/introduction.tex).
[Рабочие отчёты и последние экспериментальные ограничения](../README.md).

Эти документы остаются актуальной теоретической основой. Их перенос
в отдельную папку не меняет утверждений и доказательств. Результаты
для специальных семейств и оптимизаторов не дают общей гарантии для MLP.

В текущем методе индексатор фиксирован на протяжении каждой попытки.
Разделы о split/merge, мягком остатке и изменении числа групп сохранены
как математические расширения; соответствующие экспериментальные варианты
перенесены в [архив](../../archive/2026-11-03/README.md).
Оценки подавления шума сами по себе не объясняют преимущество перед любым
оптимизатором: [контроль с одинаковым SGD](../BASIN_RELEASE_CONTROL_2026-11-03.md)
такого преимущества не показал.

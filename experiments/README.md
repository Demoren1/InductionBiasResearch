# Код экспериментов

| Каталог | Назначение |
|---|---|
| `paper_compact_v1/` | Синтетика, Omniglot и HAR для статьи, включая `evidence.py` для пересчёта опубликованных метрик |
| `omniglot64_v1/` | Широкий Omniglot, кластеризация профилей, сравнение с WSR, LUT-Q и Yeh |
| `srr_approx_v1/`, `srr_cluster_v1/` | Построение групп по профилям и синтетические контроли |
| `paper_asrr_v1/`, `asrr_tuning_v1/` | Извлечение исходных профилей, подготовка банков и численная адаптация |
| `wsr_omniglot_v1/` | Построение и перенос групп WSR |
| `real_group_transfer_v1/` | FC100, NinaPro, траектории и повторные измерения датчиков |
| `asrr_benchmark_families_v1/` | Сдвиг задач, WISDM, Aug-Omniglot и предложения групп по градиентам |
| `paper_transfer_v2/` | Зарегистрированный протокол отдельной серии сравнения переноса |

Основные запуски выполняются из корня репозитория. Для обучения нужны
зависимости из `requirements.txt` и совместимый CUDA-рантайм. Файлы
`protocol.json`, `registration.json` и планы в
[артефактах](../artifacts/README.md) описывают точные бюджеты и разбиения.
Например, отчёт по [FC100](../paper/theory/ASRR_COMPENSATED_MERGING_FC100_2026-11-19.md)
содержит команды построения групп и оценки переноса.

Исторические ядра, аудиторы и общие компоненты остаются в
`sharing_structure_research_v1/` и `paper_structure_benchmark_v1/`.
Ранние исследовательские протоколы описывают исходные прогоны.
Многие промежуточные данные нужно сгенерировать заново, а некоторые
закрытые исследовательские скрипты убраны из рабочего дерева.
См. [журналы очистки](../archive/README.md).

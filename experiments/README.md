# Рабочий код

- [paper_structure_benchmark_v1](paper_structure_benchmark_v1/README.md) —
  основной стенд: данные, G34 и конкуренты, свежая численная адаптация,
  измерения, отчёты и аудит компактных комплектов.
- [sharing_structure_research_v1](sharing_structure_research_v1/README.md) —
  зарегистрированное ядро G34. Исходные модули сохранены без изменений.
- [theorem_pair_recovery_v1](theorem_pair_recovery_v1/README.md) —
  группировка по сигнатурам, взвешенная SVD и проверка условий теоремы.
- [omniglot_signature_v1](omniglot_signature_v1/README.md) —
  первый геометрический кандидат на Omniglot, Dense/G34 и диагностика.
- [general_signature_v1](general_signature_v1/README.md) —
  перенос на новые численные задачи local/quartet_mix/random.

В основном пакете `protocol/` отвечает за данные, `methods/` — за
структуры, `fitting/` — за численные параметры, `execution/` — за
запуск, `reporting/` — за метрики и аудит. Генератор общей синтетики
находится в `protocol/prepare_general.py`, независимо от старых опытов.

Прежние экспериментальные ветки и их сырые результаты удалены из рабочего
дерева. Они доступны в истории Git; состав удаления записан в
[журнале](../archive/2026-11-12/README.md). Снимки кода внутри результатов
сохраняют фактически использованные версии и не являются текущими entry points.

Большие наблюдения и промежуточные состояния создаются для нового запуска.
Сохранённые [компактные результаты](../artifacts/README.md) позволяют
проверять опубликованные метрики без обучения.

# Рабочие эксперименты

Текущая серия — [paper_structure_benchmark_v1](paper_structure_benchmark_v1/README.md):
перенос фиксированной структуры на новые численные задачи, сравнение с
Yeh Aφ, MSR, LUT-Q и Dense на четырёх наборах.

- `protocol/`: генерация наблюдений, разграничение выборок, экспорт структуры.
- `methods/`: извлечение структуры и реализации конкурентов.
- `fitting/`: обучение кодбука, сдвигов и свободного выходного слоя.
- `execution/`: очередь запусков и наблюдение за готовностью экспорта.
- `reporting/`: аудит, таблицы, графики и экспорт компактного комплекта.

Рядом оставлено [исходное ядро G34](sharing_structure_research_v1/README.md).
Его файлы участвуют в проверке зарегистрированных контрольных сумм и
сохранены с прежними именами и содержимым.

[Прежние экспериментальные ветки](../archive/experiments) перенесены в
архив. Их неполные сырьевые наборы и старые большие чекпойнты не входят в
рабочий комплект. Исторические команды описывают прежнее расположение
файлов; для текущего кода используйте квалифицированные модули из README.

Новые исследования создают отдельный каталог результатов. Замороженные
протоколы и предсказания завершённой серии не перезаписываются.

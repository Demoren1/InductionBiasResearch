## Данные и воспроизводимость

Команды запуска, зависимости и правила выбора кандидатов приведены
в README каждого опыта. Для новых запусков нужно использовать отдельный
каталог результатов и протокол; опубликованные измерения не перезаписываются.
Обучение обычно требует CUDA, а скрипты отчётов читают сохранённые данные
без повторного обучения. Окружение выполненных запусков записано в их
артефактах.

В Git сохранены протоколы, снимки исполнявшегося кода, настройки,
контрольные точки, измерения и истории, необходимые для аудита результатов
и пересборки рисунков. Поэтому репозиторий содержит крупные бинарные файлы.
Сгенерированные результаты отмечены в `.gitattributes`, чтобы отделить их
от исходников при просмотре изменений. Локальные кэши и журналы исключены
из Git; старые неполные наборы данных явно обозначены в архиве.

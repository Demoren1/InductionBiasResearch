# Адаптивные индексаторы для tanh

Пилот проверяет, помогают ли разбиения по конфликту градиентов при неточных
равенствах весов. Точный протокол находится в `protocol.json`: два банка для
калибровки, три новых банка для оценки, четыре силы нарушения равенств.
Исходные индексаторы извлекаются из обученных плотных сетей, без teacher I.

```bash
CUDA_VISIBLE_DEVICES=7 python -u -m experiments.adaptive_tanh_v1.run
MPLCONFIGDIR=/tmp/induction-mpl python -m experiments.adaptive_tanh_v1.report
```

Нужны CUDA, PyTorch, NumPy, SciPy и Matplotlib. Обучение и k-means работают
на GPU; CPU используется для Hungarian alignment и построения отчёта.
Запуск не перезаписывает существующую папку результатов. Для нового опыта
передайте `--protocol` с новым `output` и seed.

Градиентный и случайный split имеют одинаковые размеры всех групп на каждом
шаге. Проверка при конечном K=96 отделена от выбора checkpoint по validation,
который может вернуть более простую модель. Вторая проверка важна, когда
равенства точны и новые параметры могут вредить.

В исходной сбалансированной структуре raw и normalized SGDM эквивалентны
при пересчёте learning rate в 16 раз. Отличие появляется при неодинаковых
размерах извлечённых групп или после split. Поэтому сам по себе этот контроль
не должен интерпретироваться как обещание улучшения от нормировки.

Split использует эмпирический полный градиент на 128 support примерах.
Здесь нет независимого подтверждения направления или известных констант
концентрации: гарантия безопасного шага из теории не заявляется.
1024 validation labels используются для выбора; итоговые 8192 примера
не участвуют в обучении, настройке rates или выборе checkpoint.

Артефакты содержат протокол, снимки кода, хеши заморозки, исходные сети,
извлечённые структуры, целевые данные, модели, решения split, кривые,
таблицы и графики. Source/calibration cost приводится отдельно.

Завершённый пилот описан в
[отчёте](../../archive/2026-11-03/mds/ADAPTIVE_TANH_PILOT_2026-11-02.md). При неточных равенствах
градиентные разбиения улучшили результат относительно случайных; при точных
равенствах ухудшили качество. Правило безопасного отказа от split ещё не
проверялось. Raw и normalized SGDM в исходной сбалансированной структуре
дали ожидаемо эквивалентные результаты после пересчёта learning rate.

Первый запуск прервался во время калибровки из-за несовместимого вызова
`argsort`. Одновременно до заморозки исправлена нормировка остатка;
некорректные calibration fit исключены в `aborted_calibration/`, исходный
банк сохранён. `--resume-calibration` разрешает использовать готовые
source-банки до заморозки; калибровочные fit выполняются заново. Итоговый
опыт завершён с неизменным протоколом и новыми evaluation-банками.

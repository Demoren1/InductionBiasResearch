# MLP with a learned arbitrary weight-sharing indexator

The teacher is a32-input,16-ReLU-hidden-unit network with fixed zero biases and
fixed readout1/4. Its512 first-layer weights select32 continuous codebook values.
The shared unknown indexator distributes each codebook entry across16 arbitrary
weight positions. There are no input blocks or image geometry. The solver knows
the network shape and codebook budget32, but not assignment positions or counts.
All compared networks have the same fixed biases and readout.

Source functions use different permutations of32 equally spaced values in[-1,1].
Target functions use new continuous uniform[-1,1] values. A source network is an
ordinary unshared512-weight MLP fitted by Adam. The generic structure extractor
clusters its scalar weights into32 values, aligns hidden units using within-column
equality patterns and Hungarian matching, then aligns code labels by support.
It does not use input correlations, analytic task moments or the teacher indexator.
The same input-coordinate identities are shared across source/target functions.

```bash
python experiments/shared_codebook_mlp_v1/source.py --steps 8192 --version v2
python experiments/shared_codebook_mlp_v1/run.py --stage prior
python experiments/shared_codebook_mlp_v1/run.py --stage calibrate
python experiments/shared_codebook_mlp_v1/run.py --stage evaluate
```

Use a fresh output directory or archive the supplied artifacts before reproduction.
The exploratory v1 source run used4096steps and recovered511/512 assignments;
v2 uses8192steps and its saved source consensus recovers512/512 up equivalent
hidden-unit and code-label permutations. Teacher comparisons are post-freeze
only. Training sees8192 support and2048 query examples per source function.
Six functions x four starts yield24 source models; the best two per function form
a12-model bank. The prior stage trains on the best one per function and validates
on the second. Some source fits are partial; no near-perfect accuracy threshold
is imposed. Source numeric learning and structure extraction are separate steps.
Inferred indexators are approximations obtained by generic scalar quantization of
source weights; source NMSE evaluates the original numeric source fits.

The structure-only VAE encoder embeds discrete labels, with latent16 and a shared
categorical512x32 decoder. Its only training inputs are inferred indexators;
source query quality selects relatively good source examples. No source X/y,
numeric weights or teacher layout enter VAE training. Labels are aligned to the
best source reference, not to teacher truth. The decoder imposes neither equal
class occupancy nor a spatial arrangement. During target solving it is frozen;
32 numeric codebook entries are fitted anew, with optional optimization of z.

Two additional source-family calibration functions choose numeric learning rates.
All structural methods use the source-calibrated codebook rate. Eight independent
new target functions use128 support,1024 query and8192 test examples, eight starts
x4096 full-support steps. Targets share Gaussian input samples across functions;
function codebooks differ. The query set selects checkpoints and restarts. Test
NMSE divides MSE by support-label variance. Success is testNMSE<0.001, which is
weaker than numerical exactness. Best z, I, numeric values, step and all restart
metrics/histories are retained.

Controls include direct source consensus, retrieval of one source indexator,
untrained decoder, random assignments, permutation of entries of the inferred
consensus preserving its code-count histogram, fresh dense Adam/SGDM and dense
source initialization with unrestricted adaptation. Target budgets match steps,
starts and presented samples, not total pretraining compute or FLOPs.

This check demonstrates **transfer of weight sharing at small target sample size**.
Source tasks have more labels than target tasks, enabling dense source fitting.
It does not prove that gradient descent cannot solve the same teacher with enough
examples, nor that a new arrangement of learned parts has been synthesized.
Some individual source indexators are already correct, so retrieval can also
solve targets; this is included explicitly rather than attributed solely to VAE.

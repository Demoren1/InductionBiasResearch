# Адаптивное число общих коэффициентов

GPU-пилот переноса разбиения весов между задачами линейной регрессии.
Число групп извлекается из плотных исходных решений и выбирается на отдельных
исходных задачах. Истинная структура используется только для генерации и
диагностического ориентира. Подробности зафиксированы в `protocol.json`.

Обучение и кластеризация требуют CUDA. Использованы PyTorch 2.6.0+cu118,
float64 и одна свободная Tesla V100. Нужны также NumPy и Matplotlib.

```bash
CUDA_VISIBLE_DEVICES=7 python -u experiments/adaptive_indexators_v1/run.py
python experiments/adaptive_indexators_v1/report.py
```

Запуск отказывается перезаписывать существующую папку результатов.
Для отдельного повтора скопируйте протокол, задайте новый `output` и при
необходимости новый `seed`, затем передайте путь через `--protocol`.
Второй скрипт только агрегирует завершённые результаты и строит графики.

Артефакты: `results/metrics.csv`, `bank_summary.csv`, `summary.csv`,
`recovery.csv`, `selection.json`, `curves.json`, `timings.json`, а также
исходные веса, выбранные индексаторы, целевые коэффициенты и модели в NPZ.
Выбор для каждого банка сохраняется в `*_frozen.json` до создания target.
Хеши кода и протокола записываются в `environment.json`.

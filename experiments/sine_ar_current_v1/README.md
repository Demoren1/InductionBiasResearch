# Синусоидальная задача с текущим AR-генератором

Новый запуск 3 ноября 2026: случайный банк двухсвязных масок, текущий
`IndexMADE`, новые численные параметры и SGD. Это отдельный опыт;
исторические результаты NF/VAE не перезаписываются.

[Протокол](protocol.json) зафиксирован до запуска. Исходные маски равномерно
выбираются среди всех 120 вариантов двух из 16 связей; хорошие решения
отбираются только по эмпирической MSE на 4096 независимых примерах.
Учитель, правильные координаты и точная population MSE не участвуют
в выборе банка, настройки или целевого кандидата.

AR учится на 16 бинарных токенах активности. Каждая активная связь имеет
собственное численное значение: это частный случай индексатора без sharing.
Основной метод генерирует все токены свободно. Заранее объявленный контроль
`ar_budget2` ограничивает только общее число активных связей, не задавая их
положения или распределения между выходами. Частотный контроль — независимые
Bernoulli по позициям, без известного разбиения на роли.

Четыре полных сочетания оставлены для калибровки, ещё четыре — для проверки
новых сочетаний. Восемь остальных используются для сбора банка и отдельной
проверки новых функций знакомых структур. Итоговые функции создаются после
фиксации температуры и настроек плотных SGD/Adam.

На метод и условие — 384 поиска, 64 обучения по 1024 шага, batch 64.
У генераторов 32 разведочные попытки с четырьмя начальными векторами
и 32 свежих обучения выбранной по query маски; у dense и oracle — 64
независимых старта. Query общая между фазами. Выбираются только конечные
состояния кандидатов; промежуточные кривые служат диагностике.

Три генератора обучаются на одном банке. 384 поиска относятся к восьми
или 16 задачам, а не к 384 независимым задачам. Отдельно учитывается
262144 исходных обучения, калибровка и обучение MADE.

Из корня репозитория:

```bash
CUDA_VISIBLE_DEVICES=0 python -m experiments.sine_ar_current_v1.run
python -m experiments.sine_ar_current_v1.report
```

Каталог завершённого запуска не перезаписывается. Фазы `prepare`,
`calibrate`, `evaluate` можно запускать последовательно через `--phase`.
Для полностью нового опыта следует задать новый каталог OUTPUT и новые
seed в копии протокола. Используется CUDA; запуск сохраняет снимки кода,
протокол, исходные маски и ошибки всех попыток, веса элит, checkpoint MADE,
полные целевые результаты и истории обучения.

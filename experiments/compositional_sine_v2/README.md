# Перенос частей при большом числе сочетаний

Результаты: [краткий отчёт](../../mds/COMPOSITIONAL_SINE_PILOT_2026-10-28.md).

Пилот от 28 октября 2026. Протокол зафиксирован до получения результатов.

## Задача

У каждой из 20 частей два варианта входных весов. Вариант использует
восемь входов; эти группы скрыты общей перестановкой 160 координат.
Ответ — сумма синусоид выбранных частей:

$$
\begin{aligned}
x&\sim\mathcal N(0,I_{160}),\\
y_s(x)&=\frac1{\sqrt{20}}\sum_{j=1}^{20}
a_j\sin(\omega_j v_{j,s_j}^\top x),\qquad s_j\in\{0,1\},\\
a_j&\in[0.8,1.2],\qquad \omega_j\in[3.8,4.2].
\end{aligned}
$$

Каждый вектор части имеет восемь ненулевых элементов одинакового модуля;
их знаки задаются вариантами 11110000 и 11001100. Длина вектора равна 1.
Разные части используют непересекающиеся входы; два варианта одной части
ортогональны. Всего допустимо 2 в степени 20 полных структур — 1 048 576.

## Откуда берётся структура

Банк состоит из 40 элементарных низкочастотных задач — по одной на вариант
части. Каждая решается плотным SGD с четырёх стартов. Восстановитель
получает только обученные веса: три кластера значений дают минус, ноль
и плюс; совпадающие носители позволяют объединить варианты в пары.
Истинные векторы используются только учителем и для диагностики.
Границы групп и правильные индексы новой задачи восстановителю не даются.

Банк содержит все элементарные части, но не полные 20-компонентные
сочетания новых задач. Это перенос знакомых частей на новые сочетания.
Пилот не проверяет появление совершенно неизвестной элементарной части.

## Методы

Восстановленные части: по данным новой задачи сравнить два варианта
каждой части и сетку из 64 частот. Амплитуды подобрать линейным методом
наименьших квадратов; затем дважды уточнить частоты по остаткам.
Полные сочетания не перечисляются. Частоты учителя не передаются методу.

Случайные целые структуры: предложить 32 сочетания из восстановленных
частей, для каждого подобрать частоты и амплитуды, выбрать по отдельным
4096 примерам. Это контроль прежнего способа генерации предложений.

Неверные части: повторить структурный подбор после новой перестановки
восстановленных входных координат. Исходные численные веса: зафиксировать
все 40 низкочастотных исходных векторов и подобрать выходные коэффициенты.

Плотные SGD и Adam: обучить сеть из 40 синусоид со свободными входными
весами и амплитудами. Выбрать масштаб старта и шаг на двух отдельных
задачах. Дополнительно проверить Adam со стартом из всех исходных весов.
Во всех случаях цель представима плотной сетью.

## Оценка

Восемь новых сочетаний, по восемь стартов у градиентных методов,
1024 обновления по 64 примера. Итоговый старт выбирается по отдельной
выборке; средняя ошибка по нормальному распределению вычисляется точно:

$$
\begin{aligned}
K(u,v)&=\tfrac12\left(e^{-\|u-v\|^2/2}-e^{-\|u+v\|^2/2}\right),\\
R&=c^\top K(W,W)c-2c^\top K(W,W^*)a+a^\top K(W^*,W^*)a.
\end{aligned}
$$

Успех — MSE ниже 0,1. Сохраняются также восстановление дискретных индексов,
число примеров, число проверенных частот и время CPU. Число стартов
не приравнивает стоимость спектрального подбора и градиентного обучения:
это пилот, а не окончательное сравнение при одинаковых FLOPs.
VAE в первом пилоте не используется: сначала проверяем пользу извлечённых
частей при большом пространстве сочетаний.

Запуск из корня репозитория:

    OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 \
      python experiments/compositional_sine_v2/run.py

Результаты, параметры и рисунок сохраняются в results/pilot_v1 рядом
со скриптом. Новые тесты не создаются и не запускаются.

## Усиленная проверка на GPU

Отдельный протокол protocol_gpu_30.json зафиксирован перед запуском:
30 частей, 240 входов, 1 073 741 824 полных структуры, новый исходный банк
и новые задачи. У плотных методов 16 стартов по 4096 шагов.
На настройке выбираются также 30 или 60 скрытых синусоид;
шаг Adam со стартом из исходных весов подбирается отдельно.
Структурный подбор остаётся прежним.

GPU на этой машине доступен вне песочницы. Использовалась свободная
V100 №1; существующие процессы на остальных устройствах не затрагивались.

    CUDA_VISIBLE_DEVICES=1 OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
      MKL_NUM_THREADS=2 python experiments/compositional_sine_v2/run.py \
      --protocol experiments/compositional_sine_v2/protocol_gpu_30.json \
      --output experiments/compositional_sine_v2/results/gpu_30_v1 \
      --device cuda

Оба запуска сохраняют фактически запущенный скрипт, протокол и веса.
Первый CPU-запуск не повторялся после появления доступа к GPU.

Контроль нормировки исходных направлений и нового общего масштаба:

    python experiments/compositional_sine_v2/source_scale_control.py \
      --run experiments/compositional_sine_v2/results/pilot_v1

В усиленной проверке использована свободная V100 №3:

    CUDA_VISIBLE_DEVICES=3 OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
      MKL_NUM_THREADS=2 python experiments/compositional_sine_v2/source_scale_control.py \
      --run experiments/compositional_sine_v2/results/gpu_30_v1 \
      --device cuda --adam

Этот контроль добавлен после первого CPU-пилота. Общий масштаб выбирается
из 0,5/1/2/4/8, шаг Adam — из 0,001/0,01/0,03; оба выбора используют
только две настроечные задачи. Итоговые задачи для настройки не используются.

Построить отчёт по двум завершённым запускам:

    python experiments/compositional_sine_v2/report.py

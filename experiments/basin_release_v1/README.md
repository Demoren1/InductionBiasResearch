# Сохранение структуры или только структурная инициализация

Продолжение `basin_structure_transfer_v1` на новых численных задачах
с частотами около 6 и 8. Генераторы и банк четырёх индексаторов заморожены;
все кодбуки и амплитуды инициализируются заново.

Основная пара получает одинаковые предложения I, начальные эффективные
веса, амплитуды, минибатчи и query. Первый метод сохраняет равенства,
второй немедленно освобождает все веса. Оптимизатор и шаг калибруются
отдельно; радиус основного плотного контроля совпадает со структурным.
Дополнительный плотный контроль свободно выбирает и радиус, поэтому
не относится к сравнению строго одинаковых начальных весов.

[Протокол](protocol.json) задаёт новую калибровку, 128 знакомых и 32 чужих
целевых задачи, три существующих AR-модели и 65536 обновлений на метод
и задачу. Калибровка и итоговые функции независимы. Настройки сохраняются
до создания итоговых функций. Exact population MSE служит только отчёту;
query выбирает настройки на калибровке и кандидата на целевой задаче.

```bash
CUDA_VISIBLE_DEVICES=5 python3 -m experiments.basin_release_v1.run --frequency 6
CUDA_VISIBLE_DEVICES=6 python3 -m experiments.basin_release_v1.run --frequency 8
python3 -m experiments.basin_release_v1.report
```

Готовые каталоги не перезаписываются. Сохраняются код, хеши входов,
численные старты и результаты всех сравнений. В конце проверяется
совпадение начальных весов основной пары с учётом float32-округления.
Три seed используют одну библиотеку и одни задачи, не три независимые
выборки. Модульные тесты не добавляются и не запускаются.

После основного опыта объявлен [отдельный контроль](sgd_protocol.json)
на ещё одной независимой численной выборке. Обе стороны используют
одинаковый обычный SGD, шаг и радиус; общие настройки выбираются по
среднему качеству пары на уже завершённой калибровке. Он проверяет
взаимодействие структурного ограничения с выбором оптимизатора.

```bash
CUDA_VISIBLE_DEVICES=5 python3 -m experiments.basin_release_v1.sgd_control --frequency 6
CUDA_VISIBLE_DEVICES=6 python3 -m experiments.basin_release_v1.sgd_control --frequency 8
python3 -m experiments.basin_release_v1.sgd_report
```

Обе серии и их ограничения: [отчёт](../../mds/BASIN_RELEASE_CONTROL_2026-11-03.md).

# Восстановление индексатора по одной задаче

14 ноября 2026. Исследовательский запуск на двух прежних геометриях
general/random (case_04, case_05), с новыми численными source-задачами
и новыми примерами. D=H=16, четыре независимых кода; один и два выхода
соответственно. Это не независимая проверка на новых геометриях.

В каждом условии доступна ровно одна source-задача. Число примеров:
4096 fitting, 512 numerical validation, 1024 separate structure selection.
Шума ответов нет. Подготовка dense-весов и G34 используют неизменённые
исходные функции. GPU 0 и 1, без изменения чужих процессов.

Новый генератор сравнивает непосредственно разности логарифмов модулей
внутри нейронов. Нулевые разности объединяют индексы только локально;
совпадающие ненулевые упорядоченные разности объединяют первые и вторые
концы пар. Транзитивное замыкание даёт частичные группы. Полные группировки
с четырьмя кодами сохраняются; неполные не подменяются кластеризацией.
Маски строятся из собственной неопределённости dense-модели и масок её
начальных квантований. Сетка порогов и правила ранжирования фиксируются
до запуска извлечения. Один source-набор не используется для оценки SVD.

Геометрическое ранжирование использует только остаток калибровки при
фиксированных группах. В банк допускается не более 32 кандидатов.
Численный refit: четыре начальных состояния и 48 GN-шагов на кандидата;
структуру выбирает отдельный source structure-selection набор. Полный G34
получает тот же вход, с прежним собственным поиском; равенство полной
вычислительной стоимости не предполагается.

Идеальные контроли отдельно используют точные веса одной задачи и
положительные масштабы нейронов. Контролируемый log-шум проверяет запас
между различными отношениями кодов. Эти контроли явно имеют доступ к
истине и не поставляют индексаторы или пороги слепому learner.

Банки и source selections замораживаются до структурного аудита.
Измеряются попадание истины в банк, точное signed/unsigned восстановление,
ошибка маски, размер банка и время. Истинные параметры и ответы новых
target-задач недоступны learner. Перенос проверяется после фиксации
структур с полностью свежими численными параметрами.

Software tests не создаются и не запускаются. Статья и прежние результаты
не перезаписываются.

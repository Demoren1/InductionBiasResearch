# Очистка 8 ноября 2026

Удалены сырые данные завершённых запусков, промежуточные численные
состояния, старый архив журналов и кэши. Три завершённые ветки G34
перенесены из `experiments/` в `archive/experiments/`; шесть отчётов
и теоретических заметок из корня — в
[archive/reports/2026-11-08](../reports/2026-11-08/README.md).

## Результат

- Удалено 46 675 файлов из четырёх сырых `results/`, `artifacts/local/`,
  Python/Ruff-кэшей и регенерируемого `paper/build/`.
- Чистое сокращение объёма файлов после сохранения аудита — 4,216 ГиБ.
  Это сумма размеров файлов, а не замер свободного места общего сервера.
- Рабочими остались итоговый benchmark, зарегистрированное ядро G34
  и необходимый им модуль совместимости `darts_structured_tasks_v1`.
- Статья, PDF, таблицы, рисунки, выбранные индексаторы и основной
  `artifacts/benchmark_2026-11-07/` сохранены. До и после операций
  сверены SHA-256 всех 2608 защищённых файлов.
- История Git и посторонние изменения исходников сохранены.
  Программные тесты и новые эксперименты не запускались.

## Сохранённый аудит дополнительных проверок

В каждом `artifacts/g34_*_2026-11-08/` добавлены два архива:

- `audit_arrays.tar.gz`: точные предсказания, кривые, выбранные структуры
  и ранее открытые ответы для аудита. Общие reference-предсказания
  и ответы robust/support находятся в general-комплекте.
- `audit_records.tar.gz`: регистрации, протоколы, receipts, снимки кода,
  записи численного fitting и итогового scoring.

Архивы используют исходные пути относительно корня репозитория.
Внутри каждого есть `retained_sha256.json`; байты каждого сохранённого
файла сверены после записи архива, до удаления исходного каталога.
Размер каждого архива меньше 100 МиБ. Таблицы и рисунки доступны
без распаковки.

Для чтения распакуйте нужную пару в отдельную временную папку:

```bash
mkdir -p /tmp/ibr-audit-20261108
tar -xzf artifacts/g34_general_2026-11-08/audit_arrays.tar.gz \
  -C /tmp/ibr-audit-20261108
tar -xzf artifacts/g34_general_2026-11-08/audit_records.tar.gz \
  -C /tmp/ibr-audit-20261108
```

Это частичный аудит, а не полный снимок каждого запуска. Полные proposal
banks, все состояния оптимизатора, source-наблюдения и development/pilot
наборы не сохранялись. Старые frozen-манифесты могут перечислять файлы,
удалённые при очистке. Для нового обучения нужно восстановить архивные
пакеты на прежние места и заново подготовить данные; прежние команды
полного scoring могут требовать регенерации банков. Ответы и истинные
структуры предназначены для аудита завершённых результатов.

`results/20261107/` и архив журналов, оставленные 7 ноября, удалены
именно этой операцией.

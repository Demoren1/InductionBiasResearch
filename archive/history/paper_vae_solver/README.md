# Предыдущая статья о структурном VAE-поиске

Здесь сохранены [PDF статьи](main.pdf), четыре подробных отчёта
в [results/](results) и соответствующие JSON-сводки. Файлы восстановлены
без изменения содержимого из ревизии
`eae6086` (полный идентификатор и SHA-256 файлов —
в [списке восстановления](../../2026-11-03/restored_from_git.json)).

Это материалы этапа 25–26 октября 2026. Они нужны для чтения прежних
итоговых отчётов и сопоставления исторического partwise VAE с новым AR.
Текущая рукопись находится в [paper/](../../../paper/main.tex),
новый опыт — в [sine_ar_current_v1](../../experiments/sine_ar_current_v1/README.md).

`reproducibility/`, исходные веса и рисунки из `results/figures/`.
Они отсутствуют и в этом архиве. Ссылки на них внутри исторических отчётов
сохранены как часть исходного текста; этот каталог не является полным
комплектом для повторения всех запусков.

Таблицы и сводные рисунки итогового отчёта за 26 октября можно построить
по сохранённым JSON и файлам в `mds/assets/2026-10-26/`; пути чтения
в его скриптах обновлены на этот архив. Полный текст доказательств
доступен в сохранённом PDF.

# Provenance

The files in `source/` are the original completed-run snapshot, retained verbatim. They contain historical temporary paths and are evidence, not the current entry point. `selection.json` hashes refer to that snapshot.

Run the maintained package from the repository root with `python3 -m sine_mask_vae run --run-dir sine_mask_vae/runs/reproduction`. No measurements were recomputed during relocation. Banks, weights and per-search arrays stay in the ignored local run directory.

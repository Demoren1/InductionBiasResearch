# cVAE на Multimask

17 октября 2026. Общие encoder/decoder, условие **семья A/B** добавлено в оба. Prior стандартный N(0,I), без обучаемого conditional prior. Семья известна из постановки эпизода и не содержит индекс варианта, эталонную маску или held-out метки. Это сильная metadata-подсказка, не доказательство распознавания неизвестной семьи по данным.

Два варианта: cVAE surrogate сохраняет старый weighted BCE/hard-MSE/beta-KL для сравнения архитектур; cVAE ELBO использует обычный средний Bernoulli BCE плюс KL, делённый на 544, без hard-MSE/pos-weight/warmup. Последний является normalized negative ELBO факторизованной Bernoulli-модели; top-32 применяется только как правило решения.

## Обучение на трёх инициализациях

| Модель | Bank-test IoU, mean ± SD | KL |
|---|---|---|
| 1E / 1D | 0.7382 ± 0.3413 | 6.7767 |
| cVAE surrogate | 0.9290 ± 0.0157 | 4.7667 |
| cVAE ELBO | 0.9431 ± 0.0091 | 4.1055 |

Ширины исходные, 128 карт на задачу; отдельные validation/test seeds учителей. Объективы двух cVAE различаются, их абсолютный loss напрямую не сравнивать. Более высокий IoU ELBO-варианта не позволяет приписать весь эффект только conditioning.

## Перенос — фиксированный seed 4213

| Модель | IoU A / B | Test BCE A / B |
|---|---|---|
| 12E / 1D | 0.9394 / 1.0000 | 0.55952 / 0.54540 |
| 1E / 1D | 0.9394 / 1.0000 | 0.55964 / 0.54540 |
| cVAE surrogate | 0.9394 / 1.0000 | 0.55964 / 0.54540 |
| cVAE ELBO | 0.9394 / 1.0000 | 0.55952 / 0.54540 |

Восемь стартов,80 Gumbel/RelaxedTopK шагов по source BCE, фиксированная source-only настройка от 13 октября; три свежие MLP на каждую held-out задачу. Полный meta-search здесь один на модель, не три независимых повторения.

| Модель | Семья | D(0): IoU / BCE | Смена condition: IoU / BCE |
|---|---|---|---|
| cVAE surrogate | A | 0.8286 / 0.57759 | 0.8824 / 0.57041 |
| cVAE surrogate | B | 0.9394 / 0.55667 | 0.0000 / 0.69620 |
| cVAE ELBO | A | 0.8286 / 0.57894 | 0.0000 / 0.69724 |
| cVAE ELBO | B | 1.0000 / 0.54540 | 0.0000 / 0.69599 |

Для B даже frequency baseline только по семье достигает IoU 1 и BCE 0.54540; точный B сам по себе не доказывает пользу z или cVAE. Для A frequency baseline имеет IoU 0.7778. Нулевой код и смена condition отделяют эффект условия от latent; encoder-intervention дополнительно приведён в отчёте 1.

**Вывод:** конечный IoU не улучшился против исходной архитектуры: оба cVAE дали 0.9394 / 1.0000 для A/B. ELBO-вариант улучшил средний bank-test IoU, но функция обучения отличается; это не чистый эффект conditioning. Для B оптимум доступен при нулевом z, поэтому результат не доказывает пользу поиска. Все четыре равноценные моды не восстановлены. Известный family condition здесь существенно проще условия для совершенно неизвестной семьи.

Выбор лучшего из восьми z по source-validation, без градиентного обучения z; для обратной модели сначала zero-routing среди 12 ветвей. SD описывает три инициализации модели на одном наборе задач, не доверительный интервал.

Исходная строка полного meta-search для seed 4213 переиспользует сохранённый baseline от 13 октября; новые архитектуры оценены в текущей серии на том же банке, данных и протоколе. Это не пять новых полностью независимых повторений.

# Уборка 7 ноября 2026

Рабочими оставлены итоговое сравнение и зарегистрированное ядро G34.
Подготовка данных, методы, численная адаптация, исполнение и отчёты
разнесены по подкаталогам текущего benchmark. Соответствие старых и новых
имён записано в [module_moves.json](module_moves.json).

Прежние ветки находятся в [archive/experiments](../experiments/README.md),
заметки и итоговые отчёты — в [archive/reports](../reports/README.md).
Полный итоговый benchmark в `experiments/paper_structure_benchmark_v1/results/20261107/`
сохранён локально и исключён из Git. Его замороженные файлы и исходники
зарегистрированного метода не изменялись.

## Что сохранено

- [source_before_cleanup.tar.gz](source_before_cleanup.tar.gz) — исходники,
  выполненные исторические снимки кода и авторские документы до уборки.
  Все 3 200 файлов проверены по SHA-256 до удаления рабочих копий;
  [manifest](source_before_cleanup.manifest.json) содержит их исходные пути.
- В `archive/experiments/` оставлены канонические исходники, небольшие
  настройки, таблицы, отчёты, иллюстрации и `*.summary.npz`. Последние
  содержат только ограниченные структурные поля, кодбуки и метрики.
- `artifacts/local/legacy_records_2026-11-07.tar.gz` содержит большие
  JSON/JSON.GZ-записи старых запусков без изменения байтов. Архив целиком
  прочитан и проверен перед удалением оригиналов; он остаётся локальным.
- [Публикуемый комплект](../../artifacts/benchmark_2026-11-07/README.md)
  содержит точные итоговые предсказания и достаточно данных для пересчёта
  метрик, таблиц и рисунков. Ответы и эталонные индексаторы доступны только
  для аудита результатов, замороженных до их открытия.

Удалены старые тяжёлые чекпойнты, исходные большие массивы, повторные
снимки выполненного кода после проверки резервной копии, кэши и журналы.
Архив старых экспериментов не является полным комплектом их повторного
обучения. История Git сохранена без переписывания.

## Учёт и границы восстановления

Первый одноразовый скрипт завершил перенос файлов и проверку локального
архива, затем остановился на уже отсутствовавшем пустом каталоге до записи
сводного манифеста. Его выполненная версия сохранена в
[cleanup_legacy_attempt01_executed.py](cleanup_legacy_attempt01_executed.py).
Исправленная версия [cleanup_legacy.py](cleanup_legacy.py) пишет журнал
по мере работы; повторно применять её к уже очищенному дереву не следует.

Учёт восстановлен по резервной копии исходников, сохранённым архивам,
текущим сводкам и исходным Git blob ID. Состояние проверки записано в
[cleanup_recovery_state.json](cleanup_recovery_state.json). Для удалённых
больших файлов, которые никогда не были в Git, полный исходный перечень
контрольных сумм утрачен. Новая инвентаризация описывает реально сохранённые
файлы и не подменяет отсутствующие исходные хеши.

Итоговый состав и контрольные суммы приведены в
[artifact_cleanup_summary.json](artifact_cleanup_summary.json) и
`retained_inventory.jsonl.gz`. Исходные Git blob ID находятся в
`original_tracked_blobs.jsonl.gz`; большие записи локального архива —
в `local_record_inventory.jsonl.gz`.

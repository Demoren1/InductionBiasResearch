# Очистка исследовательского репозитория — 19 ноября 2026

Исходная ревизия: `ea72ea967f5ba0957b72bd1ff588b857fceb606a`.

Из рабочего дерева удалено 53 760 файлов, занимавших около 6,51 ГиБ.
Основную часть составляли локальные каталоги завершённых прогонов,
большие базисы Yeh и MSR, состояния подбора, дубли скачанных данных
и повторяемые синтетические панели. Убрано 90 файлов устаревшего кода
и неиспользуемых секций. Отслеживаемые версии остались в истории Git;
локальная копия удалённых исходников сохранена отдельно на рабочем
хосте. История Git не переписывалась.

`removed_files.json.gz` содержит пути, размеры, причины удаления
и SHA-256 файлов. Результаты закрытых серий остаются в отчётах.
Старые регистрации описывают исходные прогоны; полный повтор
потребует заново подготовить выпавшие из комплекта входы.

Для текущей статьи опубликованы компактные предсказания, ответы,
выбранные дискретные индексаторы и контрольные суммы. Команда
`python -m experiments.paper_compact_v1.evidence` пересчитывает
MSE, точность, кросс-энтропию и интервалы для синтетики, двух ширин
Omniglot и UCI HAR. Полные тренировочные данные и непрерывные базисы
в новый коммит не входят. Подготовленные FC100, NinaPro, Omniglot
и данные текущих запусков сохраняются локально там, где нужны для
продолжения работы.

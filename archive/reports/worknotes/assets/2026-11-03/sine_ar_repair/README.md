# Sine: композиция AR, шум и гиперпараметры

Источник: [завершённый запуск](../../../../../experiments/sine_ar_repair_v1/results/run_20261103).
[Подробный отчёт](../../../SINE_AR_REPAIR_2026-11-03.md).
Все новые priors обучены на одном строгом банке; мягкий банк показан
отдельным замороженным контролем. Целевые функции 14031/14032 новые,
384 поиска в каждом из двух условий на метод.

- `comparison.svg/png`: доли успеха, исходный и настроенный решатели.
- `coverage.svg/png`: предложение нужных связей, передача в refit, успех;
  отдельно — средняя вероятность точной новой маски на один сэмпл.
- `training.svg/png`: source-NLL, screen-query и температура генерации.
- `vae_training.svg/png`: KL и восстановление карточек при трёх β.
- `comparison.csv`: все 28 режимов, обе группы задач, MSE, успешность,
  интервалы по парам, покрытие и seed.
- `paired_differences.csv`: разности с заранее выбранными контролями.
- `generation_diagnostics.csv`: 3 × 32768 генераций на prior после
  замораживания настроек; числа масок, новизна, вероятность нужной маски.
- `sources.json`: SHA-256 источников и актуального скрипта графиков.

В основном выводе AR выбран по confirmation-query (`cross_noise`),
а не по результату целевых функций. Интервалы описательные, условны
на одном банке; новых координатных пар четыре. Более широкие маски
могут успешно обучаться, поэтому точная маска и наличие нужных рёбер
разделены. Query выбирает решения; population MSE используется для отчёта.

Рисунки строит [analyze.py](../../../../../experiments/sine_ar_repair_v1/analyze.py):

```bash
python -m experiments.sine_ar_repair_v1.analyze --phase figures
```

Исходный снимок анализа сохранён в run/source. Изменение размещения
легенд и заголовка после визуальной проверки сохранено отдельно
в run/source_revisions/publication; численные результаты не менялись.

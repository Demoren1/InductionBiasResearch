# Генерация структур для новых задач с другими кодбуками

2 ноября 2026. Основная постановка: генеративная модель учится порождать
индексаторы из исходного банка. На новой задаче она заморожена; каждый
предложенный индексатор фиксируется, а его численный кодбук обучается
с нуля. Успех — хорошее решение новой функции после такого обучения.
Создание ранее не встречавшихся структур не является обязательным.

Состояние на 3 ноября: постановка соответствует текущему
[Preliminary](../../../../paper/sections/preliminary.tex). Последующие
[контроли с признаком задачи](../INDEXATOR_TASK_CUE_RESULTS_2026-11-02.md)
и [одинаковыми стартами](../BASIN_RELEASE_CONTROL_2026-11-03.md)
ограничивают интерпретацию выигрыша: информативная инициализация помогает
и плотному Adam, а сохранение равенств при одинаковом обычном SGD
не дало преимущества. Общей гарантии против плотных методов нет.

## Что переносится

Индексатор описывает, какие связи отключены и какие позиции используют
одно общее число. Он задаёт целое семейство сетей:

$$
\mathcal F_I=\{f_{I,C,\theta}: C,\theta\text{ свободно обучаются}\}.
$$

Числа не входят в переносимое знание. В разных задачах один коэффициент
может менять знак и величину; равенство между соответствующими позициями
остаётся. Поэтому сохранение структуры совместимо с большими изменениями
самой функции. Дополнительные свободные параметры, если они предусмотрены
архитектурой, также обучаются заново.

Основной конвейер имеет вид:

$$
\begin{aligned}
\text{исходные решения}&\longrightarrow\text{извлечённые }I
\longrightarrow Q_\phi(I),\\
I_b&\sim Q_\phi,\\
(\widehat C_b,\widehat\theta_b)
&=A_T(I_b,S;\text{свежая инициализация}),\\
\widehat b&=\arg\min_b\mathcal L_{V}
  (f_{I_b,\widehat C_b,\widehat\theta_b}).
\end{aligned}
$$

Здесь S — примеры для численного обучения, V — независимые примеры
для выбора кандидата, T — фиксированный бюджет оптимизатора.
Генератор выдаёт только I. Он не выдаёт ни начальный, ни конечный кодбук;
исходные кодбуки не замораживаются и не переносятся в основной метод.
Окончательная ошибка измеряется на дополнительных данных, не участвующих
в выборе кандидата.

## Какое преимущество мы ищем

Полезная структура заранее задаёт согласованные ограничения на множество
весов. Их можно извлечь из опыта нескольких задач, даже если данных одной
новой задачи недостаточно для надёжного восстановления этих ограничений.
Численная оптимизация затем работает внутри выбранного семейства.

После завершённого пилота пользователь уточнил следующий основной случай:
данных достаточно, но плотный градиентный метод часто попадает в плохой
локальный минимум, а хорошее решение имеет малую область притяжения.
Ищем структуры, повышающие вероятность попасть в хорошее решение при
новом обучении чисел. Последний tanh-пилот показывает преимущество при
малом числе примеров; при 2048 примерах плотный Adam решает задачи точно,
поэтому оптимизационный барьер этим пилотом не установлен.

Это допускает преимущество над плотным обучением с нуля при заданных
данных и вычислениях. Само малое число кодов не гарантирует ни хорошей
аппроксимации, ни быстрой сходимости. Для общей ReLU/tanh-MLP у нас нет
теоремы, что такой метод всегда превосходит SGD. Строгие частные результаты
и условия локальной сходимости собраны в
[разборе ReLU](RELU_METHOD_THEORY_2026-11-02.md) и
[разборе tanh](TANH_STRUCTURAL_TRANSFER_2026-11-02.md).

Сравнивать следует также с плотным методом, имеющим доступ к тем же
исходным задачам. Многозадачное градиентное обучение само способно
извлекать переносимое представление в определённых моделях; например,
[Collins et al., ICML 2024](https://proceedings.mlr.press/v235/collins24a.html)
доказывают восстановление общего подпространства при своих предположениях
для двухслойной ReLU-сети. Это иной перенос, а не гарантия для наших
индексаторов, но причина включать сильный контроль предобучения.

## Исторический пример с плохим минимумом

Такой механизм уже исследован 21 октября. В
[random-mask опыте](../../../history/experiments/random_mask_vae/README.md)
искусственная функция по 16 параметрам имеет широкий строгий локальный
минимум с loss 1 и узкие глобальные минимумы с loss 0. Отношение локальных
кривизн равно 80. Правильная маска ограничивает поиск двумя координатами.
Для непрерывного градиентного спуска из согласованных Gaussian-стартов
сохранены 0/100000 успехов плотного поиска и 7399/100000 с правильной
маской; отдельно получена верхняя граница плотной вероятности 6,84e−8.
Это диагностика геометрии с известной маской, не результат генератора.

В последующем
[sine-опыте](../../../history/experiments/sine_mask_vae/results/v1/REPORT.md)
использована обычная MSE предсказаний сети. Цель содержит слабую низкую
и сильную высокую частоты; один нейрон на выход не может выразить их
обе. У ожидаемой MSE численно найдены строгие локальные минимумы с
ошибками 0,499315 и 0,048807. Нормы градиентов меньше 8e−9, минимальные
собственные значения гессианов положительны. Глобальность лучшего
минимума не доказана. Его локальная резкость сама по себе не измеряет
объём области притяжения.

На 1536 поисках с одинаковым числом онлайн-обновлений хороший результат
получен у настроенного плотного SGD в 2,86% случаев, у длинного плотного
SGD — в 2,02%, у замороженного NF/VAE с обучением по частям — в 38,54%.
Простой prior из независимых частот частей дал 37,70%. Все веса каждой
предложенной сети обучались заново; 592 успешных решения NF/VAE сохранились
после снятия маски и плотного дообучения. Стоимость исходного банка и VAE
учитывалась отдельно. Это результат для маленькой sine-сети с известными
ролями частей; он не доказывает тот же эффект для ReLU/tanh или особое
преимущество VAE перед простым структурным prior.

В старом опыте генерировались маски. Следующий опыт должен проверить
тот же оптимизационный механизм для назначений общих обучаемых значений:
генератор выдаёт I, а все элементы C независимо обучаются с нуля для
каждой новой функции. Известные структуры с новыми кодбуками достаточны;
требование новых сочетаний из старого опыта не переносится автоматически.

## Что структура может изменить в области притяжения

Зафиксируем полный столбцовый ранг матрицы назначений U. Если плохой
строгий локальный минимум плотной функции лежит в допустимом подпространстве,
он остаётся строгим локальным минимумом после ограничения на это
подпространство. В частности, при положительно определённом гессиане

$$
\begin{aligned}
w_b&=Uc_b, & \nabla L(w_b)&=0, & H_b&\succ0,\\
\nabla_c L(Uc_b)&=0, & \nabla_c^2 L(Uc_b)&=U^\top H_bU\succ0.
\end{aligned}
$$

В старом искусственном примере плохой минимум находится в нуле и лежит
в каждом линейном подпространстве индексатора. Поэтому структура не
устраняет его. Она меняет распределение начальных направлений и
последующие траектории так, что попасть в хорошую область может стать
вероятнее. Это и следует измерять; уменьшение числа параметров или
повышенная кривизна хорошего минимума по отдельности такого вывода не дают.

Для продолжения нужны два отдельных измерения: вероятность предложить
подходящий I и вероятность успешного обучения свежего C при этом I.
Сравнение с плотным методом должно использовать достаточный объём данных
или свежие minibatch, собственную калибровку шагов и масштаба старта,
рестарты и длинные запуски SGD/SGDM/Adam. У групповых параметров надо
учесть множитель размера группы в градиенте; сравнение с усреднённым
градиентом и согласованной нормой начальных весов отделит геометрию от
простого изменения шага или масштаба. Траектории неудачных запусков
следует проверить отдельно: существование плохого минимума ещё не
доказывает, что каждый неуспех вызван попаданием именно в него.

## Полезность генератора включает успех нового обучения

Зафиксируем задачу и её обучающую выборку. Пусть s(I) — вероятность, что
свежая инициализация и T шагов численного оптимизатора внутри I дадут
истинную ошибку не выше выбранного порога. Тогда успех одной попытки равен

$$
p=\sum_I Q_\phi(I)s(I).
$$

При независимых предложениях и независимых случайностях оптимизатора
вероятность получить хотя бы одного хорошего кандидата за B попыток равна

$$
1-(1-p)^B.
$$

Это вероятность присутствия хорошего решения среди кандидатов, а не
гарантия его правильного выбора по конечной query. Формула условна на
общую обучающую выборку; случайность разных задач усредняется после неё.
Для неоднородных задач нельзя подставлять средний p в эту формулу как
точную оценку: из вогнутости следует

$$
\mathbb E_\tau[1-(1-p_\tau)^B]
\le 1-(1-\mathbb E_\tau p_\tau)^B.
$$

Поэтому нужны результаты по отдельным задачам и семьям. Высокая средняя
частота хороших предложений может скрывать целую плохо покрытую семью.
Низкая NLL исходных индексаторов также не заменяет проверку s(I):
maximum likelihood учит распределение банка, а полезность определяется
новым обучением чисел. Это уточнение ранее записанного аргумента покрытия,
а не доказательство нового универсального алгоритма обучения MLP.

## Зачем совместная генерация при уже известных структурах

Даже хранение нескольких изученных структур требует сохранять зависимости
между их частями. Зафиксируем две опорные позиции с метками 0 и 1.
У первого индексатора остальные L позиций присоединены к группе 0,
у второго — к группе 1. Это два разных разбиения позиций, а не просто
переименование кодов. При равной частоте этих структур переменные
позиции имеют маргинальные вероятности по половине. Независимое
сэмплирование этих L позиций возвращает одну из двух исходных структур
с вероятностью

$$
2^{1-L}.
$$

Точная совместная модель всегда возвращает одну из них. Авторегрессия
может представить такое распределение; её успешное обучение нужно
проверить. Перенос целой структуры из банка тоже сохраняет эти зависимости
и поэтому является обязательным сильным контролем. Здесь не требуется
новая комбинация частей или новая структура.

Это утверждение о покрытии исходных разбиений. Для ненулевого различия
двух значений кодбука смешанное разбиение не воспроизводит тот же вектор
весов: опорные позиции уже задают разные значения. Однако перенос этого
факта на ошибку произвольной нейросети требует идентифицируемости её
параметров. Предыдущий пример без опорных позиций был некорректен для
этой цели: постоянные метки 0 и 1 задавали одно и то же разбиение.

Если для каждой новой задачи пригодна одна из M равновероятных изученных
структур, точная безусловная модель с равными массами предлагает нужную
структуру за B попыток с вероятностью

$$
1-(1-1/M)^B.
$$

Это ориентир при идеальном численном обучении и отсутствии других
подходящих структур. Если одна структура подходит всем задачам, высокая
концентрация на ней полезна. Если подходят разные структуры, излишнее
снижение температуры может потерять покрытие части семей. Температуру
следует выбирать на новых исходных функциях с заново обученными кодбуками.

## Что разные исходные кодбуки дают извлечению

Рассмотрим уже согласованные по нейронам исходные веса. Для каждой
весовой позиции соберём её значения на m исходных задачах в один профиль.
Позиции одной истинной группы имеют одинаковые профили независимо от
того, чему численно равны кодбуки разных задач.

Пусть среднеквадратичная по задачам ошибка каждого профиля не больше e,
а минимальное расстояние между профилями разных истинных кодов равно d.
Тогда расстояние внутри группы не больше 2e, а между группами — не меньше
d−2e. Если d больше 4e, любой порог между этими двумя границами точно
восстанавливает группы. Это непосредственно следует из неравенства
треугольника.

Данный достаточный критерий объясняет, как разнообразие исходных функций
может отделить устойчивые равенства от близости чисел на одной задаче.
При точных весах и разных значениях кодов одной задачи уже может хватить;
разнообразие не является обязательным во всех случаях. Если два кода
совпадали на всех источниках, разделение их ролей может быть неидентифицируемым.

Условие относится к согласованным весам, а не только к низкому loss.
Перестановки нейронов и другие симметрии параметризации нужно учитывать.
На общей ReLU-сети хорошая аппроксимация исходных функций сама по себе
не доказывает близости весов к одному общему представлению.

## Место энкодера

Если банк индексаторов уже получен, энкодер VAE может получать I, а
декодер — выдавать распределение I. Кодбук в этот выход не добавляется.
Авторегрессионный вариант вообще не требует такого энкодера.

Отдельная возможная задача — обучить извлечение структуры из исходных
весов. Тогда выходом извлекателя должны быть отношения между позициями
или индексатор. Для работы с перестановками нейронов есть подходящие
архитектурные идеи в
[Navon et al., ICML 2023](https://proceedings.mlr.press/v202/navon23a.html).
Они учитывают симметрии весового пространства; готовой гарантии выделения
нужного нам I эта работа не даёт. В текущем пилоте используется существующее
извлечение, чтобы отдельно проверить генерацию изученных схем.

## Проверка и требование не ухудшать SGD

Текущий [пилот](../../../experiments/generative_structure_transfer_v1/README.md)
использует четыре выученные структуры, новые функции каждой известной
семьи и одну неизвестную семью. Генератор заморожен, все кодбуки основного
метода обучаются заново. Два объёма обучающих данных и длинные плотные
запуски помогают отделить эффект нехватки данных от недостатка шагов.

Для защиты от неподходящей структуры можно выбирать по query между
структурным решением и полноценным плотным baseline. Это требует
вычислить оба решения. Сохранение baseline с его полным бюджетом плюс
дополнительный поиск не является гарантией превосходства при том же
суммарном бюджете.

Для bounded loss можно получить вероятностную гарантию осторожного
переключения по отдельной независимой контрольной выборке. Для нашей
исходной неограниченной NMSE такой вывод без условий на хвосты не следует.
Пилот поэтому проверяет фактические ухудшения на независимом test,
а не называет выбор по query строгой гарантией.

Продолжение с оптимизационными ловушками также завершено:
[эксперимент с новым обучением кодбуков](../BASIN_STRUCTURE_TRANSFER_RESULTS_2026-11-02.md)
и [проверка доказательств](BASIN_TRANSFER_THEORY_AUDIT_2026-11-02.md).

# Исторические отчёты и заметки

- [worknotes](worknotes/README.md) — прежние рабочие заметки, теория и общие
  иллюстрации; до уборки находились в `mds/`.
- [final](final/README.md) — датированные итоговые отчёты; прежде `final_mds/`.
- [methods](methods/ALGORITHM_TRANSFORMER_RU.md) — прежнее описание метода
  с Transformer.

Содержание описывает соответствующие этапы исследования. Текущие результаты
и ограничения приведены в [отчёте статьи](../../paper/BENCHMARK_REPORT.md).
Внутренние ссылки обновлены после переноса. Ссылки на `*.summary.npz`
ведут к компактным структурным сводкам, а не к полным исходным массивам.
Часть старых ссылок на ранее удалённые данные остаётся исторической.

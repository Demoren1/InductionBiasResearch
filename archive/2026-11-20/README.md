# Очистка 20 ноября 2026

Удалены 472 временных файла завершённых серий, занимавшие 2,92 ГиБ:
дубли входов для валидации и заново генерируемые входы эпизодов.
[Перечень](removed_caches.json) содержит пути, размеры и SHA-256.

Сохранены исходные датасеты, параметры исходных моделей, выбранные
индексаторы и сохранённые результаты. В Git опубликован компактный
комплект из сводок, планов, поэпизодных оценок, структур и рисунков.
[Каталог отчётов](../../paper/theory/README.md) ссылается на данные
опубликованных экспериментов.

Отдельная серия с кодом в `experiments/paper_transfer_v2/` на момент
очистки продолжалась. Её файлы выполнения остались в рабочем каталоге.
Пути удалённых временных входов в старых регистрациях описывают
исходные прогоны; восстановление таких входов требует повторной генерации.

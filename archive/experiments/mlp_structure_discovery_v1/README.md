# Контроль: извлечение из весов решателей

3 ноября 2026 здесь выполнены обучение плотных MLP, последовательное
разреживание и кластеризация профилей весов без заданных блоков и ролей.
После уточнения пользователя основным стал случайный поиск, который
не ориентируется на численные веса градиентных решателей:
[random_structure_search_v1](../random_structure_search_v1/README.md).

Этот контроль остановлен после исходного отбора; авторегрессия и новый
целевой эксперимент для него не запускались. Его source-validation
результаты нельзя выдавать за подтверждённый перенос на новые задачи.

`fit.py` содержит общий численный решатель, используемый также случайным
поиском. В нём нет геометрии генератора задач. Остальные модули этого
каталога не предлагают структуры для случайного поиска.

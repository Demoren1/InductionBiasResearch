# Проверка необходимости бинарной support-маски G34

Дата регистрации: 8 ноября 2026. Проверка по прямому запросу пользователя.
Разрешены все GPU 0–7, не более одного внешнего задания на карту.

## Вопросы и варианты

Различаем отдельное хранение бинарной маски, фиксацию нулевых позиций
при поиске, фиксированный нулевой символ и сам шэринг.

1. **current**: неизменённый G34 из завершённой общей синтетической серии.
   Маска каждого геометрического запуска фиксирована, четыре свободных
   значения кодбука и фиксированный ноль.
2. **free**: те же source-решения, anchors, выравнивание, четыре варианта
   начальной маски и все исходные старты; после инициализации разрешён
   общий выбор из 0 и ±1,…,±4 на КАЖДОЙ позиции. Никакого штрафа за
   ненулевую связь. Исходный WLS и Cauchy score сохранены, IRLS не добавлен.
   Отдельная бинарная маска внутри цикла не фиксируется. Начальные маски
   и threshold-based alignment остаются: это не поиск с нуля без порогов.
   Как и current, банк сохраняет исходные source anchors; отчёт показывает,
   был ли выбран унаследованный anchor и был ли выбранный I в новых proposals.
3. **full**: те же начальные маски/старты, но после инициализации все позиции
   обязаны получить один из ±1,…,±4. При source meta-выборе допускаются
   только полностью ненулевые индексаторы; старый разреженный anchor
   не может незаметно спасти этот контроль. Число свободных кодов то же.
   Это меняет класс моделей: произвольные четыре ненулевых значения плюс
   фиксированный ноль нельзя в общем случае представить четырьмя
   полностью свободными знаковыми кодами.
4. **learned_zero**: у source-selected current I заменить все нули
   дополнительной меткой 5. На target обучаются пять свежих кодов;
   пятый код не фиксирован в нуле. Группировка бывших нулей известна из
   извлечённого I. Контроль проверяет необходимость ЖЁСТКОГО нуля при
   численной адаптации, а не способность самостоятельно найти эту группу.
5. **mask_only**: сохранить только маску выбранного current I, каждую
   активную связь сделать отдельным свободным параметром; шэринг снят.
6. **dense**: завершённый Dense из той же серии, без маски и шэринга.

## Согласованные бюджеты и данные

Ретроспективная абляция на уже известном cohort
experiments/g34_theory_v1/results/20261108_general/confirmation.
Новые target-ответы и teacher I открываются только после глобальной
фиксации всех новых выбранных структур и предсказаний. До неё доступны
только source observations/descriptors и уже экспортированные target
support/selection/query inputs. Новые target-результаты не используются
для настройки.

Шесть структур: по две local, quartet_mix и random. D=H=16, K=4,
O=1/2; 16 source tasks, source noise 0/0.2; независимые readout,
во второй структуре каждой семьи независимые hidden biases.
Source: 4096 train, 512 numerical selection, 1024 structure selection.
Новые source-варианты используют до 32 новых геометрических кандидатов,
четыре численных старта, 48 GN-шагов; те же source anchors и numeric code.
В full sparse anchors исключаются только из meta-выбора, их результаты
сохраняются для аудита. Free наследует тот же fallback, что current.

На каждой из 48 новых target functions переносится только I;
все численные параметры инициализируются заново. Те же вложенные N=64,
256,1024, дополнительная numerical selection N/4, 2048 clean query;
18 Adam starts × 2000 steps, затем четыре GN starts × 48 steps.
Программа target_fit/adaptation/numerical не меняется.
Для learned_zero и mask_only меняется только индексатор и число кодов.
Бюджеты шагов одинаковы; FLOPs, число параметров и время могут различаться.

## Основная оценка и ограничения

Основная метрика: clean target MSE после Adam+GN при N=1024,
раздельно по трём геометриям и source noise. Дополнительные:
N=64/256, Adam, mask precision/recall, exact I, шэринг ARI,
покрытие proposal/refit-банка, source/target стоимость, изменение
нулевых позиций во free-проекции. Проверка маски оценивается после
лучшей перестановки hidden units; точность signed I допускает
перестановки/знаки кодов и hidden units.

Две структуры на семью — малый диагностический cohort, не новая
независимая confirmation. Восемь функций одной структуры не являются
восемью независимыми структурами. Низкий геометрический Q сам по себе
не является доказательством качества переноса. Полный G34 и рукопись
не изменяются, новых software tests нет.

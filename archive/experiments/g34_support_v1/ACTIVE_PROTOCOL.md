# Проверка только фиксированной бинарной маски, нулевой символ сохранён

8 ноября 2026. Уточнение пользователя: «нуль надо оставить, я говорил
только про бинарные маски». Оно заменяет расширенный перечень сравнений
исходного PROTOCOL.md.

Сравниваются current G34 и free. В ОБОИХ случаях ровно четыре свободных
знаковых кода и специальный фиксированный ноль. Штраф, исходный WLS,
выравнивание, source observations, численные seeds, лимит refit и
target adaptation совпадают.

- current: внутри каждой геометрической проекции нулевые/активные
  позиции заданы отдельной фиксированной бинарной маской.
- free: исходная маска применяется только к инициализации. Затем на
  каждой позиции выбирается из 0, ±1,…,±4 по тому же Cauchy-cost;
  позиции могут переходить из нулевых в активные и обратно.
  Отдельная фиксированная маска не ограничивает итерации.
- Dense используется только как уже готовая контекстная оценка.

Исходные threshold-based source descriptors, alignment, anchors и
четыре варианта инициализации сохранены. Это проверка необходимости
ФИКСИРОВАТЬ support внутри совместной проекции. Она не доказывает, что
из всей source-процедуры можно удалить все threshold-based инициализаторы.
Как и в current, free допускает сохранение исходных source anchors;
в отчёте явно показано, выбран ли такой anchor или новая проекция.

Готовые free-задания и все их исходные hashes сохранены. Лишние full
задания остановлены; full, learned_zero и mask_only исключены из
активного сравнения и target-плана. Новых оценок target query до
уточнения не было. Отмена записана в scope_amendment.json, исходный
план сохранён для истории. Никакая настройка free не изменена.

12 source jobs → 12 новых target jobs, по одному внешнему заданию
на GPU, разрешены GPU0–7. Ретроспективный cohort прежний: по две
структуры local/quartet_mix/random, D=H16,K4,O1/2;16источников,
noise0/.2;8 новых функций/структуру. Source4096/512/1024;
до32 новых кандидатов×4старта×48GN. Target N64/256/1024,
selection N/4, clean query2048;18Adam×2000+4GN×48, переносится
только I, все численные параметры свежие.

Основная метрика — target MSE после Adam+GN при N1024 по geo/noise.
Дополнительные — меньшие N, Adam, маска precision/recall/exact,
точный signed I, покрытие банка, смены нулевых позиций и стоимость.
Все выбранные I и predictions фиксируются глобально до query/truth scoring.
Две структуры на семейство — диагностическая абляция на известном cohort,
не свежая confirmation. Software tests и правки рукописи не выполняются.

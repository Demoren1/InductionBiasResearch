# Зафиксированный базовый метод: deepsets_consensus_exact_v1

Непрерывный Z после 2000 шагов плотного обучения оптимизируется ещё 10000 шагов
по задаче и штрафу согласования с Q=C[I]. Каждые 50 шагов точная одномерная
проекция совместно выбирает I/C для Z+U. Все 256 позиций доступны, готовая
маска и число активных связей не передаются. Rho: 0.01→100, lambda: 0.3,
шаг dual: 0.25. Z не перезаписывается через C[I]; C внутри поиска вычисляется
проекцией. Отдельный task-fit C нужен для выбора снимков и финальной оценки.

Подтверждение: точный полный I в 3/3 запусках, успешные 32 свежих C исходной
функции; перенос фиксированного I на шесть дополнительных новых функций.
Полный протокол, фактические исходники и выбранные состояния сохранены здесь.
method.json закрепляет хеши исходных результатов и копий. Никакие состояния
учителя или сохранённые I этого архива не используются для инициализации
нового поиска со сбросами Z.

Оригинальные результаты: ../../results/20261104/deepsets_consensus_exact/.

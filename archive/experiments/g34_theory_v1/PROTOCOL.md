# Проверка предложений из теории G34

8 ноября 2026. Исходный G34 сохраняется без изменения научного ядра.

## Вопрос и границы

Проверяем, улучшают ли кандидаты по отношениям модулей и знаковым профилям
предсказания на новых численных задачах. Область этой проверки — две synthetic
семьи текущего benchmark: Pattern и DeepSets, source noise 0 и 0.1.
Результат не является проверкой на Omniglot/MNIST.

## Разработка и подтверждение

- Разработка использует только source observations и сохранённые source fits
  старых case_00/c1 и case_03/c1 из серии 20261107/synthetic_confirmation.
  Их прежние результаты уже известны, поэтому это development.
- Новый confirmation seed: 27110854013, три семейства каждого вида,
  шестнадцать source-задач и восемь target-задач на семейство.
- Новые source fits можно вычислять параллельно разработке, но их значения
  не используются для изменения конфигурации до её регистрации.
- Конфигурация proposals, их квоты и код фиксируются после development,
  до просмотра confirmation source-selection и любых target-результатов.
- True I, численные teacher-параметры, target responses и старые audit answers
  не доступны learner-процессам. Открытие I — только после freeze всех новых
  предсказаний для описательной диагностики.

## Сравнение

1. Исходный G34: те же source solver, anchors, projection и 32 новых refit.
2. G34 diversity: тот же исходный pool, но покрытие разных пространств и
   знаковых вариантов при том же лимите 32.
3. G34 theory: дополнительные отношения модулей, знаковые proposals и
   многозадачные support-гипотезы; тот же лимит 32 новых refit.

Все варианты сохраняют общие source anchors. Дополнительный размер
вычисленного pool не скрывается: CPU proposal time и весь source refit
учитываются отдельно. Это равный лимит refit, не обещание равного wall time.
Development может исключить ветвь, если она не даёт допустимых кандидатов;
окончательная конфигурация сохраняется отдельно до confirmation.

## Перенос и оценка

Переносим только I. На targets заново обучаются все числа.
Общий adapter исходного benchmark: 18 Adam restarts, 2000 шагов,
4 Gauss--Newton starts, 48 шагов; support 64/256/1024,
numerical selection 16/64/256, query 2048.
Seed адаптации общий для вариантов. Сохраняются обе стадии: Adam и Adam+GN.

Главная метрика — чистая target MSE при support1024.
Вторичные — MSE при 64/256, source selection, structural recovery/recall
после freeze, число кандидатов и затраты.
Сравнение парное по одинаковым target-задачам. Неопределённость сравнения
оценивается по независимым семействам; восемь задач внутри семейства
не считаются восемью независимыми структурными репликациями.

После глобального freeze сохраняются таблицы, train/validation loss по шагам,
графики target quality и structural recall, выбранные I, входные/кодовые
хеши, access receipts и Markdown-отчёт.
После открытия target answers изменения алгоритма по этому confirmation
не принимаются как независимо подтверждённые.

## Ресурсы

GPU 0–5, по одному внешнему заданию на GPU; GPU 6/7 не используются.
Без software tests. Исследовательские прогоны и проверка артефактов разрешены.

# Авторегрессия на одиночных реальных изображениях

[Отчёт с таблицами, примерами и графиками](../../reports/worknotes/REAL_IMAGE_AUTOREGRESSIVE_2026-11-02.md).

Проверка на MNIST и Fashion-MNIST без отвлекающих картинок и скрытой перестановки. Изображения усредняются до 14×14. Исходные классы 0–5, новые 6–9; задачи бинарные. Это перенос между задачами на реальных данных, а не стандартная десятиклассовая классификация.

Модель выбирает 64 из 196 входов, затем обучает MLP 64→16→1. Все ненулевые веса независимы: проверяем перенос масок, частный случай индексатора. Плотная MLP 196→16→1 и линейный классификатор — отдельные контроли. Архитектурная геометрия изображения в генератор не закладывается.

## Источник и генератор

Используются ранее собранные банки `experiments/structure_search_v2/runs/feature_bank_{DATASET}_v1/`: 832 маски, полученные эволюцией частичных решений. Новый численный аудит использует две скорости обучения, по четыре старта и 2048 шагов — всего восемь обучений на маску. Оставляются лучшие 75% внутри каждой исходной задачи и группы ветвей поиска: 624 маски, 312/156/156 для обучения, выбора и аудита.

Генератор получает только бинарные маски. MADE обучается максимальным правдоподобием; ширина, шаг и L 2 выбираются по NLL исходных validation-масок. В начале выходные смещения задают эмпирические частоты. Если лучшим оказывается шаг 0, это явно фиксируется: нейросетевое обучение не улучшило частотную инициализацию.

Порядок 196 позиций случайный и фиксирован заранее. Для всех предложений задан общий бюджет 64: после 64 выбранных входов остаются только нули; если нужны все оставшиеся позиции, они принудительно включаются. Эти принудительные позиции имеют нулевой вклад в NLL. Частотный генератор использует то же ограничение. Это единственное ограничение декодирования; оно не сообщает расположение полезных пикселей. Отдельный consensus выбирает top 64 частот, целая маска берётся из банка, случайная — равномерно из всех 64-подмножеств. Сохранён также необученный MADE.

## Калибровка и оценка

Численные оптимизаторы, температуры и длинные контроли выбираются на двух отложенных исходных парах классов и новых исходных изображениях. Генератор и все настройки замораживаются до создания целевых случаев. Support 16/64/256 на класс, query 64 на класс, official test 512 на класс. Query-метки — дополнительная разметка, не часть заявленного обучающего support.

У каждого метода 8 стартов 4096 шагов. При 16 примерах на класс дополнительно проверяются Adam/SGD с 16 384 шагами и исходным подбором соседних learning rates/constant/cosine. Выбор состояния и старта только по queryBCE. Целевые классы дают 6 пар×8 выборок:48 случаев, но всего 6 пар классов. Все методы используют одинаковые случаи.

Градиентный перенос предварительно обучает 196→16→6 на том же союзе 912 исходных изображений. Для него 528 train/384 validation,9 конфигураций×2 старта. На целевой задаче обучаются либо все веса с новой головой, либо только голова. Полная стоимость источника и FLOPs не уравнены с генератором структур.

## Команды

Из корня репозитория, Python с PyTorch/torchvision/NumPy/Matplotlib; CUDA доступна вне sandbox. Выбрать свободную карту через `CUDA_VISIBLE_DEVICES`.

```bash
python -m experiments.real_image_ar.run --dataset MNIST --stage prepare
python -m experiments.real_image_ar.run --dataset MNIST --stage source
python -m experiments.real_image_ar.prior --dataset MNIST
python -m experiments.real_image_ar.evaluate --dataset MNIST --stage calibration
python -m experiments.real_image_ar.evaluate --dataset MNIST --stage freeze
python -m experiments.real_image_ar.evaluate --dataset MNIST --stage target
```

Повторить для FashionMNIST. Калибровку и target можно разделять по `--size 16 64 256` и `--group structural|dense`. Один выход должен иметь одного работника. Полные численные состояния, наблюдения и кривые находятся в игнорируемом `runs/v1/`; законченные методы пропускаются по `complete.json`.

Используется неизменённый численный solver из `experiments.dynamic_signal_v1.fit`. Входы каждого старта заранее сокращаются до выбранных 64 координат, поэтому численные параметры действительно компактны. Маски не адаптируются на целевых данных.

Датасеты уже использовались в прежних разработочных опытах. Это новая проверка авторегрессионного метода на известном benchmark. Гиперпараметры не подбираются по его целевым результатам. Аналитического правильного индексатора для реальных изображений нет.

## Результат и воспроизведение отчёта

Преимущества в этой серии не получено. При 16 обучающих изображениях на класс AR дал 94,21% на MNIST и 97,11% на Fashion-MNIST; SGD — 95,77% и 97,30%. Генераторы обоих датасетов выбрали шаг 50, ширину 128, lr 0,0003 и L2 0,0001; дальнейшее обучение переобучалось на исходных масках. Все три объёма обучения и простые контроли сохранены в отчёте.

`python -m experiments.real_image_ar.report` проверяет замороженные входы и создаёт компактный экспорт. `python -m experiments.real_image_ar.report --from-export` пересоздаёт таблицы и рисунки из `results/v1/`, без обучения и больших исходных наблюдений. Калибровочные истории усреднены по конфигурациям. Списки входов в калибровочных NPZ восстанавливаются как `selected_inputs_unique[selected_inputs_inverse].astype('int64')`; индивидуальные итоговые метрики сохранены. Целевые истории и выбранные входы не усреднялись.

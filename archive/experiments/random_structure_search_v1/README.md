# Обнаружение структуры случайным поиском

Основной опыт после уточнения цели 3 ноября 2026: начальные маски и
индексаторы случайны; структура не извлекается из весов или градиентов
плотных решателей. Градиентный метод обучает только численные коэффициенты
при уже заданной структуре. Внешнему поиску доступны только ошибки
предсказаний после такого обучения.

## Что разрешено алгоритму

Вход — наблюдения `support_x/y`, `query_x/y` исходных задач. Размер входа
выводится из данных. Общий решатель — плотная по допустимым связям ReLU MLP
с 64 скрытыми нейронами. Никаких блоков входов, ролей, пар фильтров,
истинных перестановок или аналитических индексаторов в поиске нет.

Это не утверждение об отсутствии всех индуктивных предположений:
выбраны класс MLP, диапазоны сложности и операторы случайного поиска.
Они не используют устройство конкретного генератора задач.

Две популяции по 64 кандидата ищут бинарные маски и произвольные
группы равных весов. Начальная плотность и число кодов выбираются из
геометрических сеток. Случайные мутации добавляют, удаляют и переносят
связи, меняют коды, объединяют и разделяют группы равных весов.
Кроссовер меняет произвольные столбцы матрицы. Каждое поколение
сохраняет восемь лучших кандидатов и добавляет восемь новых случайных
кандидатов в каждую популяцию. Ни один оператор не читает численные веса.

Оценка кандидата — средняя query BCE на восьми исходных задачах после
1024 обновлений Adam с новой инициализации. Одинаковые начальные числа
и последовательности батчей уменьшают шум сравнения. Повторная структура
получает уже вычисленную оценку. 64 поколения после начальной популяции
зафиксированы до запуска.

Затем отдельные исходные задачи 8–9 выбирают структуру, численные
настройки и температуру генерации. Банк из 32 структур обучает MADE.
У AR отложены кандидаты банка, а не независимые семейства: родственные
потомки могут находиться в обеих частях. Новые целевые задачи создаются
только после замораживания банка, генератора и настроек. Задачи 10–11
служат дополнительным исходным аудитом.

На каждой целевой задаче заново обучаются все численные коэффициенты:
2048 support-примеров, восемь стартов, 4096 обновлений на старт.
Query выбирает старт и checkpoint, независимый test используется только
для окончательных метрик. Контроли — плотная MLP, одна найденная структура,
выбор структуры целиком из банка, независимые частоты, новые случайные
структуры с тем же числом связей и распределением кодов, перестановка
входов найденной структуры и та же маска без sharing.

## Запуск

Из корня репозитория, последовательно:

```bash
CUDA_VISIBLE_DEVICES=0 python -m experiments.random_structure_search_v1.search
CUDA_VISIBLE_DEVICES=0 python -m experiments.random_structure_search_v1.select
CUDA_VISIBLE_DEVICES=0 python -m experiments.random_structure_search_v1.prior
python -m experiments.random_structure_search_v1.prepare_target
CUDA_VISIBLE_DEVICES=0 python -m experiments.random_structure_search_v1.evaluate --stage audit
CUDA_VISIBLE_DEVICES=0 python -m experiments.random_structure_search_v1.evaluate --stage target
python -m experiments.random_structure_search_v1.report
```

`protocol.json` описывает алгоритм, `benchmark.json` — только генератор
независимых данных. Последний читает лишь `prepare_target.py` после
замораживания алгоритма. Архив `teacher_audit_only.npz` не используется
ни поиском, ни отбором, ни генератором индексаторов, ни оценкой качества.

Полные наблюдения и веса сохраняются в исключённом из Git `runs/`.
Компактные результаты, найденные индексаторы, кривые и хеши экспортирует
`report.py`. Общий численный решатель находится в
`../mlp_structure_discovery_v1/fit.py`; при поиске он возвращает только
предсказательные метрики (`save_parameters=False`).

Ранее начатое извлечение из весов в `mlp_structure_discovery_v1` остановлено
после уточнения пользователя и не подменяет этот случайный поиск.

## Результат первого запуска

[Отчёт и графики](../../reports/final/RANDOM_STRUCTURE_SEARCH_2026-11-03.md):
7183 случайных и мутировавших структуры, один банк, 16 новых задач.
Полезный перенос в этом бюджете не получен: плотный Adam — 82,52%,
свежие случайные маски — 81,48%, выбор из банка — 81,42%.
У MADE выбран checkpoint на шаге 0, задающий независимые частоты;
его 81,17% не являются результатом обучения авторегрессионных зависимостей.

Банк содержит 32 разных маски, но медиана попарного расстояния — всего
19,5 позиции из 8192. Исходный отбор улучшился без подтверждённого переноса.
Это отрицательный результат данного поиска, а не доказательство
невозможности обнаружения структуры.

Точные снимки замороженного кода, исходный вариант выполненного поиска до
правок стиля, checkpoint, банк и численные итоги сохранены в
`results/search_20261103/`. Авторская интерпретация checkpoint и разнообразия
банка — `interpretation.json` и отчёт; генерация графиков не переобучает модели.

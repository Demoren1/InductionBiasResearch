## Архивирование кода 26 октября

При уборке 26 октября компактный комплект прежней статьи был сохранён
в `paper_vae_solver/reproducibility/`. Каталог `paper_vae_solver/` теперь
отсутствует в рабочем дереве; сведения о той упаковке описывают прежний этап.
Код новых опытов находится в [experiments](../experiments).

`2026-10-26/legacy_research.tar.gz` содержит прежний код, включая незакоммиченные
изменения, конфигурации, снимки исходников и текстовые/табличные результаты
проектов `pattern`, `multimask`, `overlapping_groups` и `tmp`.
Каждый из 13 344 файлов проверен по SHA-256 перед удалением рабочей копии.
Рядом лежит manifest с перечнем файлов и контрольными суммами.

Тяжёлые веса и бинарные массивы старых опытов, сгенерированные банки `data/`,
кэши и журналы удалены. Архив прежнего кода не является полным комплектом
для воспроизведения старых исследований.

Для просмотра прежнего кода распакуйте его отдельно:

```bash
mkdir -p /tmp/induction-bias-legacy
tar -xzf archive/2026-10-26/legacy_research.tar.gz -C /tmp/induction-bias-legacy
```

Команда выполняется из корня репозитория. Архивные переносы сохраняются
обычными коммитами без переписывания истории Git.
Состав уборки зафиксирован в [cleanup.json](2026-10-26/cleanup.json).

При подготовке публикации 3 ноября из прежней Git-ревизии дополнительно
восстановлены исходники `data/` и `sine_mask_vae/`, три небольших массива
overlapping groups, PDF и сводки `paper_vae_solver/`. Они размещены
в тематических папках `history/`; существующие архивные копии сохранены.
Исходная ревизия, пути и SHA-256 записаны в
[restored_from_git.json](2026-11-03/restored_from_git.json).
Для шести ранних итоговых отчётов в `final_mds/` оставлены ссылки на полные
архивные версии, чтобы не поддерживать два экземпляра одного текста.

## Внешняя память: состояние на 26 октября

Память Basic Memory на Mac обновлена 26 октября 2026. В
`projects/induction-bias-research/` сохранена краткая карта проекта; текущие
теория, результаты и рукопись вынесены в `paper/`, сведения об артефактах —
в `artifacts/`. Десять прежних заметок перенесены в тематический `archive/`

в карте тогда были зафиксированы пауза исследований и ожидание авторских правок.
Это исторический статус; актуальная навигация указана в начале этого файла.

Первоначальная ошибка `Transport closed` относилась к прежнему подключению
инструмента этого чата. Новое MCP-соединение через тот же SSH-сокет успешно
прочитало и обновило заметки; Mac/SSH при повторной проверке были доступны.

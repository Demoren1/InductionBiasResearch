The connectivity and parameter-sharing structure of a neural network
influences how well it generalizes from limited data. We study how
solutions to related tasks can reveal structural constraints that
remain useful when numerical parameters are learned afresh. We
represent these constraints by an indexator specifying active
connections and signed groups of shared weights, with task-specific
values supplied by a trainable codebook. For aligned ReLU weights
with known active connections, we characterize when the observations
uniquely determine the groups and give sufficient conditions for exact
recovery by Sign--Ratio Recovery (SRR). For fitted dense networks,
we propose Approximate Sign--Ratio Recovery (aSRR), which clusters
normalized weight profiles across source tasks. We transfer the resulting
indexator and train the numerical parameters from scratch on each
new task. On a cross-correlation benchmark with known support, aSRR
recovers all signed groups in six layouts. Across five real datasets,
the learned groups improve accuracy over matched shuffled groups on
four, using the same number of trainable coefficients.

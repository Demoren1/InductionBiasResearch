# aSRR и случайные индексаторы на синтетике

18 ноября 2026 года.

## Зашумлённые профили с известными группами

Сгенерировали 32 новые структуры общим генератором синтетики aSRR.
Для каждой структуры использовали восемь исходных профилей и три
новые тестовые функции. Уровни шума 0, 0,01 и 0,04 проверяли на одних
и тех же структурах. На вход алгоритму подавались зашумлённые
выровненные веса, полученные из учителя.

Для общих групп входов использовали кластеризацию профилей входов.
Для знаковых групп использовали знаковую кластеризацию aSRR.
Число кодов и семейство групп заданы условиями задачи. Случайный
контроль сохраняет число кодов, знаки и число связей каждой группы
в каждом нейроне. Для групп входов переставляли входы совместно
во всех нейронах. Отдельно проверили схему с одним общим кодом
и отдельными кодами для случайных связей.

На каждой новой функции численные коды подбирали заново на общих
наблюдениях методом ridge с выбором регуляризации по численной
валидации. Случайные контроли усредняются по четырём маскам.
Точное восстановление проверяется с учётом переименования кодов
и смены общего знака кода. Для деформированной структуры сравнение
идёт с исходными группами до деформации.

| Структура при шуме 0,04 | Коды | Точных aSRR | MSE aSRR | MSE случайных групп | MSE общего кода с исключениями | MSE Dense | MSE истинного индекса |
|---|---:|---:|---:|---:|---:|---:|---:|
| Сбалансированные знаковые группы | 8 | 4/8 | 0,00427 | 0,665 | 0,741 | 0,0341 | 0,00170 |
| Неравномерные знаковые группы | 8 | 3/8 | 0,00570 | 0,718 | 0,860 | 0,0375 | 0,00178 |
| Деформация от задачи к задаче | 8 | 0/8 | 0,09634 | 0,951 | 1,025 | 0,0349 | 0,06129 |
| Общие группы входов | 24 | 8/8 | 0,00610 | 0,689 | 0,708 | 0,0373 | 0,00610 |

Для общих входных групп парная разница MSE между случайными группами
и aSRR равна 0,683 (95% ДИ от 0,314 до 1,052, по восьми независимым
структурам). При деформации от задачи к задаче Dense даёт меньшую
ошибку, чем даже исходный индексатор с истинными группами до
деформации. [Результаты по всем уровням шума](../../artifacts/asrr_synthetic_random_controls_2026-11-18/linear/results.json).

## ReLU-задача из статьи

Использовали сохранённый индексатор aSRR из обученного Dense
и те же четыре новые функции случая 04. Во всех структурных
вариантах четыре кода. Для каждого из двух индексаторов построили
четыре случайные перестановки связей внутри каждого нейрона,
сохраняя активные позиции, знаки и число связей каждой группы.
Во втором контроле использовали индексатор учителя.
Значения кодов, смещения и выходные веса подбирались заново тем же
Adam и Gauss–Newton.

| Метод | Активные связи | Query MSE |
|---|---:|---:|
| G34, совпавший с истинным индексатором | 160 | 1,91 × 10⁻¹¹ |
| Случайные группы при активных позициях и знаках учителя | 160 | 1,298 |
| aSRR из Dense | 256 | 1,426 |
| Случайная перестановка групп aSRR | 256 | 1,498 |
| WSR из Dense, шаг 500 | 256 | 4,017 |
| Dense | 256 | 0,473 |

Перестановка связей при известной маске и знаках учителя поднимает
ошибку до 1,298. Вариант aSRR в этой постановке использует все
256 связей при 160 активных у учителя. Его ошибка близка к диапазону
ошибок переставленных вариантов от 1,400 до 1,604.
[Парные результаты на четырёх функциях](../../artifacts/asrr_synthetic_random_controls_2026-11-18/relu/results.json).
[Код эксперимента](../../experiments/srr_approx_v1/synthetic_random_controls.py).

Сохранённый WSR оценён на тех же четырёх функциях, с теми же
наблюдениями и численным решателем. После 500 шагов на исходной задаче
WSR объединил 253 из 256 связей одним кодом и выделил по своему коду
для трёх остальных. Точного восстановления в этом случае не получилось.
[Сопоставление с WSR](../../artifacts/asrr_synthetic_random_controls_2026-11-18/wsr/results.json).

## Первая проекция WSR на зашумлённых профилях

В этой серии исходные данные заданы профилями весов. Для каждого
из восьми исходных векторов построили группировку одной проксимальной
проекцией WSR при том же числе кодов. Из восьми группировок выбрали
лучшую по ошибке на development после подгонки новых кодов. На тесте
коды заново обучались прежним ridge-решателем.

| Структура при шуме 0,04 | MSE aSRR | MSE WSR на шаге 0 | MSE случайных групп | Точных WSR |
|---|---:|---:|---:|---:|
| Сбалансированные знаковые группы | 0,00427 | 0,463 | 0,665 | 0/8 |
| Неравномерные знаковые группы | 0,00570 | 0,396 | 0,718 | 0/8 |
| Деформация от задачи к задаче | 0,09634 | 0,559 | 0,951 | 0/8 |
| Общие группы входов | 0,00610 | 0,426 | 0,689 | 0/8 |

На чистых профилях общих групп входов оба метода восстановили 8 из
8 индексаторов с MSE 0,00610. При шуме 0,04 парная разница WSR
минус aSRR составила 0,420 (95% ДИ от 0,173 до 0,666 по восьми
структурам). В знаковых постановках один код aSRR может использоваться
с обоими знаками, тогда как код WSR задаёт равное скалярное значение
всем связям группы. Для общих групп входов оба семейства допускают
истинный индексатор. [Все уровни шума](../../artifacts/asrr_synthetic_random_controls_2026-11-18/wsr/results.json).
[Код сравнения WSR](../../experiments/srr_approx_v1/synthetic_wsr.py).

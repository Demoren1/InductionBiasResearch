# Когда несколько задач позволяют восстановить общую структуру

Дата: 14 ноября 2026. Исследовательское продолжение текущей теории.
Полные доказательства приведены в
[отдельном документе](MULTITASK_COMPLEMENTARITY_PROOFS_2026-11-14.md).
В [основной текст статьи](../sections/theory.tex) включены критерий
согласования частичных отношений и функциональный пример ReLU.
Доказательства, совпадения кодов, разные наблюдаемые маски и точная
граница исправления парных ошибок перенесены в
[теоретическое приложение](../sections/theory_appendix.tex).
Общие оценки по конечному семейству и ошибочным спискам кандидатов
оставлены в этом исследовательском разборе.

**Главный вывод.** Задачам достаточно совместно исключать неверные
структуры; каждая отдельная задача может оставаться неоднозначной.
Если задачи показывают разные части структуры, эти части должны
согласовываться между собой. Для исправления ошибок нужна избыточность
именно в связях между частями, а также преимущество правильного
объяснения над неправильными по частоте подтверждений.

Здесь есть три разных операции. Множества допустимых **полных**
объяснений пересекаются. Надёжные **локальные** ограничения собираются
вместе. Ошибочные ограничения требуют робастного согласования.
Пересечение использованных в каждой задаче связей обычно потеряет
нужные, но временно неиспользуемые части общей структуры.

| Ситуация | Условие | Результат |
|---|---|---|
| У задачи несколько допустимых структур | Каждый неверный кандидат исключается хотя бы одной задачей | Совместная структура однозначна; при случайных задачах есть явная оценка их числа |
| Коды совпадают или не используются в отдельных задачах | Каждая пара разных групп различается хотя бы в одной задаче | Совместные профили восстанавливают группы, даже если ни одна задача отдельно их не определяет |
| Из задачи видна только часть позиций | Собранные равенства и различия имеют единственное продолжение при заданном бюджете кодов | Полная структура восстанавливается из частичных наблюдений |
| Некоторые парные ответы ошибочны | Для двух групп любой разрез графа наблюдений содержит больше удвоенного числа ошибок рёбер | Любые такие ошибки исправимы; условие также необходимо для равномерной гарантии |
| Извлечение структуры случайно ошибается | Правильный кандидат нарушает меньше ограничений в среднем, чем любой неверный | Совместный выбор исправляет ошибки с вероятностью, стремящейся к единице |

## 1. Что именно является общим

Общая структура — разбиение фиксированного множества позиций весов
на sharing-группы. Позиции должны иметь одинаковый смысл между
задачами; для скрытого слоя это включает корректное выравнивание
нейронов. Множество позиций обозначим через E.
Названия групп значения не имеют.

Обозначим истинное разбиение через I, конечное семейство допустимых
разбиений через C, а его размер через N. Истина принадлежит C:

$$
I\in\mathcal C,\qquad N:=|\mathcal C|.
$$

Семейство фиксируется до наблюдения задач. В нём могут быть заданы
бюджет кодов, допустимые маски и другие структурные ограничения.
Все численные параметры, включая значения кодов, выбираются для
каждой задачи заново. Общими значениями весов результаты не пользуются.

**Решающая структура одной задачи** означает структуру, которая может
объяснить её доступную информацию с некоторыми собственными численными
параметрами. Если доступна функция на распределении входов, речь идёт
об объяснении этой функции почти всюду на данном распределении.
Если доступны только веса на части позиций, речь идёт об объяснении
именно этих весов. Нулевой training loss сам по себе не даёт ни одного
из этих утверждений.

Одна задача задаёт множество допустимых глобальных продолжений.
Произвольно выбранное плотное решение обычно даёт только одно
представление из этого множества. Чтобы многозадачное согласование
могло снять неоднозначность, существенные альтернативы нужно сохранить.

## 2. Неоднозначные задачи могут совместно дать единственный ответ

### 2.1. Точное условие и роль разнообразия

Для задачи с номером tau обозначим множество допустимых структур
через C_tau. Пока предполагаем, что извлечение ограничений точно:
оно всегда сохраняет I. Совместимые со всеми задачами структуры образуют

$$
\mathcal C_T:=\bigcap_{\tau=1}^T\mathcal C_\tau.
$$

**Теорема 1: совместное исключение альтернатив.** Структура I
восстанавливается по этим ограничениям тогда и только тогда, когда
для каждого другого кандидата найдётся задача, которая его исключает:

$$
\forall J\in\mathcal C\setminus\{I\}\quad
\exists\tau\le T:\quad J\notin\mathcal C_\tau.
$$

Теперь пусть задачи независимы и одинаково распределены. Для каждого
неверного кандидата обозначим вероятность его исключения одной задачей
через q_J. Если наименьшая из этих вероятностей положительна, положим

$$
q_J:=\Pr\{J\notin\mathcal C_\tau\},\qquad
q:=\min_{J\ne I}q_J>0.
$$

Тогда

$$
\Pr\{\mathcal C_T\ne\{I\}\}
\le\sum_{J\ne I}(1-q_J)^T
\le(N-1)e^{-qT}.
$$

Для N не меньше двух и вероятности неудачи не больше delta достаточно

$$
T\ge\frac{\log((N-1)/\delta)}{q},\qquad 0<\delta<1.
$$

Таким образом, разнообразие здесь означает **вероятность обнаружить
конкретную неверную структуру**. Не требуется, чтобы одна задача
полностью определяла истину. Не требуется и восстановление всего
непрерывного пространства возможных значений кодов.

Если какой-то кандидат никогда не исключается, согласование именно
этих множеств его не устранит. Иная информация, например известное
распределение численных кодов, может добавить ограничения; в данной
теореме такого распределения не предполагается.

Для фиксированного набора задач минимальное достаточное подмножество
также описывается точно. Каждая задача исключает часть неверных
кандидатов; нужно выбрать задачи, чьи исключения вместе покрывают все
альтернативы. Поэтому универсального минимального числа задач только
по числу кодов здесь нет: важно, какие альтернативы они различают.

Если сохранилось несколько объяснений, можно извлечь общую для них
часть: фиксировать только те равенства и различия групп позиций,
которые выполняются во всех сохранившихся кандидатах. При точных
ограничениях эта часть верна и может расти с добавлением задач,
даже пока полное разбиение неоднозначно. Критерий восстановления
конкретной группы через все её допустимые продолжения приведён в
[прежнем разборе, раздел 3.3](MINIMAL_RECOVERY_CONDITIONS_2026-11-14.md).

### 2.2. Полная идентификация не обязательна для переноса

Для любого кандидата J определим q_J тем же способом, включая q_I=0.
Это вероятность, что новая задача из того же окружения окажется
несовместима с кандидатом.

**Следствие 1.** С вероятностью не меньше 1−delta каждый кандидат,
сохранившийся после T независимых задач, удовлетворяет

$$
q_J\le\frac{\log(N/\delta)}{T}.
$$

Можно выбрать любой сохранившийся кандидат. Он может отличаться от
генерирующего индексатора, но редко оказывается несовместим с новой
задачей из того же окружения. Это утверждение о существовании новых
численных решений; точность и стоимость их обучения требуют отдельного
анализа. Если множества C_tau построены только по приближённому
дескриптору, вывод относится к совместимости с этим дескриптором.

### 2.3. Зачем ограничивать сложность структуры

Если разрешено произвольно разделять sharing-группы, более свободная
структура объяснит все задачи истинной: её дополнительные коды можно
положить равными. Тогда положительность всех q_J невозможна.

Поэтому восстановление генерирующих групп требует ограничения класса,
например известного бюджета кодов, или отдельного принципа минимальности.
Минимальность по наблюдаемым задачам может всё ещё объединить две
настоящие группы, если окружение пока не показало их различия.

## 3. Совпадения кодов и неиспользуемые части структуры

### 3.1. Совместные профили вместо структуры одной задачи

Рассмотрим прозрачную модель: наблюдаются сопоставимые численные веса
на всех позициях, и внутри каждой группы они равны. Такая модель
применима после корректной калибровки; в одном нейроне общий положительный
масштаб задачи не меняет используемые ниже отношения равенства.
Обозначим номер группы позиции p через g(p), а численное значение
кода группы j в задаче tau — через c_tau,j. Здесь разрешены совпадения
между кодами и нулевые значения:

$$
w_{\tau,p}=c_{\tau,g(p)}.
$$

В этом разделе допустимы все разбиения позиций в пределах указанного
бюджета, без дополнительных структурных ограничений.

Профиль позиции p — вектор её наблюдений по задачам. Обозначим через Q
разбиение позиций на классы одинаковых профилей:

$$
a_p:=(w_{1,p},\ldots,w_{T,p}),\qquad
p\sim_Q q\ \Longleftrightarrow\ a_p=a_q.
$$

**Теорема 2: восстановление из неоднозначных значений.**

1. Кандидат объясняет все наблюдения ровно тогда, когда каждая его
   группа содержится в одном классе Q.
2. Разбиение Q — единственное объяснение с наименьшим числом групп.
3. Если истина содержит m групп, а кандидаты используют не больше m,
   истина определяется однозначно ровно тогда, когда у любых двух
   истинных групп различаются совместные профили кодов:

$$
\forall j\ne k\quad
\exists\tau\le T:\quad c_{\tau,j}\ne c_{\tau,k}.
$$

Одна задача может объединять несколько истинных групп из-за совпадения
значений. Следующая задача разделяет другие пары. Совместное разбиение
получается пересечением отношений равенства отдельных задач.
Случайные ошибки в эти равенства пока не входят; они рассматриваются ниже.

**Пример: две неоднозначные задачи.** Пусть имеются четыре непустые
истинные группы. Их значения в двух задачах таковы:

| Группа | Задача 1 | Задача 2 |
|---|---:|---:|
| A | 1 | 1 |
| B | 1 | 2 |
| C | 2 | 1 |
| D | 2 | 2 |

Каждая задача отдельно допускает объяснение всего двумя группами.
Совместно нужны четыре, и при бюджете не больше четырёх истинные
группы восстанавливаются однозначно. Численные значения между задачами
не переносятся: используются отношения между позициями.

Для нескольких нейронов их неизвестные отдельные масштабы мешают
непосредственно сравнивать такие профили. Этот результат нельзя
применять к сырым плотным весам разных нейронов без калибровки.
Расширение текущей модели ReLU без такого сравнения дано в разделе 7.

### 3.2. Не все группы должны использоваться в каждой задаче

Предположим, что задача использует ровно одну из m групп: её код равен
единице, остальные равны нулю. Глобальное множество позиций известно,
включая позиции неиспользуемых в этой задаче групп. Тогда совместные
профили различаются ровно тогда, когда **не более одной группы ни разу
не использовалось**. У двух никогда не использованных групп одинаковый
нулевой профиль; одна оставшаяся группа неоднозначности не создаёт.

Если задачи независимо и равновероятно выбирают одну из групп, для m
не меньше двух теорема 2 даёт

$$
\Pr\{\text{истина не определена при бюджете }m\}
\le\binom m2\left(1-\frac2m\right)^T
\le\binom m2 e^{-2T/m}.
$$

Здесь каждая отдельная задача показывает лишь одну используемую часть,
а остальные группы различаются благодаря другим задачам. Условие
«всякая группа встретилась» достаточно, но сильнее необходимого:
в этой модели важно разделить каждую пару групп.

В этом примере ноль — наблюдаемое значение, а не пропуск измерения.
Если позиция вообще недоступна, ей нельзя приписать нулевой вес.
Если неизвестно и глобальное множество активных связей, неиспользуемую
связь дополнительно нужно отличать от структурного нуля.

## 4. Восстановление из разных видимых частей

### 4.1. Точный критерий через парные ограничения

Теперь задачи могут наблюдать разные подмножества позиций.
Предположим, что из них надёжно извлечены два вида ограничений:
пары, обязанные принадлежать одной группе, и пары, обязанные принадлежать
разным группам. Обозначим их множества через P и D соответственно.
Отсутствие ограничения означает отсутствие информации.

Соединим пары из P и объединим каждую связную компоненту в один блок.
Построим граф H на этих блоках: ребро означает, что какая-то пара
из D запрещает объединять соответствующие блоки. Если запрещённая
пара оказалась внутри блока, ограничения противоречат друг другу.

**Теорема 3: согласование частичных структур.** Непротиворечивые
глобальные разбиения с не более чем m группами находятся во взаимно
однозначном соответствии с правильными раскрасками H в не более чем m
цветов, с точностью до переименования цветов. Следовательно,
структура определяется ровно тогда, когда такая раскраска единственна.

Это точный критерий **для информации в данных парных ограничениях**.
Дополнительные ограничения на циклы весов или функции могут дальше
сократить множество раскрасок.

Из критерия следуют простые достаточные условия.

- Для бюджета в два кода и хотя бы двух блоков правильная раскраска
  единственна ровно тогда, когда H связен. Предполагается, что
  ограничения выполнимы, то есть H двудолен.
- Для общего m достаточно иметь m попарно конфликтующих опорных
  блоков. Если каждый оставшийся блок конфликтует с опорами всех
  цветов, кроме одного, его группа также определена.
- Если подтверждённые равенства уже связали каждую истинную группу
  в один блок, а число групп известно **точно**, эти блоки и есть
  ответ. При одном лишь верхнем бюджете нужно также запретить
  объединять разные блоки.

Таким образом, локальные части можно согласовать даже без прямого
наблюдения равенства между всеми позициями одной истинной группы.
Иногда группу определяют именно её различия с другими группами.

### 4.2. Пример непосредственно на функциях ReLU

Есть четыре входные координаты и один ReLU-нейрон с нулевым bias
и единичным выходным коэффициентом. Структура задаёт не больше двух
положительных кодов первого слоя; значения кодов для задач свои.
Через e_p обозначим p-й координатный вектор. Функция задачи имеет вид

$$
f_\tau(x)=\operatorname{ReLU}
   \left(\sum_{p=1}^4c_{\tau,g(p)}x_p\right).
$$

Задача с номером tau, от одного до трёх, имеет входы только на двух
координатных векторах с положительными вероятностями. Её известные
значения равны

$$
f_\tau(e_\tau)=1,\qquad
f_\tau(e_{\tau+1})=2,\qquad \tau=1,2,3.
$$

Каждая задача устанавливает только различие двух соседних позиций.
Остальные веса на её распределении входов не наблюдаемы. Получается
путь из четырёх вершин, единственная двуцветная разбивка которого равна

$$
I=\bigl\{\{1,3\},\{2,4\}\bigr\}.
$$

Это полное совместное восстановление по функциям на их распределениях
входов. Ни одна из трёх задач отдельно не определяет I.
Только первая и третья также не достаточны: между двумя видимыми
частями остаётся неопределённое соответствие групп. Средняя задача
устраняет именно эту неоднозначность.

Пример использует маленькую известную архитектуру; он не предполагает
идентифицируемость произвольной многонейронной ReLU-сети по функции.

### 4.3. Покрыть все позиции недостаточно

При трёх кодах связный путь из четырёх позиций допускает, например,
два разных разбиения на три группы:

$$
\bigl\{\{1,3\},\{2\},\{4\}\bigr\},\qquad
\bigl\{\{1\},\{2,4\},\{3\}\bigr\}.
$$

Оба соблюдают все соседние различия. Значит, покрытие позиций и
связность наблюдений сами по себе не являются общим условием
идентифицируемости. Для двух кодов связность точна; для большего
бюджета её заменяет единственность допустимого продолжения.

## 5. Когда другие задачи исправляют ошибки

### 5.1. Точная граница для двух sharing-групп

Рассмотрим бюджет не больше двух кодов. Каждая задача сообщает один
парный ответ: относятся ли две наблюдаемые позиции к одной группе.
Это уже извлечённое структурное наблюдение. Оно должно быть обосновано
моделью измерения; случайное совпадение двух численных кодов не
сертифицирует равенство их групп.

Например, для одного ReLU-нейрона с нулевым bias и единичным
выходным коэффициентом такой ответ извлекается из значений функции
на двух базисных входах, если разные коды в этой задаче разделены
зазором. При известной верхней границе ошибки каждого значения
и зазоре больше четырёх таких ошибок порог в две ошибки безошибочно
разделяет равенство и различие. Задачи, где этот контроль нарушен,
могут давать ошибочные парные ответы. Коды здесь положительны.

Построим мультиграф G: вершины — позиции, каждое парное наблюдение —
ребро. Повторные наблюдения одной пары сохраняются как отдельные рёбра.
Пусть не больше s ответов могут быть произвольно ошибочными.
Множество рёбер с учётом повторов обозначим через E(G), а через
lambda(G) — минимальное число рёбер между непустой частью вершин
и её непустым дополнением:

$$
\lambda(G):=
\min_{\varnothing\ne A\subsetneq\mathcal E}
\bigl|\{e\in E(G):e\text{ соединяет }A
                         \text{ с }\mathcal E\setminus A\}\bigr|.
$$

В множестве позиций предполагается хотя бы два элемента.

**Теорема 4: исправление ошибок через разрезы.** Любое разбиение
на не более чем две группы можно однозначно восстановить при любых
не более s ошибочных парных ответах тогда и только тогда, когда

$$
\lambda(G)\ge 2s+1.
$$

Достаточно выбрать разбиение, нарушающее наименьшее число ответов.
Теорема характеризует возможность восстановления; она не утверждает,
что этот минимум во всех постановках легко вычислить.

Без ошибок условие превращается в связность. Если между двумя
крупными частями есть единственный мост, одна ошибка на мосту
меняет соответствие групп целой части. Сколько угодно дополнительных
задач внутри этих частей этого не исправит.

Для простого достаточного плана наблюдений можно взять любое
остовное дерево и получить по 2s+1 парных ответов на каждом ребре.
Тогда любые s ошибочных ответов во всём наборе исправимы.
Большинство само по себе не является источником гарантии:
важно, чтобы повторения защищали каждый возможный разрыв структуры.

Когда одна задача даёт сразу много ответов и целиком может быть
испорчена, s нужно считать в задачах, а расстояние — в различающихся
задачах. Точный общий критерий такого случая дан в доказательствах,
раздел 5. Простая подстановка числа плохих задач вместо числа плохих
рёбер в условие выше необоснованна.

### 5.2. Случайные ошибки: правильное объяснение должно выигрывать в среднем

Пусть теперь каждая задача возвращает неточное множество кандидатов.
Обозначим через D_tau(J) индикатор исключения кандидата J:

$$
D_\tau(J):=\mathbf 1\{J\notin\widehat{\mathcal C}_\tau\}.
$$

Пусть задачи независимы, а средняя вероятность исключить истину
не больше alpha. Средняя вероятность исключить любого неверного
кандидата должна быть не меньше beta, причём beta больше alpha:

$$
\begin{aligned}
\frac1T\sum_{\tau=1}^T\mathbb E D_\tau(I)&\le\alpha,\\
\min_{J\ne I}\frac1T\sum_{\tau=1}^T\mathbb E D_\tau(J)&\ge\beta,
\qquad \beta>\alpha.
\end{aligned}
$$

Одинаковое распределение задач здесь не требуется. Одна задача может
совсем не различать некоторые альтернативы, если их различают другие.

**Теорема 5: восстановление при неточном извлечении.** Выберем
кандидата, исключённого наименьшим числом задач. Тогда

$$
\Pr\{\widehat I\ne I\}
\le (N-1)
   \exp\left(-\frac{T(\beta-\alpha)^2}{2}\right).
$$

Зависимость ошибок разных позиций одной задачи допускается.
Нужна независимость между задачами и положительный разрыв в
средней совместимости. Для условной версии после построения банка
необходимо проверить эти условия условно на построенный банк.

Полезная специализация связывает этот результат с теоремой 1.
Пусть точный список сохранял истину и исключал каждого неверного
кандидата с вероятностью хотя бы q. Если полученный список отличается
от точного с вероятностью не больше epsilon, то допустимы

$$
\alpha=\epsilon,\qquad
\beta=q-\epsilon,\qquad
\beta-\alpha\ge q-2\epsilon.
$$

Поэтому достаточно **q больше удвоенной вероятности ошибки извлечения**.
Редкая информативность задач может оказаться слабее даже небольшого
шума. Увеличение числа задач тогда само по себе не даёт гарантии.
При одних этих предположениях запас точен: если вероятность
произвольной ошибки списка допускает q/2, два разных истинных
кандидата могут давать одинаковое распределение извлечённых списков.
Конструкция дана в доказательствах, раздел 6.3.

Жёсткое пересечение ошибочных списков особенно неудачно: если
независимое извлечение исключает истину с фиксированной положительной
вероятностью, вероятность сохранить её во всех списках стремится
к нулю. Подсчёт нарушений сохраняет возможность исправления.

### 5.3. Более простой вариант для частичных парных ответов

Пусть заранее выбран набор из M парных сравнений, достаточный для
единственного продолжения в смысле теоремы 3. Каждая нужная пара
наблюдается не меньше n раз по фиксированному плану. Её ответы
независимы между задачами и каждый ошибается с вероятностью не
больше eta, меньшей половины. Внутри задачи зависимости допускаются.

Большинство по каждой паре и последующее точное согласование
восстанавливают структуру с вероятностью ошибки не больше

$$
M\exp\left(-2n(1/2-\eta)^2\right).
$$

Не нужно сравнивать все пары позиций: достаточно набора,
однозначно определяющего структуру. Если некоторые задачи только
неинформативны, их следует считать пропусками, а не голосами за
равенство. Иначе условие ошибки меньше половины может не выполняться:
например, две разные группы могут почти всегда одновременно не
использоваться и иметь одинаковое наблюдаемое нулевое значение.

## 6. Какие предположения здесь разумны и что действительно необходимо

1. **Существует общий объясняющий механизм.** Одно допустимое
   разбиение объясняет задачи с собственными численными параметрами.
   Для задач с посторонними механизмами нужна явная модель выбросов
   или частично общей структуры.
2. **Задачи показывают разные различия.** Каждая интересующая
   альтернатива должна иногда противоречить наблюдениям. Просто
   разные значения loss или названия классов этого не обеспечивают.
3. **Видимые части можно сопоставить.** Координаты, нейроны или
   локальные блоки имеют общий смысл, либо их соответствие включено
   в множество гипотез. Пропуски не заменяются произвольным решением.
4. **Ограничена свобода объяснения.** Иначе более свободные
   структуры всегда воспроизводят задачи истинной структуры.
   Конкретное ограничение должно следовать из постановки.
5. **Есть запас над ошибками.** В статистической модели правильное
   объяснение лучше в среднем; для произвольных ошибок каждое
   альтернативное объяснение отличается на достаточно многих
   наблюдениях. Одна лишь независимость ошибок не заменяет этот запас.

Условие полного покрытия всех частей сильнее нужного в одних моделях
и слабее нужного в других. Подходящее общее требование — **совместная
различимость допустимых объяснений**, а для частичных данных ещё и
возможность согласовать их в единой системе позиций.

## 7. Прямое расширение текущей модели ReLU

### 7.1. Разные наблюдаемые маски

Сохраним общие позиции и выровненные нейроны текущей статьи, но
разрешим задаче видеть только известное множество позиций O_tau.
Это должны быть ненулевые, действительно наблюдаемые веса.
Обозначим принимающий нейрон позиции p через h(p). Модель на
наблюдаемой части остаётся прежней:

$$
r_{\tau,p}=
\frac{\sigma_p c_{\tau,g(p)}}{s_{\tau,h(p)}},
\qquad p\in O_\tau,\quad
s_{\tau,h}>0,\quad \sigma_p\in\{-1,1\}.
$$

Для каждой задачи оператор Pi_tau вычитает среднее **только по
наблюдаемым позициям каждого нейрона**. Нейрон с одной наблюдаемой
позицией не даёт контраста. Для кандидата J определим его номер
группы g_J, число групп m_J и пространство

$$
\begin{aligned}
y_\tau&:=\Pi_\tau\log|r_{\tau,O_\tau}|,\\
\mathcal S_{\tau,J}
&:=\left\{\Pi_\tau(u_{g_J(p)})_{p\in O_\tau}:
                              u\in\mathbb R^{m_J}\right\}.
\end{aligned}
$$

**Утверждение 6: совместная различимость при пропусках.** Кандидат
объясняет все наблюдаемые модули ровно тогда, когда

$$
y_\tau\in\mathcal S_{\tau,J}
\qquad\text{для всех }\tau.
$$

Предположим дополнительно, что условно на маски и наблюдаемые знаки
каждый истинный y_tau имеет плотность на своём пространстве
S_tau,I. Тогда с вероятностью один модульно совместимы ровно кандидаты
с включениями

$$
\mathcal S_{\tau,I}\subseteq\mathcal S_{\tau,J}
\qquad\text{для всех }\tau.
$$

Независимость между задачами для этого утверждения не требуется.
Вместо одного полного наблюдаемого пространства получаем набор
разных наблюдаемых частей. Каждого неверного кандидата может исключать
своя задача. Это непосредственное расширение прежней теоремы, которое
сохраняет задачно-зависимые положительные масштабы нейронов.

### 7.2. Знаки без общей полностью наблюдаемой задачи

Для каждой группы кандидата J построим двудольный граф: с одной
стороны её позиции, с другой — задачи, в которых они наблюдаются.
Ребро несёт знак наблюдаемого веса.

**Утверждение 7.** Наблюдаемые знаки допускают фиксированные знаки
позиций и свои знаки кодов в каждой задаче тогда и только тогда,
когда произведение знаков рёбер любого цикла каждого такого графа
равно +1. Вместе с утверждением 6 это полный точный критерий
совместимости частично наблюдаемых signed-весов.

При полных масках достаточно циклов длины четыре: получается
условие совпадения нормированных знаковых профилей из текущей статьи.
При пропусках первая задача уже не обязана видеть все позиции,
а равенства знаков передаются по цепочкам перекрытий.

Если группа известна, относительные фиксированные знаки всех её
позиций определены ровно тогда, когда эти позиции лежат в одной
связной компоненте её двудольного графа наблюдений. Разные компоненты
можно независимо переворачивать, не меняя наблюдений.

Эти критерии условны на правильные маски, соответствие нейронов и
модель весов. Они не доказывают, что произвольный dense-решатель
извлекает именно такие представления. Для нулевых кодов логарифмы
на соответствующих позициях не определены: такие позиции требуют
отдельной модели нулей или маски, а не численного floor в доказательстве.

## 8. Что следует изменить в теоретическом и алгоритмическом акценте

**Распределение в статье после редакции 14 ноября.** Основной текст
содержит критерий продолжения частичных отношений и пример, где
три задачи ReLU совместно определяют группы. В приложение вошли
доказательства, более общая модель наблюдаемых масок, совпадения
кодов и точная граница исправления ошибок для двух групп. Теоремы
об исключении конечного семейства, ошибочных списках и запасе
q больше двух epsilon остаются здесь: они полезны для постановки,
но требуют отдельной модели извлечения и во многом повторяют
общие аргументы выбора и концентрации из прежней теории.

Для многозадачного обоснования наиболее содержательны **частичная
наблюдаемость и согласование неоднозначных объяснений**. Они дают
примеры, где отдельная задача принципиально недостаточна, а задачи
вместе достаточны. Ошибки добавляют вопрос об избыточности наблюдений.
Это дополняет прежнюю теорему об одной точной задаче общего положения:
её условие полной наблюдаемости здесь целенаправленно ослаблено.
Примеры с совпадающими кодами, в свою очередь, ослабляют предположение
об общем положении численных значений одной задачи.

Сильнейший конкретный результат этого разбора — точная граница через
разрезы для двух групп. Для произвольного числа групп точный ответ
через единственность раскраски сохраняется, но простой универсальной
замены ему здесь не установлено. Вероятностные оценки исключения
кандидатов и подсчёта нарушений дают общий слой над этими моделями.

Из результатов следует небольшой вариант текущей стратегии:

1. Хранить наблюдаемые позиции и допустимые продолжения, включая
   альтернативные представления задачи.
2. Собирать подтверждённые локальные отношения с учётом калибровки;
   недоступные и неиспользуемые части отмечать отдельно.
3. При неточном извлечении выбирать по числу или весу нарушений,
   сохраняя несколько близких объяснений.
4. Направлять дополнительные наблюдения на неоднозначные связи
   между частями, а не только на уже хорошо согласованные части.
5. Проверять полученную структуру новым fit численных параметров.
   Для гарантии на новые задачи нужны задачи того же окружения
   либо отдельное условие, связывающее source и target.

Это теоретически обоснованное направление модификации, а не уже
доказанная гарантия текущего G34. Для ограниченного банка остаётся
необходимым сохранить правильное продолжение. Если банк построен
по тем же задачам, нельзя без дополнительного аргумента заменить
размер исходного класса N его меньшим итоговым размером в оценках.

## 9. Связь с известными результатами

Общие вероятностные оценки используют стандартное исключение
гипотез, концентрацию ограниченных величин и исправление ошибок
по минимальному расстоянию. Их смысл здесь — явно отделить
неоднозначность одной задачи, пропуски и ошибки. Заявление о
приоритетной новизне этих общих принципов не делается.

- [Baxter, *A Model of Inductive Bias Learning*](https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume12/baxter00a.pdf)
  рассматривает обучение пространства гипотез по окружению задач
  и перенос на новые задачи из этого окружения. Это общий контекст
  следствия 1, а не готовая теорема восстановления наших групп.
- [Tripuraneni, Jordan, Jin, *On the Theory of Transfer Learning:
  The Importance of Task Diversity*](https://proceedings.neurips.cc/paper/2020/file/59587bffec1c7846f3e34230141556ae-Paper.pdf)
  связывают разнообразие source-задач с качеством представления
  для target-задач; определение 3 сравнивает среднюю source-ошибку
  представления с его ошибкой для будущих задач. Здесь используется
  более узкая дискретная характеристика: исключение альтернативных
  sharing-структур.
- [Strehl, Ghosh, *Cluster Ensembles — A Knowledge Reuse Framework
  for Combining Multiple Partitions*](https://jmlr.org/papers/v3/strehl02a.html)
  рассматривают объединение разных кластеризаций, в том числе
  полученных на разных наборах объектов. Наша постановка требует
  отдельно учитывать, что локальное объединение может означать
  совпадение кодов или отсутствие наблюдения, а не равенство
  генерирующих групп.
- [Davidson, Ravi, *The Complexity of Non-Hierarchical Clustering
  With Instance and Cluster Level Constraints*](https://web.cs.ucdavis.edu/~davidson/Publications/TRDAMI.pdf)
  изучают ограничения совместного и раздельного включения объектов
  в кластеры. Представление частичной структуры через такие
  ограничения и раскраску относится к известной комбинаторной
  постановке; его точная специализация доказана здесь.
- [Abbe, Bandeira, Bracher, Singer, *Decoding Binary Node Labels
  from Censored Edge Measurements*](https://arxiv.org/abs/1404.4749)
  изучают бинарные метки по зашумлённым относительным измерениям
  на рёбрах. Теорема 4 использует ту же бинарную структуру измерений
  и элементарное условие исправления произвольных ошибок через
  минимальный разрез. Стохастические пороги и алгоритмические
  гарантии этой работы на наш этап извлечения не переносятся.

Полные доказательства всех сформулированных здесь утверждений,
включая необходимые ограничения и критерий ошибок целых задач:
[MULTITASK_COMPLEMENTARITY_PROOFS_2026-11-14.md](MULTITASK_COMPLEMENTARITY_PROOFS_2026-11-14.md).

# Проверка переноса групп на свёртке, WISDM и Aug-Omniglot

На новых задачах заново обучали все численные параметры. Для каждого датасета выделили исходные задачи для построения банка и отдельные валидационные задачи для выбора разбиения и численного режима. Основной контроль сохраняет маску, знаки и число назначений каждого кода, меняя конкретные связи. При свободных весах каждый разрешённый вес первого слоя обучается независимо. В 1D это Dense на найденной маске, в WISDM — слой с независимыми весами внутри каждого временного участка, в Aug-Omniglot — полносвязная Dense. Для классификации отдельно подбирали численный режим каждой модели, включая контроль из четырёх перестановок. Сетка включала 25, 75, 150 и 300 шагов Adam и две скорости обучения, 0,003 и 0,01. [План опыта](../../experiments/asrr_benchmark_families_v1/plan.json)

## Группы, согласованные между исходными задачами

У двух позиций первого слоя есть профили весов по исходным задачам. После выравнивания в нелинейных моделях разбиваем задачи на две части. Для каждого относительного знака измеряем ошибку равенства весов по обеим частям.

$$
\begin{aligned}
d(p,q)&=
\min_{s\in\{-1,1\}}\max_{b\in\{1,2\}}
\left(1-\frac{2s\langle z_{p,b},z_{q,b}\rangle}
                  {\max\{\|z_{p,b}\|^2+\|z_{q,b}\|^2,10^{-15}\}}\right).
\end{aligned}
$$

Для входных разбиений складываем в профиль веса по задачам и нейронам блока, знак фиксируем положительным. Используем полную связь при иерархической кластеризации. Порог ограничивает попарное расхождение внутри группы при лучшем относительном знаке каждой пары. Если для позиции надёжной пары нет, она сохраняет собственный код. Размер итогового разбиения определяется порогом, который выбираем по переносу на валидационных задачах. Обычный Ward выбирает разрез с заданным числом групп из отдельной сетки. В линейной задаче выходные позиции известны, поэтому выравнивание и нормировка по нейронам не нужны. [Реализация](../../experiments/asrr_benchmark_families_v1/groups.py)

Разрез по порогу восстанавливает истинное разбиение, если все расстояния внутри истинных групп не превышают порог, а все расстояния между группами его превышают. Действительно, расстояние между двумя кластерами для полной связи равно наибольшему расстоянию между их элементами. Поэтому до достижения порога алгоритм объединяет только части одной истинной группы и успевает объединить каждую такую группу целиком. Это объясняет, почему можно оставлять отдельные веса свободными без задания числа групп. Условие относится к разбиению по наблюдаемым профилям.

## 1D-кросс-корреляция

На полностью общей свёртке три коэффициента используются в 68 местах, каждому смещению фильтра соответствует одна группа. В частичной свёртке у каждого из трёх смещений 17 из 68 мест получают индивидуальные коэффициенты. Позиции с индивидуальными весами фиксируются для всей серии, а все численные значения заново генерируются для каждой функции. Входы гауссовские, на исходных ответах добавлен шум со стандартным отклонением 0,05. В каждом режиме 96 исходных функций по 96 примеров, 48 функций для подбора и 160 новых функций для теста. Выходы наблюдаемы одновременно. Геометрия в каждом режиме одна, поэтому интервалы характеризуют перенос на новые функции при этой геометрии. [Генератор и численная подгонка](../../experiments/asrr_benchmark_families_v1/linear.py)

На исходных задачах маски строятся по средней энергии оценённых полных весов, порог входит в валидационный выбор. На новых задачах обучаем числа методом гребневой регрессии. Для MSR заново обучили непрерывную матрицу исходным алгоритмом на тех же функциях и отбрасываем начальные числа и скорости адаптации. Для сравнения с Yeh используем адаптацию их идеи на те же задачи. Обучаем положительные назначения на маске из исходных оценок, дифференцируем через решаемую точно гребневую регрессию и выбираем на валидации между мягким и дискретным разбиениями. Параметры обеих базовых схем подобраны на тех же валидационных функциях. [MSR, §5.1](https://arxiv.org/pdf/2007.02933#page=6) · [Yeh, §5.3](https://proceedings.mlr.press/v151/yeh22b/yeh22b.pdf#page=8) · [Протокол адаптации Yeh](../../artifacts/asrr_benchmark_families_2026-11-19/linear/yeh_protocol.json)

| Геометрия, один опорный пример | aSRR с порогом | Ward aSRR | MSR, свежие коэффициенты | Yeh, свежие коэффициенты | Та же маска, свободные веса | Перестановка | Dense | Эталон |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Точная свёртка, MSE | ≈0 | ≈0 | 0,00154 | ≈0 | 1,924 | 1,951 | 2,838 | ≈0 |
| Частичная свёртка, MSE | **0,1553** | **0,1553** | 0,8514 | 0,4174 | 1,8893 | 2,1798 | 2,8022 | **0,1553** |

В частичной свёртке выбранный вариант с порогом восстановил 3 825 из 3 825 знаковых равенств без лишних связей и правильно оставил 51 вес независимым. С одним опорным примером тот же ответ нашёл обычный Ward с числом кодов, подобранным на валидации. Парный выигрыш варианта с порогом над моделью с той же маской и свободными весами составил 1,734 MSE (95% ДИ от 1,585 до 1,883). При пяти примерах вариант с порогом также восстановил все связи. Ward выбрал 102 кода и сохранил 194 общие связи. При этом пяти примеров достаточно для определения трёх активных весов каждого выхода, поэтому модель со свободными весами на точной маске тоже достигает численного нуля. ## WISDM

Используем три оси акселерометра часов и модуль ускорения для 18 активностей. Переходим к общей частоте 20 Гц внутри непрерывной записи одной активности, затем выделяем неперекрывающиеся окна по 64 отсчёта. Для новой задачи первые 40% окон образуют опорный пул, последние 50% образуют проверочный пул. Пять участников с менее чем 24 окнами хотя бы в одном классе исключены до обучения. Осталось 27 участников для извлечения структуры, 7 для подбора, 12 для теста. На тесте у каждого участника 32 эпизода. В запросах каждого эпизода все классы представлены одинаково. Входы стандартизованы по опорному пулу исходных участников. Все 51 файл акселерометра из зеркала побайтово совпали с официальным архивом. [WISDM, UCI](https://archive.ics.uci.edu/dataset/507/wisdm%2Bsmartphone%2Band%2Bsmartwatch%2Bactivity%2Band%2Bbiometrics%2Bdataset) · [Распределение участников](../../artifacts/asrr_benchmark_families_2026-11-19/wisdm/panel_registration.json) · [SHA-256 файлов](../../artifacts/asrr_benchmark_families_2026-11-19/wisdm/official_file_audit.json)

Основная метрика — средняя точность на пяти опорных примерах на класс. Доверительные интервалы строятся по парным различиям, усреднённым внутри участника.

## Aug-Omniglot

Эпизоды состоят из пяти разных символов. Исходные, валидационные и тестовые символы отделены. В каждой исходной задаче Dense видит пять чистых и десять преобразованных рисунков каждого символа, ещё пять преобразованных рисунков используются для выбора численных параметров. На новых задачах опорные изображения чистые. На 15 оставшихся рисунках каждого класса оцениваем две версии запросов, чистую и преобразованную. Преобразования следуют протоколу MSR и включают случайную обрезку с масштабированием, отражения и повороты до 30 градусов. Используем 48 исходных задач, 192 задачи для выбора и 768 тестовых. [MSR, §6 и приложение D.3](https://arxiv.org/pdf/2007.02933#page=8) · [Панели Omniglot](../../artifacts/asrr_benchmark_families_2026-11-19/aug_omniglot/panel_registration.json)

У всех моделей один полносвязный скрытый слой из 64 ReLU. Сравниваем входные разбиения, общие для всего слоя или отдельные для четырёх блоков нейронов. Ward рассматривает 2 048, 4 096 и 8 192 кодов, а вариант с порогом рассматривает пороги 0,18, 0,40 и 0,65, включая разбиение, оставляющее все веса свободными. Для каждого числа примеров на класс выбор разбиения и численного режима зависит только от точности на преобразованных запросах валидации. На тесте чистая версия даёт парное сравнение чувствительности к аугментациям при неизменном обучении.

Для обоих бюджетов валидация выбрала одно разбиение с порогом 0,65 и четырёхблочный Ward по 32 входные группы в каждом блоке. Первый вариант даёт 23 360 кодов, второй — 2 048. Для варианта с порогом совпадает группа у 31,3% соседних по стороне пикселей, размер каждой группы не превышает шести. У Ward доля соседних пар в общей группе в среднем по четырём блокам составляет 75,3%. Ожидания при перестановках тех же размеров составляют 0,2% и 3,6% соответственно. На карте серым показаны одиночные пиксели. Карта Ward иллюстрирует первый из четырёх блоков. ## MSR на тех же эпизодах

Для WISDM и Aug-Omniglot обучили адаптацию MSR с факторами Кронекера в первом слое. Использовали те же исходные записи и рисунки, ту же ширину и маску связей, те же эпизоды выбора и теста. На исходных задачах базис, численная инициализация и скорости SGD обучались совместно, с дифференцированием через один внутренний шаг. В Aug-Omniglot внутренний шаг использовал чистые исходные рисунки, а внешний — преобразованные. Подбирали ранг и число блоков из шести конфигураций на набор, включая полноранговую. На тех же валидационных эпизодах независимо выбрали численный режим для переноса только базиса и для переноса базиса вместе с инициализацией. В первом случае все численные параметры обучались с нуля по той же сетке Adam, что для aSRR. Во втором использовались исходные начальные значения всех численных параметров и обученные скорости SGD.

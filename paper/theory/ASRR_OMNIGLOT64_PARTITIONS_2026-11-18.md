# Четыре и восемь разбиений aSRR на широком Omniglot

18 ноября 2026 года.

## Зафиксированный результат

Для следующих сравнений используем aSRR с четырьмя разбиениями. Сеть
784–64–5, 16 сохранённых Dense-моделей и бюджет 4096 кодов совпадают во
всех сравнениях. Каждый нейрон использует 64 кода. Внутри блока
нейроны используют одно разбиение пикселей, построенное k-means по
профилям весов этого блока. Варианты с четырьмя и восемью разбиениями
содержат соответственно 16 и 8 нейронов в блоке.

Оценки ниже получены на одних и тех же 1024 эпизодах подтверждающего
прогона. На каждом эпизоде коды и остальные численные параметры
обучались с нуля по общему правилу с 24 стартами, 500 обновлениями
и ансамблем из четырёх выбранных решений. Интервалы условны на
фиксированном пуле тестовых символов. Восемь разбиений проверили
на этих эпизодах после первого подтверждения четырёх.
[Подтверждающий прогон](../../artifacts/omniglot64_asrr_confirmation_2026-11-18/results.json).
[Добавление восьми разбиений](../../artifacts/omniglot64_asrr_eight_partitions_2026-11-18/results.json).

| Метод | Точность, % (95% ДИ) | Кросс-энтропия |
|---|---:|---:|
| aSRR, одно разбиение k-means | 84,03 ± 0,50 | 0,5102 |
| aSRR, четыре разбиения | 84,56 ± 0,49 | 0,4960 |
| aSRR, восемь разбиений | 84,55 ± 0,49 | 0,4959 |
| WSR | 85,29 ± 0,50 | 0,4673 |

Четыре разбиения опережают одно на 0,53 п.п. (парный 95% ДИ от +0,23
до +0,83). На первой когорте из 1024 эпизодов выигрыш составлял 0,52 п.п.
Добавление ещё четырёх разбиений дало −0,01 п.п. (от −0,26 до +0,23).
Отставание от WSR составляет 0,73 п.п. для четырёх разбиений
(от 0,37 до 1,09) и 0,74 п.п. для восьми (от 0,40 до 1,08).
Ранг совместных сумм по группам пикселей вырос с 253 до 486 при
переходе от четырёх разбиений к восьми.

## Как распределены 4096 кодов

У aSRR с четырьмя и восемью разбиениями каждый код закреплён за одним
нейроном. Выбранный WSR объединяет
45 911 из 50 176 связей во всех 64 нейронах одним общим кодом,
а 3950 связей получают собственные коды. Вне крупнейшей
группы остаются 4265 связей. Первый слой можно записать как один
общий коэффициент при сумме всех входов и поправки к весам на
этих 4265 позициях.

| Индексатор | Коды для отдельных связей | Связи в крупнейшей группе | Коды, общие для нескольких нейронов |
|---|---:|---:|---:|
| aSRR, четыре разбиения | 96 | 203 | 0 |
| aSRR, восемь разбиений | 112 | 146 | 0 |
| WSR, проекция готовых Dense-весов | 3392 | 44 971 | 696 |
| WSR, выбранный шаг 75 | 3950 | 45 911 | 144 |

У выбранной исходной задачи WSR крупнейшая группа покрывает 89,6%
связей уже после первой проксимальной проекции весов, до обновлений
по меткам. После 75 шагов доля составляет 91,5%. Все 4265 исключений
на шаге 75 уже были среди 5205 исключений первой проекции.
[Диагностика сохранённых индексаторов и шага 0](../../artifacts/omniglot64_asrr_eight_partitions_2026-11-18/allocation_diagnostics.json).

## Проверка дообучения WSR и выбора отдельных связей

Для WSR сравнили первую проксимальную проекцию на шаге 0 и выбранную
группировку после 75 обновлений по меткам. Обе начинаются с одного
Dense-фита исходной задачи 104. У двух вариантов aSRR один общий
код покрывает 46 081 связь, остальные 4095 связей получают по одному
коду. Профильный вариант выбирает связи с наибольшим средним
квадратом отклонения от медианы нормализованных весов внутри каждой
из 16 задач. Случайный контроль выбирает столько же связей у каждого
нейрона равномерно без возвращения. Использована одна зафиксированная
случайная маска.

Все пять вариантов сравнили на тех же 1024 эпизодах подтверждающего
прогона при 4096 кодах, одинаковых численных стартах и обучении кодов
с нуля. Для WSR на шаге 75 и для четырёх разбиений использованы
сохранённые предсказания.

| Метод | Точность, % (95% ДИ) | Кросс-энтропия |
|---|---:|---:|
| aSRR, четыре разбиения | 84,56 ± 0,49 | 0,4960 |
| WSR, шаг 0 | 85,09 ± 0,51 | 0,4692 |
| WSR, шаг 75 | 85,29 ± 0,50 | 0,4673 |
| Один общий код, исключения по профилям | 81,46 ± 0,55 | 0,5658 |
| Один общий код, случайные исключения | 85,09 ± 0,51 | 0,4614 |

Шаг 75 выигрывает у шага 0 на 0,20 п.п. (парный 95% ДИ от −0,06
до +0,46). Уже шаг 0 опережает четыре разбиения на 0,53 п.п.
(от +0,17 до +0,88). Случайная маска выигрывает у четырёх разбиений
на 0,52 п.п. (от +0,15 до +0,90), а разница с WSR на шаге 75
составляет −0,20 п.п. (от −0,47 до +0,07).

Случайная маска опережает профильную на 3,63 п.п. (от +3,24 до
+4,02). Исключения по профилям охватывают 389 из 784 пикселей, а
случайные исключения — 783. Для каждого из остальных пикселей
любая связь использует общий код, поэтому эти пиксели входят
в модель только через их сумму. Разница в охвате даёт гипотезу
о причине проигрыша профильного отбора.
[Парные результаты](../../artifacts/omniglot64_allocation_ablation_2026-11-18/results.json).
[Построение индексаторов](../../experiments/omniglot64_v1/allocation_ablation.py).

Предыдущий вариант с 2048 кодами для групп пикселей и 2048 кодами для
отдельных связей получил 83,43% против 83,88% у одного разбиения k-means
на первой когорте. Уточнение по воспроизведению
активаций Dense улучшило ошибку на исходных задачах, а точность на
development осталась ниже результата четырёх разбиений.

## Подтверждение на нескольких случайных масках

На 768 новых общих эпизодах из того же пула тестовых символов
сравнили исходную случайную маску и четыре новых. Во всех масках
один общий код и 4095 отдельных кодов. Число исключений у каждого
нейрона совпадает с исходным контролем. Все маски зафиксированы
до генерации эпизодов. Численное правило совпадает с предыдущим
сравнением. Среднее по четырём новым маскам даёт равный вес каждой
и исключает исходную маску.

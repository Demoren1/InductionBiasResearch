# Единый aSRR со знаковыми группами и общей матрицей весов

Алгоритм оценивает по исходным задачам одну матрицу первого слоя B. На новой задаче веса определяются обучаемым вектором коэффициентов, а B фиксирована. Смещения и выходной слой подгоняются на опоре вместе с коэффициентами.

$$
w_\tau=Bc_\tau.
$$

Геометрия слоя определяет сравнимые позиции. Для входного разбиения каждому нейрону соответствует свой вектор коэффициентов, а локальные базисы собираются в B блочной диагональю после упорядочивания весов по нейронам. Для общей известной опоры в регрессии сравниваем отдельные позиции весов.

## Один критерий для групп

После нормировки и выравнивания исходных Dense-сетей собираем профиль каждой сравнимой координаты из её весов по задачам. Профиль входа включает веса всех нейронов блока. Число блоков на каждом участке слоя — наибольший делитель ширины участка, не превышающий 16. Это общий предел размера сохраняемой структуры. Внутри блока один базис используется с отдельными коэффициентами для каждого нейрона.

Для группы с фиксированными знаками её столбец равен подписанному индикатору, делённому на корень из размера группы. Соберём эти столбцы в матрицу G. Пусть A — матрица скалярных произведений исходных профилей, а K — симметризованная матрица взаимных произведений градиентов опоры и запроса в общей точке. Перед смешиванием делим каждую матрицу на её норму Фробениуса. Одно разбиение получается жадными объединениями по критерию

$$
\operatorname{tr}\bigl(G^\top[(1-\beta)A+\beta K]G\bigr).
$$

На каждом шаге выбираем пару групп и относительный знак их слияния, которые дают наибольшее изменение оценки. Обозначим через C и E две группы, через M смешанную матрицу, через S суммы её элементов с текущими знаками позиций. Например, перекрёстная сумма берётся по позициям первой и второй групп. Изменение оценки после лучшего из двух относительных знаков равно

$$
\Delta(C,E)=
\frac{S_{CC}+S_{EE}+2|S_{CE}|}{|C|+|E|}
-\frac{S_{CC}}{|C|}-\frac{S_{EE}}{|E|}.
$$

При слиянии умножаем знаки второй группы на знак перекрёстной суммы. Для нулевой суммы берём плюс. При положительных знаках и нулевом весе градиентов оценка даёт критерий Ward. Число групп в блоке задаёт бюджет. Для входного блока один базис используется с собственным вектором коэффициентов у каждого нейрона.

Градиентную часть можно вывести из одного шага подгонки. Пусть P — ортогональный проектор на допустимые веса, а g с нижними индексами s и q — градиенты опоры и запроса в одной точке. При шаге размера η изменение ошибки запроса в первом порядке равно

$$
L_q(w-\eta P g_s)-L_q(w)
=-\eta\, g_q^\top P g_s + O(\eta^2).
$$

Для подписанных групп проектор равен произведению G на её транспонированную матрицу. Усреднение скалярного произведения по исходным задачам и нейронам блока даёт градиентный член критерия. Он оценивает локальную пользу совместного обновления. Поэтому численные параметры выбираем по ошибке после полной подгонки на опоре валидационных задач.

Для распределения блоков половину их массы делим между видами запросов поровну. Вторую половину относим к виду с наибольшей исходной ошибкой в общей точке вычисления градиентов. Переводим доли в целые числа блоков, сохраняя хотя бы один на каждый вид, если их хватает. При меньшем числе блоков складываем нормированные матрицы градиентов с этими долями. При отборе модели виды запросов равноправны.

## Один базис из групп и исходных задач

Из двух независимых частей исходной задачи получаем воспроизводимые различия средних и ковариаций классов. Смешиваем две матрицы сигнала после нормировки и оцениваем ведущие обобщённые собственные векторы с поправкой на внутриклассовый разброс. В линейной регрессии соответствующий сигнал первых моментов задают перекрёстные ковариации входов и ответов по двум частям задачи. Для нескольких выходов эти ковариации размещаем на известных позициях их входов. Направления ортонормируем и обозначаем U.

Пусть G и U содержат по r ортонормированных столбцов на общей области координат. Переносим один базис. Для входных блоков бюджет слоя равен произведению r на число нейронов. Для общей группы отдельных весов бюджет слоя равен r.

$$
B=\operatorname{Top}_r\!\left((1-\lambda)U D U^\top
                              +\lambda G D G^\top\right),
\qquad
w=Bc .
$$

Оператор Top возвращает ведущие собственные векторы симметричной матрицы. D — фиксированная положительная диагональ со значениями от 1 до 0,9. Она задаёт порядок направлений на концах интервала и слегка различает веса столбцов при смешивании. Это важно для покоординатной численной подгонки. Формула выбирает r-мерное подпространство с наибольшей взвешенной энергией проекций. При значении 1 оно совпадает с пространством групп. При значении 0 получаем чистый базис исходных статистик.

При значении 1 пространство B совпадает с пространством G. Если G восстановила подписанные группы, все их равенства выполнены для любых новых коэффициентов. При положительном весе групп r-е собственное значение матрицы в формуле для B не ниже веса групп, умноженного на 0,9. Проецируя её уравнение на ортогональное дополнение G, получаем

$$
\left\|(\mathrm{Id}-GG^\top)B\right\|_2
\leq \min\left\{1,\frac{1-\lambda}{0.9\lambda}\right\}.
$$

Если две позиции имеют один код со знаком плюс или минус, вектор разности или суммы их координат ортогонален G. Поэтому величина нарушения этого равенства после подгонки ограничена правой частью, умноженной на норму коэффициентов и корень из двух. Оценка контролирует равенства весов при большом весе групп. Вклад в качество измеряем на новых задачах.

Точный случай для начального разбиения также проверяем отдельно. Пусть ненулевые профили равны с точностью до фиксированного знака внутри группы и различаются с точностью до знака между группами. При нулевом весе градиентов изменение оценки равно взятому со знаком минус взвешенному квадрату расстояния между средними профилями, с выбором лучшего относительного знака. Каждое правильное слияние имеет нулевую цену. Перекрёстное слияние имеет строго положительную цену. При остановке на истинном числе групп индукция даёт точное восстановление групп и относительных знаков. Это условие применяем к наблюдаемым нормированным профилям. Более общий случай с неизвестными масштабами между нейронами и повторяющимися отношениями описывает Theorem 2 о строгом SRR.

При знаковом слиянии проектор на текущие индикаторы теряет ровно одно направление. Поэтому возмущение матрицы сходства меняет цену любого одного слияния не более чем на свою операторную норму. Если на каждом шаге ценовой зазор между лучшим верным и лучшим неверным слиянием больше удвоенной нормы возмущения, лучшим остаётся верное слияние. Это даёт достаточное условие устойчивости к ошибкам профилей и добавлению градиентного члена.

Смысл использования моментов близок к спектральной оценке общей линейной репрезентации. В MSR общая матрица параметризации получается оптимизацией по исходным задачам. Здесь первая часть спектральной задачи выводится из отношений и совместных обновлений весов. [Tripuraneni et al., 2021](https://proceedings.mlr.press/v139/tripuraneni21a.html) · [Zhou et al., 2021](https://arxiv.org/abs/2007.02933)

## Проверка

Подбор структуры состоит из десяти кандидатов. Сила связи принимает значения 1/8, 1/2 и 1. Вес градиентов в группировке равен 0 или 1/2. Вес ковариаций в исходном сигнале равен 0 или 1/4. При силе связи 1 исходный спектральный сигнал выпадает, поэтому здесь только два кандидата. Для регрессии используем первый момент. Число блоков и доли запросов выводятся по правилам выше.

Оставляем бюджеты из статьи и выбираем по средней точности после подгонки на эпизодах валидации. Для регрессии сравниваем среднеквадратичную ошибку. После фиксации выбранного базиса оцениваем методы на общих новых тестовых эпизодах. Для Aug-Omniglot проверяем каждый вид запроса. Для HAR, WISDM и тороидального MNIST парные разности агрегируем по участникам или парам цифр. На синтетической кросс-корреляции измеряем восстановление связей и ошибку после подгонки.

Чистый спектральный конец интервала и переставленные группы дают два контроля при том же бюджете. Первый показывает вклад групп сверх спектрального сигнала. Второй проверяет вклад конкретных восстановленных связей. Настройку бюджета можно добавить после проверки в сопоставимых бюджетах.

## Псевдокод

Вход — исходные сети и эпизоды, бюджет, геометрия первого слоя и отдельные эпизоды валидации. Через C обозначим внутриклассовый разброс с регуляризацией 0,03 от средней дисперсии координаты. Матрицы S с индексами mean и cov — нормированные оценки сигнала классовых средних и ковариаций. Для каждого набора численных параметров применяем следующие операции ко всем блокам.

$$
\begin{aligned}
G &\gets \operatorname{SignedMerge}_r\bigl((1-\beta)A+\beta K\bigr),\
U &\gets \operatorname{GEV}_r\bigl((1-\alpha)S_{\rm mean}+\alpha S_{\rm cov},\,C\bigr),\
B &\gets \operatorname{Top}_r\bigl((1-\lambda)UDU^\top+\lambda GDG^\top\bigr).
\end{aligned}
$$

Здесь SignedMerge означает жадные слияния по указанному приращению, GEV — ведущие обобщённые собственные векторы с последующей ортонормировкой. Собираем блоки в общую матрицу и выбираем её по точности на запросах после подгонки на опоре. На каждой новой задаче возвращаем веса из произведения фиксированной матрицы на заново подогнанные коэффициенты.

## Проверенный вариант с нормировкой базиса по внутриклассовому разбросу

Ниже описана диагностическая проверка прямой спектральной оценки со штрафом за выход из групп. Она использовала оценку объединения по независимым половинам исходных задач. На валидации FC100 точность лучшего базиса составила 29,39% против 31,97% у MSR-FC. На WISDM получено 50,54% против 52,12%. Такой способ нормировки и смешивания оценивает качество направлений по исходному разбросу и также меняет условия численной подгонки на опоре.

Общая матрица B определяет первый слой для всех новых задач. На каждой задаче обучаем её коэффициенты и свободные параметры сети. Для входного разбиения каждый нейрон получает свой блок столбцов общей матрицы.

$$
w_\tau=Bc_\tau.
$$

Для каждого нейрона оцениваем матрицу сходства нормированных Dense-профилей и матрицу согласованных градиентов опоры и запроса. По двум половинам исходных задач измеряем, воспроизводятся ли различия между нейронами. Пусть M₁ и M₂ — оценки соответствующей матрицы по двум половинам, а A₁ и A₂ — эти же оценки после вычитания среднего по нейронам одного участка. Оценка после объединения имеет вид

$$
\begin{aligned}
\bar M &= (M_1+M_2)/2,\
t &= \max\{0,\langle A_1,A_2\rangle_F\},\
n &= \|A_1-A_2\|_F^2/4,\
\widehat M_h &= \bar M_{\cdot}+\frac{t}{t+n}(\bar M_h-\bar M_{\cdot}).
\end{aligned}
$$

Здесь среднее с точкой берётся по нейронам. При нулевом знаменателе берём среднее. Числитель оценивает воспроизводимую межнейронную вариацию. Второй член знаменателя оценивает шум в среднем двух независимых оценок. Это даёт единое правило объединения вместо сетки по числу блоков. При нескольких видах запроса число нейронов каждого вида пропорционально его исходной ошибке. Обе матрицы нормируем по Фробениусу, складываем и строим G жадными знаковыми слияниями. В группе используется одно значение с фиксированными знаками.

Обозначим через S воспроизводимый сигнал классовых контрастов, через C регуляризованный внутриклассовый разброс. Рассмотрим координаты после нормировки по C. В этих координатах P — ортогональный проектор на образ G. Пусть L — нижний множитель разложения Холецкого, а Top возвращает ведущие ортонормированные собственные векторы. Опускаем общий положительный масштаб базиса.

$$
\begin{aligned}
C &= LL^\top,\
P &= \operatorname{Proj}(L^\top G),\
S' &= L^{-1}S L^{-\top}\big/\|L^{-1}SL^{-\top}\|_F,\
B &= L^{-\top}\operatorname{Top}_r\bigl((1-\lambda)S'+\lambda P\bigr).
\end{aligned}
$$

Формула максимизирует воспроизводимый сигнал после поправки на внутриклассовый разброс. Второе слагаемое эквивалентно штрафу за выход из пространства найденных связей. При строгом связывании пространство B совпадает с пространством G. Коэффициенты в B тогда отличаются от обычных кодов только обратимой заменой координат. При конечном штрафе сильные направления могут выйти из групп. За счёт собственного спектра сигнала это решение различает направления по выраженности контрастов.

Подбор структуры сводится к пяти кандидатам по общей сетке. Сила связи принимает значения 1/8, 1/2 или 1. Для первых двух значений сигнал S включает либо только средние, либо смесь средних и ковариаций с весом 1/4 у ковариаций. При силе 1 спектральный сигнал выпадает. Выбираем по средней точности после refit на эпизодах валидации. Случай нулевой силы нужен для оценки вклада групп и не участвует в выборе. Бюджет и протокол численной подгонки совпадают с табличным сравнением.

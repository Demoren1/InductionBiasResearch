WSR leads the k-means variant by $1.09$ percentage points

$163\times$ as long to build its candidates as aSRR with Ward takes to
build its grouping. Both aSRR variants and WSR use 57\% less peak GPU
memory than Dense during target fitting and take longer on the same
episodes. Yeh (soft) has the shortest target fitting time with cached
basis features and the highest peak GPU memory in both stages.

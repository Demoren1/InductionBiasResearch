\section{Experiments}
\label{sec:experiments}

We study recovery with a known generating structure and evaluate transfer
to new characters on Omniglot and new subjects on UCI HAR. We compare
aSRR with Dense, LUT-Q~\cite{cardinaux2018iteratively}, Yeh's
method~\cite{yeh2022equivariance}, MSR-FC~\cite{zhou2021meta} and
weight-sharing regularization (WSR)~\cite{shakerinava2024weight}.

Within each experiment, the sharing methods have the same budget of
first-layer code values or latent coefficients. Yeh (MAP) transfers
the most probable assignments. Yeh (soft) and MSR-FC transfer their
continuous bases. All methods learn the numerical parameters, biases
and output layer afresh on the same target examples. We report the
wall time to build source candidates before their final selection.
Appendix~\ref{app:asrr-tuning-details} gives the fitting and timing
protocols.

\subsection{Synthetic recovery and transfer}

The generating ReLU network has 16 inputs, 16 hidden units, one output,
160 active first-layer connections and four shared codes. One source
function supplies 4096 fitting,
512 numerical-selection and 1024 structure-selection examples.
The fitted Dense weights are available to aSRR and WSR. An audit
after fitting checks the support and signed groups against the teacher.

We fit fresh parameters to four new functions with the same generating
structure, using 256 fitting and 64 numerical-selection examples per
function. Each method uses the same Adam and Gauss--Newton solver.
The aSRR candidates retain all 256 connections, so the sparse teacher's
indexator lies outside this bank. The selected assignment obtains a
mean query MSE of $1.43$, compared with $0.473$ for Dense
(Table~\ref{tab:recovery-synthetic}).

\subsection{Transfer between people on UCI HAR}

UCI HAR~\cite{reyes2013har} has six activity classes and 561 input
features. The four source tasks each pool four training subjects.
Five other subjects are used for development, and nine held-out subjects
provide 180 test episodes. Each episode uses three fitting and five
query windows per activity. Development fixes the numerical training
rule for each method before transfer.

With 128 codes, aSRR reaches $91.50\%$ accuracy
(Table~\ref{tab:recovery-har}). The paired gain is $5.07\pm2.17$
percentage points over Dense and $6.48\pm2.48$ over WSR. Yeh (soft)
is close to aSRR, with a paired difference of $0.63\pm1.72$ points
in favor of aSRR. All intervals use the nine subject means.

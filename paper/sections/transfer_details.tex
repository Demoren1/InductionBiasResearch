\subsection{Transfer benchmark protocol}
\label{app:transfer-details}

\paragraph*{Source signals.}
For each class in each source task, let $\mathbf a,\mathbf b$ be the
support and query means, centered across classes within each sample.
Let $C_S,C_Q$ be the analogous class-centered sample covariance
matrices. Using the normalization and symmetrization in
Equation~\eqref{eq:asrr-affinities}, we compute
\[
    M_1=\mathcal N\bigl(\operatorname{sym}\mathbb E[
          \mathbf a\mathbf b^{\mathsf T}]\bigr),
    \qquad
    M_2=\mathcal N\bigl(\operatorname{sym}\mathbb E[C_S C_Q]\bigr).
\]
The averages include classes, source tasks and query views. At a
site with $d$ inputs, let $\Sigma_0$ be the pooled within-class
covariance. We use
$\Sigma=\Sigma_0+0.03\max\{\operatorname{tr}(\Sigma_0)/d,10^{-8}\}\mathrm{Id}$.

For the gradient signal, we draw eight support sets per source task at
the target shot count. On each draw, we fit a reference network for
15 Adam steps at rate 0.01. Its basis is the signed grouping from
$\mathbf A$ alone, with the same rank and at most four equal blocks
per site. We evaluate the gradients of the support and each query
loss at the fitted weights. With $V$ query views, assign view $v$
mass $\omega_v=1/(2V)+\mathbf1_{\{v=v_*\}}/2$, where $v_*$ has the
largest mean query loss at these reference fits. If there are at
least $V$ blocks, give one block to each view. For the $b$th block
after that, give it to the view maximizing $b\omega_v-n_v$, where
$n_v$ is its current count. This sets $\pi_v=1$ for the assigned view
and zero for the others. With fewer than $V$ blocks, use
$\pi_v=\omega_v$ in every block.

\paragraph*{Cross-correlation.}
For each layout we draw 96 source, 48 development and 160 test
functions. Each source function has 96 Gaussian inputs and independent
response noise with standard deviation 0.05. We fit its least-squares
weights using 80 examples. For the gradient kernel and $M_1$, we
evaluate squared-loss gradients at zero weights on two disjoint halves
of the 96 examples. Each vector consists of input-response moments
on the known support, up to the common loss constant. We use the
normalized cross moment for both signals and an identity covariance.
Each target function has 96 noiseless query examples. Development
selects the basis and ridge strength separately for each support
size. Paired intervals use the six layout means. Yeh and MSR-FC
learn their representations by differentiating through ridge refits
on source functions.

\paragraph*{Real-data episodes.}
Toroidal MNIST and Aug-Omniglot use 64 hidden neurons. On MNIST we
split the 45 digit pairs into 25 source, 10 development and 10 test
pairs and separate the original images before applying a random
circular shift and a fixed pixel permutation. The test set has
2,000 two-way episodes. Aug-Omniglot uses 48 source tasks, 192
development episodes and 768 test episodes with disjoint character
pools. Its transformed queries use random resized crops,
reflections and rotations of up to $30^\circ$.

FC100 uses 16 local image patches with eight neurons per patch and
mean-pooled $4\times4$ RGB inputs. We use 16 source tasks, 384
development episodes and 2,048 test episodes. On WISDM, we use 18
activities and nonoverlapping 64-sample windows of the three smartwatch
acceleration axes and their magnitude. The 32 hidden neurons are
organized in four sites. We use 27 source, 7 development and 12 test
participants after filtering for sufficient windows per activity.
The 768 test episodes use early windows for fitting and later windows
for queries.

On UCI HAR a 561--16--6 ReLU network receives the original features.
We retain every second window within each subject and activity
before drawing episodes. Each of four source tasks pools four
participants and uses 366 fitting, 78 numerical-selection and 78
additional source windows. The latter supply source queries.
Five participants supply 96 development episodes and nine
held-out participants supply 360 test episodes. Each test episode
has three fitting and five query windows per activity.
All five datasets use new test draws from the held-out pools.

\paragraph*{Numerical selection.}
We evaluate the full aSRR grid on development episodes. For MNIST,
Aug-Omniglot, FC100 and WISDM we compare Adam rates 0.001, 0.003,
0.01 and 0.03 and durations of 25, 75, 150 and 300 updates, averaging
accuracy over two starts. We break accuracy ties by query
cross-entropy. HAR uses the same four rates with activation
quantiles 0.1, 0.5 and 0.9 and up to 1,000 Adam steps. We retain
three settings by query cross-entropy and compare ensembles of
1, 4 and 16 predictions.

The baselines retain their previously selected representations and
refit settings. All methods refit on the same new episodes. Test
accuracy averages two fresh starts on the four input-group
benchmarks other than HAR, which uses each model's selected ensemble.
Paired intervals use participant means on HAR and WISDM, digit-pair
means on toroidal MNIST and episodes conditional on the held-out
class pools on FC100 and Aug-Omniglot. For the additional WISDM
check, we partition the other eligible participants into three
disjoint test sets. Both methods learn their representations afresh
within each split and select settings on separate development
participants. The training participants can overlap across splits.

For a shuffled control, we permute the rows of $\mathbf G$ within
each block and recompute Equation~\eqref{eq:asrr-basis} at the same
settings and with the same $\mathbf U$. This preserves group sizes
and their signs. We average four permutations with matched refit
settings and initialization seeds.

We retain four Dense fits per source task on MNIST, Aug-Omniglot,
HAR and WISDM, and three on FC100. On the input-group benchmarks
other than HAR, WSR and LUT-Q generate proposals from eight Dense
initializations selected by source numerical-validation loss.
WSR uses the proximal map with rewinding and LUT-Q updates a dictionary
of nearest code values. Yeh learns blockwise probabilistic assignments
through three inner updates. Its hard assignment maximizes total
probability at the prescribed code count. MSR-FC learns a factorized
basis. Both continuous baselines transfer the basis and fit fresh
coefficients.

\section{Preliminary}
\label{sec:preliminary}

Related prediction tasks may benefit from the same relations between
weights even when they require different numerical values. For example,
a group of connections may share a coefficient in each task, while its
value changes from one task to another. Reusing this pattern constrains the
parameters learned on a new task. Such constraints can help a predictor
generalize from limited data and change which solutions an optimizer
finds within a given budget. We study this form of transfer by separating
the structure of a network from its numerical parameters. The structure
is proposed from experience with previous tasks; its usefulness is
judged after the numerical parameters have been learned anew.

\subsection{Multi-task learning}
\label{sec:tasks}

Each task $\tau$ has a distribution $P_\tau$ over input--target
pairs $(\mathbf x,y)$. Source and target tasks share input and output
spaces and are drawn independently from a common task environment
\cite{baxter2000model}. We learn sharing constraints on the source
tasks and assess their transfer on the target tasks.
For each task, a \emph{training sample} $S_\tau^{\mathrm{train}}$ is used to
fit numerical parameters, and an independent \emph{validation sample}
$S_\tau^{\mathrm{valid}}$ is used to compare the fitted predictors
\cite{finn2017model,zhou2021meta}. Conditional on $\tau$, both samples
consist of independent draws from $P_\tau$.
For a predictor $f$ and a loss $\ell$, the population risk
$R_\tau(f)$ and empirical loss $\mathcal L_S(f)$ average that loss
over the task distribution and a sample $S$, respectively.
\begin{equation}
    R_\tau(f):=\mathbb E_{(\mathbf x,y)\sim P_\tau}\ell(f(\mathbf x),y),
    \qquad
    \mathcal L_S(f):=\frac{1}{|S|}\sum_{(\mathbf x,y)\in S}\ell(f(\mathbf x),y).
    \label{eq:task-loss}
\end{equation}
Here, $\ell$ measures prediction error on one example, such as squared
error for regression or cross-entropy for classification.

\subsection{Network structure}
\label{sec:network-structure}

We distinguish structural constraints shared across tasks from
task-specific numerical values.
A network structure specifies which connections are permitted and which
weights share a trainable parameter. Let $P$ be the number of constrained
positions, indexed by $p=1,\ldots,P$ across any number of layers.
When describing a single task, we omit its index $\tau$ from its
weights, code values and predictor. We restore it when comparing tasks.

We encode the constraints using an \emph{indexator}, an integer vector
$\mathbf I=(I_p)_{p=1}^P$ whose entries are labels in $\{0,\ldots,K\}$.
The label at each position selects a weight from the task's
\emph{codebook} $\mathbf C=(C_0,\ldots,C_K)^{\mathsf T}$.
\begin{equation}
    w_p=C_{I_p},\qquad C_0=0.
    \label{eq:indexator-weights}
\end{equation}
Under this rule, $I_p=0$ removes a connection, while $I_p=I_q>0$
requires the corresponding weights to remain equal throughout
training~\cite{yeh2022equivariance}.
Varying the code values in~\eqref{eq:indexator-weights} gives all
admissible weights. Positive labels name the groups, so they can be
renamed together with their codes. Distinct groups have independent
parameters even if their fitted values coincide on a task.

Write $\mathcal F_{\mathbf I}$ for the class of predictors obtained
by varying the codebook and all unconstrained parameters while holding
$\mathbf I$ fixed. Each fitting attempt initializes these numerical
parameters afresh and optimizes them on the task's training sample.

\subsection{Problem formulation}
\label{sec:problem-formulation}

Let $\mathcal{I}_K:=\{0,\ldots,K\}^{P}$ denote the set of indexators.

For a fixed indexator $\mathbf I$, its optimal
risk~\cite[Eq.~(6)]{baxter2000model} on task $\tau$ is
\begin{equation}
    R_\tau^\star(\mathbf I):=\inf_{f\in\mathcal F_{\mathbf I}}R_\tau(f).
    \label{eq:optimal-task-risk}
\end{equation}
The infimum optimizes task-specific numerical parameters with respect
to the true task distribution, giving an ideal measure of the
predictive capacity of $\mathbf{I}$. Generalization from finite training
samples and numerical convergence also depend on the fitting procedure.

We choose an indexator to minimize the expected optimal risk on a
new task drawn from the same environment.
\begin{equation}
    \mathbf I^\star
    \in\operatorname*{arg\,min}_{\mathbf I\in\mathcal I_K}
    \mathbb E_\tau R_\tau^\star(\mathbf I).
    \label{eq:optimal-structure}
\end{equation}

With $T$ source tasks, the corresponding ideal empirical objective
averages the best training loss on each task under a fixed indexator.
\begin{equation}
    \widehat{\mathbf I}\in\operatorname*{arg\,min}_{\mathbf I\in\mathcal I_K}
        \frac1T\sum_{\tau=1}^T
        \inf_{f\in\mathcal F_{\mathbf I}}\mathcal L_{S_\tau^{\mathrm{train}}}(f).
    \label{eq:structure-learning}
\end{equation}

On each target task the corresponding fitting objective is
$\inf_{f\in\mathcal F_{\widehat{\mathbf I}}}\mathcal L_{S^{\mathrm{train}}}(f)$.
Each task has its own numerical parameters, so these optima can be
averaged over target tasks. We measure transfer by the mean validation
loss of the predictors obtained after fitting. Section~\ref{sec:method-selection}
gives the selection rule used with a finite bank and a numerical solver.

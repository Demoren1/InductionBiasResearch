# Теоретическое состояние эксперимента

Дата среза: 2026-08-23. Этот файл — самостоятельная отправная точка для
обсуждения гипотез, а не инструкция по запуску.

## Вопрос эксперимента

Можно ли по структуре множества успешно обученных разреженных MLP восстановить
полезный **структурный prior** — в данном случае почти Toeplitz-поддержку для
детекции локального паттерна — и затем использовать этот prior для генерации
масок, которые обобщаются лучше случайных?

Важно различать три объекта:

1. **Маска** `M` — фиксированная бинарная поддержка первого слоя.
2. **Обученные веса** `W1`, `W2` внутри маски.
3. **Importance-карта** — нормированное `|W1 * M|`, на которой обучается VAE.

## Синтетическая задача и gold solution

- Вход: `x ∈ {-1, +1}^8`.
- Для каждого из 16 бинарных паттернов длины 4 отдельная задача: `y=1`, если
  паттерн встречается в `x` как непрерывная подпоследовательность.
- Возможных положений окна пять: `0..4`.

Gold-решение — пять matched filters длины 4, по одному для каждого окна. Их
поддержка — Toeplitz-маска: hidden unit видит только четыре подряд идущие
позиции входа. В сети используется `H=8`, поэтому ideal mask содержит два
дубликата окон `0,1,2` и по одному окну `3,4`; всего 32 активных ребра из 64.

Идеальная поддержка не зависит от самих битов паттерна: значения taps зависят
от паттерна, а **геометрия** локального окна — нет.

## Модель и экспериментальный канал

Каждая базовая модель — однослойный masked MLP:

`f(x) = W2ᵀ ReLU((W1 * M)ᵀx + b1) + b2`.

- Сначала обучается банк из 2 000 MLP на каждый паттерн.
- Для каждого MLP маска `M ~ Bernoulli(0.5)` фиксирована на всём обучении.
- Отбираются лучшие 10% MLP по validation loss.
- Из их `|W1 * M|` строятся importance-карты `8×8`.
- Unconditional CVAE обучается на объединении сырых top-10% importance-карт.

CVAE не получает идентификатор паттерна: он моделирует общий prior на маски.
При генерации для каждого образца берётся независимый `z ~ N(0, I)`, decoder
выдаёт 64 logits, а итоговая маска — global top-32 по `sigmoid(logits)`.

Исправленный независимый семплинг `z` принципиален: более ранние исторические
результаты с повторным использованием одного `z` для 64 масок несопоставимы с
текущими.

## Текущий основной результат: генерация 64 масок

Протокол: для каждого источника масок обучается свежий MLP на каждой из 64
масок для каждого паттерна; затем accuracy усредняется по паттернам. Все числа
ниже относятся к одному чистому запуску с raw top-10% targets, BCE-sum и
`β=0.1`.

| источник маски | mean accuracy | σ по паттернам | mean BCE |
|---|---:|---:|---:|
| mean importance | 0.7876 | 0.0314 | 0.3991 |
| deterministic regressor | 0.7875 | 0.0312 | 0.3994 |
| random Bernoulli(0.5) | 0.8877 | 0.0504 | 0.2848 |
| **CVAE, raw top-10%** | **0.9181** | **0.0402** | **0.2351** |
| реальные top-10% MLP masks (oracle) | 0.9246 | 0.0390 | 0.2219 |
| exact ideal Toeplitz | 0.9302 | 0.0310 | 0.2090 |

Наблюдение: CVAE превосходит random на 3.04 п.п. и отстаёт от exact Toeplitz
на 1.21 п.п. Его 64 сэмплированные маски все различны. Средний
best-permutation IoU с gold Toeplitz mask равен 0.6442 (диапазон 0.5238–0.7778).
Перестановка hidden units применяется только в диагностике, не при обучении.

## Отдельный опыт: bilevel-поиск через frozen decoder

Это **другой протокол**, и его нельзя численно объединять с таблицей выше.
Для каждого паттерна берётся одна top-32 маска. Внутренний MLP обучается на
первой половине fixed validation set, а внешний градиент минимизирует BCE на
этой половине через soft mask; итоговая бинарная маска проверяется на второй
половине восемью новыми MLP.

Сравнивались три режима:

- `z`: обучаемый latent размерности 32, decoder CVAE заморожен;
- `z0`: prior mode `z=0`, без внешней оптимизации;
- `free`: напрямую оптимизируемые 64 logits, без decoder.

| режим | mean test accuracy | σ по паттернам | Toeplitz IoU бинарной маски |
|---|---:|---:|---:|
| **z** | **0.9122** | 0.0440 | **0.6881** |
| z0 | 0.8893 | 0.0418 | 0.6410 |
| free | 0.8694 | 0.0510 | 0.5820 |
| random reference | 0.9263 | 0.0430 | — |
| ideal reference | 0.9322 | 0.0321 | — |

`z` лучше `z0` на 13 из 16 паттернов и лучше `free` на 15 из 16. Random
reference здесь — одна конкретная случайная маска в one-mask протоколе; её
превосходство над `z` не означает, что random лучше CVAE в основном 64-mask
протоколе.

## Насколько маски теплицевы?

Маски `z` имеют частичную, но не точную Toeplitz-геометрию. Суммарные
назначения hidden columns окнам: `[21, 47, 31, 19, 10]`, тогда как target для
16 масок — `[32, 32, 32, 16, 16]`. В частности, окно 1 переиспользовано, а
крайние окна 0 и 4 недоиспользованы.

Следовательно, decoder-manifold не кодирует exact Toeplitz mask как жёсткое
правило. Он задаёт мягкий prior на локальные связи, который bilevel-оптимизация
может приблизить к нужной структуре, но цель BCE не штрафует напрямую за
неправильное распределение окон.

## Может ли второй слой объяснить нетеплицевость?

Для ответа заново обучены все 48 one-mask ансамблей тем же final-eval
протоколом. Для каждого построена непрерывная effective importance-карта:

`E = mean_repeats(|W1 * M| * |W2|)`.

После оптимального выравнивания скрытых колонок с gold измерялась доля массы
`E`, лежащая на Toeplitz-support.

| режим | Toeplitz mass бинарной поддержки | Toeplitz mass effective карты |
|---|---:|---:|
| z | 0.8145 | **0.8529** |
| z0 | 0.7812 | 0.8267 |
| free | 0.7344 | 0.7948 |

Второй слой действительно ослабляет часть неструктурных связей: effective
mass выше у всех трёх режимов. Но ранжирование остаётся тем же: `z > z0 >
free`. Поэтому нетеплицевость не является только артефактом `W2`: часть
неправильной геометрии содержится в самих масках. В то же время вывод не
каузальный: `W1` и `W2` обучались совместно, а метрика использует gold only
as a post-hoc diagnostic.

## Что подтверждено и что нет

Подтверждено в текущем single-seed запуске:

- Отбор top-10% структурных карт и CVAE с BCE-sum, `β=0.1` преодолевают
  исторический collapse/baseline около 0.79.
- CVAE-маски существенно лучше random масок в 64-mask downstream протоколе.
- Frozen CVAE decoder даёт более хороший и более Toeplitz-подобный search
  space, чем `z0` и свободная 64-битовая оптимизация.
- Второй слой усиливает локальную структуру, но не создаёт её полностью.

Не подтверждено:

- Устойчивость чисел к нескольким `EVAL_SEED`, CVAE seeds и train seeds.
- Превосходство над historical selfalign/window: их высокие числа получены до
  исправления независимого семплирования и требуют честного повтора.
- Что именно learned manifold представляет «свёртку» или эквивариантность, а
  не более слабую статистику локальности и центральной позиции.
- Каузальная необходимость Toeplitz-геометрии для качества: current evidence
  корреляционное и сравнительное, а не интервенционное.

## Центральные теоретические гипотезы

1. **Manifold prior hypothesis.** CVAE учит низкоразмерное множество масок с
   локальной геометрией; ограничение оптимизации этим множеством защищает от
   переобучения `free`-логитов на finite validation split.
2. **Permutation nuisance hypothesis.** Перестановка hidden units добавляет
   нерелевантную мультимодальность importance-картам и ограничивает качество
   unconditional VAE на сырых картах.
3. **Effective-structure hypothesis.** Часть структурности проявляется только
   после совместного учёта `W1` и `W2`; support mask — полезный, но неполный
   объект для анализа.
4. **Boundary-bias hypothesis.** Недоиспользование окон 0 и 4 — не только
   ошибка модели, а следствие статистики обучающих примеров, finite width или
   объективной выгодности центральных позиций в данном протоколе.

## Наиболее информативные следующие эксперименты

1. Повторить main eval для нескольких seeds и дать доверительные интервалы для
   разности CVAE–random и CVAE–ideal.
2. Повторить `window`/`selfalign` после исправления sampler при том же
   64-mask протоколе; это проверит роль permutation nuisance.
3. Добавить контролируемую регуляризацию на window coverage или
   Toeplitz-distance при bilevel-поиске и измерить trade-off
   accuracy–структура.
4. Сравнить unrestricted MLP с архитектурой, в которой каждый hidden unit
   принудительно видит одно непрерывное окно длины 4. Это превращает Toeplitz
   prior в интервенцию, а не post-hoc метрику.
5. Менять длину входа, длину паттерна и число hidden units; проверить, растёт
   ли преимущество learned prior с размером пространства масок.

# Два замороженных VAE: поиск согласованных масок

Дата: 2026-09-06.

Полный запуск на GPU: два VAE seeds 42/43, один OOD split seed 42, 64 независимых старта. Оптимизация использует только расстояние мягких top-32 масок после Hungarian-перестановки колонок. Gold и held-out метки не участвуют в поиске, выборе checkpoint или лучшей итерации.

## Контроль качества VAE и ограничений поиска

Число разных масок с точностью до перестановки колонок: initial_vae1: 64/64; initial_vae2: 64/64; optimized_vae1: 64/64; optimized_vae2: 64/64; random_search_vae1: 64/64; random_search_vae2: 64/64.

- VAE seed 42: best validation loss 28.5807; средний std decoder probabilities по prior-сэмплам 0.1902.
- VAE seed 43: best validation loss 28.4137; средний std decoder probabilities по prior-сэмплам 0.1935.
- initial: средняя норма latent 5.612, на границе радиуса 8 — 0/128; среднее S(1−S) = 0.1213 (0 для бинарных значений, 0.25 для 0.5).
- final: средняя норма latent 7.849, на границе радиуса 8 — 92/128; среднее S(1−S) = 0.0799 (0 для бинарных значений, 0.25 для 0.5).

Это один pair seeds и одно разбиение задач. 64 старта не заменяют повторение с другими VAE. Случайный поиск сопоставлен по числу независимых пар-кандидатов (1001 на старт), а не по времени вычислений. Радиус latent ограничен, но это не гарантирует нахождение на типичной области распределения декодируемых карт.

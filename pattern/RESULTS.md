# Результаты свежего прогона

Дата: 2026-08-22.

Источник: чистый запуск `scripts/run_all.sh` после очистки `outputs/`, затем
`scripts/07_optimize_z.sh` в режиме `z`. Основные артефакты: `outputs/cvae/`,
`outputs/eval/eval_results.json` и `outputs/eval/zopt_results.json`.

## Краткий вывод

Без выравнивания hidden units VAE восстанавливает полезную структуру из сырых
importance-карт: **0.9181** downstream accuracy. Это на **3.04 п.п.** выше
случайной маски (`0.8877`) и на `0.65 п.п.` ниже oracle из реальных top-10%
масок (`0.9246`). До ideal Toeplitz-маски остаётся `1.21 п.п.`.

Этот запуск использует исправленный семплер: каждая из 64 CVAE-масок получает
свой независимый latent `z`. Поэтому результат нельзя без оговорок смешивать с
историческими CVAE-цифрами из `FINDINGS.md`, где один `z` по ошибке повторялся
для всех `n_masks`.

## Конфигурация

| компонент | значение |
|---|---|
| задача | 16 бинарных паттернов длины 4 в последовательности длины 8 |
| MLP-банк | 2 000 masked MLP на паттерн, `H=8`, 2 000 шагов Adam |
| VAE targets | сырые `importance.pt`, только top-10% по `val_loss` |
| VAE | unconditional, latent 32, hidden 256, 80 эпох |
| VAE loss | BCE, reduction `sum`, `β=0.1` |
| VAE split | 2 720 train / 480 validation importance-карт |
| eval | 64 независимые binary top-32 CVAE-маски на паттерн, `EVAL_SEED=42` |

Лучший validation loss VAE: `28.3237`; последний: `28.3378`.

## Downstream-оценка

Для каждой маски обучается свежий masked MLP, затем accuracy усредняется по
16 паттернам. `σ` — population standard deviation средних accuracy по
паттернам.

| источник маски | mean accuracy | σ по паттернам | mean BCE | плотность |
|---|---:|---:|---:|---:|
| mean importance | 0.7876 | 0.0314 | 0.3991 | 0.500 |
| deterministic regressor | 0.7875 | 0.0312 | 0.3994 | 0.500 |
| random Bernoulli(0.5) | 0.8877 | 0.0504 | 0.2848 | 0.498 |
| **CVAE, raw top-10%** | **0.9181** | **0.0402** | **0.2351** | **0.500** |
| реальные top-10% MLP masks (oracle) | 0.9246 | 0.0390 | 0.2219 | 0.581 |
| ideal Toeplitz | 0.9302 | 0.0310 | 0.2090 | 0.500 |

CVAE лучше random на `0.0304`, но закономерно уступает маскам, отобранным по
качеству у уже обученных MLP, и точной Toeplitz-структуре. Худший CVAE-паттерн
— `1001` (`0.8568`), лучший — `1111` (`0.9748`).

Отдельная gold-диагностика структуры: 64 сэмплированные CVAE-маски были все
различны; их mean best-permutation IoU с ideal mask равен `0.6442`
(`0.5238–0.7778`). Венгерское сопоставление столбцов используется только для
метрики, не при обучении VAE.

## Связь с `FINDINGS.md`

Исторический baseline без фильтрации и с коллапснувшим VAE давал около `0.79`,
ниже random. Свежие `mean_imp` и `det_reg` (`≈0.788`) воспроизводят эту точку
отсчёта. Новая конфигурация исправляет два независимых узких места:

1. `BCE-sum, β=0.1` даёт информативный латент вместо posterior collapse.
2. Отбор top-10% карт отбрасывает 90% наиболее шумных targets.

Таким образом, текущий результат подтверждает основной вывод `LOSS_SWEEP.md`:
даже без канонизации перестановок качество/чистота обучающих карт позволяют
получить большую часть полезной структуры. Но он пока не отменяет вывод
`FINDINGS.md` о выравнивании: исторические selfalign/window результаты
(`≈0.932–0.935`) выше, однако их нужно повторить с исправленным независимым
семплированием для прямого сравнения.

## Bilevel-оптимизация z через frozen VAE

Выполнен только режим `z`: для каждого паттерна оптимизируется latent через
замороженный decoder, затем одна top-32 маска оценивается на отдельной половине
validation-набора восемью свежими MLP.

| режим | mean test accuracy | σ по паттернам | mean test BCE | mean final val loss |
|---|---:|---:|---:|---:|
| z | 0.9122 | 0.0440 | 0.2392 | 0.4825 |
| random reference | 0.9263 | 0.0430 | 0.2153 | — |
| ideal reference | 0.9322 | 0.0321 | 0.2033 | — |

Это отдельный одно-масочный протокол; его нельзя напрямую сравнивать с таблицей
из 64 CVAE-масок выше. Кроме того, в свежем запуске отсутствуют `z0` и `free`,
поэтому пока нельзя утверждать, улучшает ли именно bilevel-оптимизация prior
режим или ограничение decoder manifold. Следующий корректный запуск:

```bash
GPU_IDS="0" MODES="z z0 free" bash scripts/07_optimize_z.sh
```

Для уже готового `z`-запуска сохранены маски и их структурная диагностика:
mean best-permutation IoU с Toeplitz target равен `0.6881`, а суммарные
назначения по окнам — `[21, 47, 31, 19, 10]` при целевых `[32, 32, 32, 16,
16]`. Матрицы и график находятся в
`outputs/plots/z_analysis/zopt_masks_z.png` и
`outputs/plots/z_analysis/zopt_toeplitz_z.png`.

## Роль второго слоя в effective importance

Для каждой из 48 сохранённых масок был заново воспроизведён final-eval
протокол: восемь MLP, 2 000 шагов, те же seeds. Затем измерена непрерывная
карта `|W1 * mask| * |W2|`; перед метрикой её столбцы выровнены с Toeplitz
target. Reproduced accuracy совпадает с zopt-результатами.

| режим | binary-support Toeplitz mass | effective Toeplitz mass | изменение |
|---|---:|---:|---:|
| z | 0.8145 | **0.8529** | +0.0384 |
| z0 | 0.7812 | 0.8267 | +0.0455 |
| free | 0.7344 | 0.7948 | +0.0604 |

Второй слой систематически уменьшает вклад неструктурных связей, однако
порядок режимов после этого не меняется: `z > z0 > free`. Значит отклонение
от Toeplitz-структуры связано и с избыточностью/перевзвешиванием hidden units,
и с самими масками; decoder manifold остаётся источником полезного
структурного prior.

Артефакты: `outputs/eval/effective_mask_analysis.json`,
`outputs/eval/effective_mask_analysis.pt`,
`outputs/plots/z_analysis/effective_mask_summary.png` и
`effective_masks_<mode>.png`. Воспроизводимый запуск:

```bash
GPU_IDS="0" bash scripts/08_analyze_effective_masks.sh
```

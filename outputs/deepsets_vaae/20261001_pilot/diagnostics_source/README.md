# Диагностика исходных карт

`source_bank_diagnostic.py` только читает сохранённые банки и MNIST8m. Он
воспроизводит исходную инициализацию весов каждого кандидата отдельными
документированными RNG, сравнивает её с сохранёнными лучшими весами и измеряет
активность пикселей на точном `source_train` для seed 4100.

`source_bank_diagnostic.png` / `.pdf`:

1. верхний ряд показывает активность входа, важность, которую видит VAE, и
   такую же важность до обучения;
2. нижний ряд показывает изменение весов за обучение и важность после
   умножения на стандартное отклонение входного пикселя;
3. scatter сравнивает нормированные пространственные маргинали raw-карт до и
   после обучения. Линия `unchanged` означает отсутствие пространственного
   сдвига.

Важно: activity-weighted карта — диагностическая контрфактическая метрика. VAE
обучался на raw `abs(W) * M`, а не на ней. Поэтому она показывает расхождение
между информацией в данных и целевым представлением VAE, но не измеряет
качество VAE.

# Codebook-поиск: завершённый эксперимент

Дата: 25 октября 2026. Генератор выдаёт назначения I; два значения C обучаются заново. Source-решения получены обычным dense SGD на простых задачах; правильные target-назначения доступны только oracle-контролю и диагностике.

## Дизайн

Одночастотный sine teacher имеет плотный вектор из двух повторяющихся значений. Вектор разбит на блоки по восемь координат, в каждом один из двух мотивов. Source содержит все комбинации с чётной суммой индексов мотивов; evaluation — новые нечётные комбинации. Source-частоты 0.8–1.2, target-частоты 3.8–4.2. Три независимых банка на каждую размерность.

В банке хранятся только принятые по empirical MSE<0.005 обученные решения; индексы извлекаются кластеризацией весов в два скалярных центроида (K=2). Амплитуда канонизирована по знаку. VAE учится на восстановленных восьмибитных блоках; block prior независимо выбирает реальные восстановленные блоки. Границы блоков известны обоим методам. Teacher-индексы не используются для обучения prior.

Внешний бюджет 32+32, каждое обучение 1024 шага batch=64. Два codebook-параметра и выходная амплитуда обучаются. Нормированные координаты центроидов имеют std=2, поэтому средняя квадратная норма начального вектора равна восьми. SGD по этим координатам соответствует усреднению градиентов внутри группы. Dense SGD/Adam выбираются на отдельных validation-функциях по сетке learning rate и общей начальной нормы.

Кандидат выбирается по 4096 независимым от training примерам; возвращённая ошибка измеряется аналитически. Общие minibatch потоки связывают кандидатов. Источники и параметры запечатаны в plan.json до evaluation.

## Что отделяют контроли

1. Codebook с новыми назначениями и случайными значениями проверяет перенос схемы sharing, а не готового решения.
2. Перенос старого C, в том числе при oracle I, проверяет перенос численных значений при сдвиге частоты. В этом опыте он не помогает; это не универсальное утверждение против warm start.
3. Independent bits теряет зависимости внутри полезного блока. Replay целых I не содержит отложенных комбинаций. Block prior и VAE комбинируют известные части.
4. Raw initialization меняет только начальную норму C; summed-gradient меняет только метрику обновления. Эти два фактора разделены.
5. Sparse-two не может точно представить плотный teacher: это контроль представимости с тем же числом свободных скаляров, а не равномощный оптимизационный baseline. Аналогично фиксированный source C ограничивает доступные частоты.

## Ограничения вывода

Доказаны свойства линейной codebook-параметризации и reduction к эффективной размерности; основной exponential trapping theorem относится к fixed-scale population GD. Он не является численным сертификатом настроенных dense baseline с нормой, не растущей с d. Дополнительная SGD-теорема требует clipping амплитуды и достаточно большого batch. Здесь оба dense baseline и codebook SGD работают без clipping при batch=64.

Роли блоков известны, задача синтетическая, библиотека мала. Отсутствуют полный перебор codebook-комбинаций, сравнение с teacher-independent спектральным/моментным решателем и оптимизация дискретных назначений с адаптивным перераспределением бюджета. При 16 весах только четыре полные комбинации: это демонстрация механизма, а не преимущество перед перебором. Ноль наблюдённых успехов не доказывает нулевую вероятность.

Неопределённых/расходящихся candidate fits: 0. Они учитываются как неудачи. Индивидуальные данные, доли по банкам и описательные task-cluster интервалы находятся в codebook_summary.json; три банка не дают точной оценки внешней вариации.

## Артефакты

Вычисления выполнены во временном /dev/shm. Компактные raw NPZ, исходные банки, VAE checkpoints, планы и исходники скопированы в runs/codebook_v1. Эта долговременная копия позволяет повторить агрегацию после очистки временной памяти. export.json фиксирует пути и SHA-256 планов.

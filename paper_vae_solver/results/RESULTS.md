# Результаты запущенных экспериментов

Дата: 25 октября 2026. Все приведённые ниже запуски завершены.

Основной исход: доля возвращённых решений с MSE < 0.1. Для sine риск вычислен аналитически; для tanh используется независимая выборка из 65 536 примеров. Кандидаты во всех случаях выбираются по эмпирической selection MSE.

## Происхождение и исправления

Основные таблицы используют matched_v2 и replication_v2. В первых версиях enumeration второй проход повторял ту же маску с теми же весами. В v2 цепочка инициализации сдвигается на каждом проходе: каждая из 16 масок получает два различных старта. Основное сравнение пересчитано; для репликации повторена только оценка с теми же сохранёнными банками и VAE. Старые результаты сохранены для аудита и не используются как дополнительная репликация.

Каждый запуск содержит plan.json, исходники на момент запуска и сырые NPZ. summary.json включает отдельные вероятности встречи правильной маски и её выбора для refit. Исходные эксперименты sine_mask_vae не изменены.

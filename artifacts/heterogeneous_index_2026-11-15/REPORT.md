# Похожие структуры и однотасковый алгоритм 1

15 ноября 2026. Первый диагностический опыт; в рукопись не включён.

54 source-банка: 3 независимые базовые структуры × 3 уровня изменения назначений × 2 уровня source-шума × 3 количества source-задач. В каждой матрице 12×4=48 весов и 4 независимых генерирующих кода. Learner перебирает бюджеты 2/4/8/48. Значения кодов, перестановки выходных колонок и локальные изменения назначений свежие на каждой задаче.

Source: 32 Gaussian-примера на задачу, точное численное OLS; source label noise 0/15% RMS сигнала. Target: 8/24 fit-примера и 8 отдельных selection-примеров, noise 10%. Изменяются ровно round(48×fraction) позиций до перестановки; 10%/30% соответствуют 5/14 из 48. Ошибка — точная относительная population MSE для независимого Gaussian-входа. Истинные target-веса открыты scorer только после фиксации всех предсказаний.

## Что именно сравниваем

G34 здесь — экземпляр алгоритма 1 с identity descriptor и signed lookup: Cauchy IRLS для значений кодов, затем дискретное обновление назначений. Нейронных масштабов, масок и нелинейного обучения нет. Выравнивание перебирает все 24 перестановки выходных колонок, профилируя значения кодов. Это перестановки каналов между задачами, не доказательство восстановления скрытых ReLU-нейронов. Pair использует прежний ScalarPairs/pair_candidates; кандидаты от двух source-решений сравниваются общим aligned score.

G34 fixed переносит индексатор без перестановок. Align разрешает только перестановку колонок. Adapt дополнительно запускает алгоритм 1 при T=1 с 0/1/4/12 categorical updates. Single запускает тот же T=1 алгоритм из однотаскового Lloyd seed. Значения кодов для прогноза каждый раз заново fit LS/ridge по F. H выбирает m, candidate, ridge и depth; итоговый риск для выбора не используется. Во всех learner-банках доступен вариант без sharing.

## Ограничения

Это первая маленькая диагностика конкретного механизма. Три структуры не дают основания объявлять общий выигрыш или независимость всех 48 задач на уровне source-структур. Полный nonlinear G34 и native MSR/Yeh здесь не сравнивались; коэффициенты кодбука независимы, дополнительной линейной карты кодов нет. Малый target F=8<D=12 делает dense OLS недоопределённым; оценка residual uncertainty не ограничивает этот bias. Бюджет 4 в source recovery figure — явный срез для аудита; functional selection не получает true m.

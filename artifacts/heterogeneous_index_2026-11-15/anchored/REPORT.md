## Ограничения

Это signed lookup с identity descriptor на линейном слое12×4. Новые среды — независимые базовые индексаторы того же генератора, не новый dataset или ReLU architecture. Три независимые новые структуры не дают основания для универсального вывода. Числа0/10/30% означают0/5/14 изменённых позиций из48. Oracle I и true m в source_audit используются только при оценке. В структурных метриках учитываются также выбранные m2/8/48: избыточное дробление групп не считается точным восстановлением I, даже если численные веса близки.

Оригинальные четыре learner-файла с зарегистрированными хэшами сохранены в executed_source/. После запуска возможна только отмеченная стилистическая правка итерации по словарю, не изменение численных правил. metrics.csv содержит все выборы/ошибки; summary.json — отдельные результаты старых/новых структур и means по каждой среде; paired_comparisons.json — парные различия. Runtime включает весь перебор λ и контролей, поэтому не используется как время одного метода.

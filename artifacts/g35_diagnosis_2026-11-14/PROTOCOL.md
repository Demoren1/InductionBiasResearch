# Diagnostic follow-up: G34 and Pair remain the baselines

The nonlinear covariance extension did not improve G34 on its three evaluated datasets. Pair results are mixed and must be compared to Pair itself. This follow-up diagnoses the difference from noiseless linear synthetic results. It does not assume that G35 is a better practical method and does not edit the manuscript.

There are three separable questions. First, covariance on synthetic data used400 or800 source functions, whereas the real-data study had four HAR functions and ten binary image functions. A fixed-index synthetic ablation reduces only the number of functions used by covariance to4/10/20/50/all. It retains200 examples per function, the former recovered index and its previously selected SVD dimension. Eight precommitted subsets are used at each partial count. New audit tasks are generated once with seed35111622 plus rank; no hyperparameter is chosen from their losses. The index still benefits from its original full training set. This diagnoses the covariance sample count, not the end-to-end sample complexity of bank recovery.

Second, retained numeric fits of the same real source function need not give identical layer weights. Four fits selected on source H are available. Their normalized weight-space variability and SVD subspace overlaps are measured alongside their H losses. These are different settings/restarts, not independent new functions. Large parameter variability would challenge a weight-covariance estimate, but would not by itself prove that network symmetries cause target error.

Third, nonlinear G35 with a positive isotropic residual preserves the same bank function family as G34/Pair. Its numerical differences can arise from initialization and optimization coordinates. We distinguish full covariance, marginal variances without correlations, and group-energy normalization without learned covariance. New code-coordinate shrinkage has the exact baseline at zero and approaches the observed second moment at one. All positive identity components preserve every original bank direction. Mean weight-space initialization energy is matched to the baseline. Both the best retained fit per function and the pool of four fits are estimated. Pooling fits increases sampled numeric variability without creating new source functions.

The controlled maps use the fixed512-code bank for each method and dataset, matching the earlier selected nonlinear G35 budgets. Baselines are retuned over8/16/32/64/128/512; full-N Dense remains an explicit endpoint. Original G35512 variants remain controls. Shrinkage values are0/.01/.05/.1/.25/.5/.75/1; zero is the existing baseline, without reparameterization. No new source optimization is performed. New development episodes use seed35111601 in the same previously studied class/person environments. The common fresh Adam, learning-rate/activity grid and two-restart averaging are unchanged. Coarse500 then the best three structures per family refined through2000 updates limits compute. A higher number of diagnostic candidates is disclosed rather than treated as a matched model-selection contest.

This stage is validation-only. It does not create or access new nonlinear target tasks. Any promising modification will require a separately frozen comparison before another target evaluation. Existing test results remain untouched, including all failures and negative results. Source models and original G34 code are not changed. No software tests are created or run; verification consists of minimal lint and the actual registered research calculations.

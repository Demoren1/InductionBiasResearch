# Следующий исследовательский шаг

Текущие96+90 структурных и24 transfer условия завершены; повторно запускать их не нужно. Основные бейзлайны G34/Pair сохраняются. Простой fixed-scale профильный контроль не заменяет их.

1. Проверить вывод на нескольких новых mixing-средах, а не на двух подмножествах одной старой среды. Для каждого r2/r5 оценивать отдельно шум source, шум target support и число support. Все случайные seed и grids фиксировать до новых результатов; бюджет по clean/source-heldout проверке без oracle.
2. Сравнить свободный I, ограниченную карту и мягкую зависимость кодов, сохраняя raw code coordinates. Для ReLU важен прямой контроль из coordinate_ablation: изменение Adam coordinates при той же функции само по себе ухудшало результат. Поэтому новый кандидат должен выражать гипотезу в целевой функции/штрафе либо явном выборе модели, а не только в замене координат.
3. Возможный кандидат — квадратичный prior по кодам с shrinkage к isotropic covariance и силой0 в сетке. Источник covariance оценивать с учётом within-function вариации нескольких хороших source fits; не считать каждый restart новой source-функцией. Выбор силы по отдельным source-задачам с соответствующим числом support. Пока это план, алгоритм не запущен и не подтверждён.
4. Для улучшения собственно извлечения I проверить регулярные графы совместного появления, зазор активных величин и неизвестные положительные масштабы. Не выдавать невозможность применить saturated recognizer к68 раздельным треугольникам MSR за отказ общей теории. Разделять abstention, exact recovery и малый projection bias.

Full MSR image suite остаётся в фоне. Текущий manager/PID и очередь — artifacts/msr_reproduction_2026-11-14; не останавливать живых workers или чужие Yambda задачи. Mini5shot D8 wider pilot ещё не завершён; выбрать layout только после обеих2000-step validation оценок, сохранить optimizer/RNG и продолжить до общего60000. Нельзя копировать pilot complete.json в основной fit. Mini1shot уже выбран и скопирован; повторно его не перетирать.

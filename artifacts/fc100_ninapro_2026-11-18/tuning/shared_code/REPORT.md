# Один общий код на FC100 и NinaPro DB2

При уже выбранных бюджетах aSRR проверили контроль из Omniglot:
один код разделяет все связи, кроме случайно выбранных исключений.
Каждое исключение получает отдельный код. На FC100 это 3071
исключение из 6144 связей, на NinaPro — 1023 из 1536. Число
исключений различается между нейронами максимум на одно. Для каждого
датасета построили четыре маски по фиксированным семенам без
использования исходных моделей. Отдельный контроль с одним кодом
задаёт равные веса у всех связей слоя.

На новых задачах все численные параметры обучали с нуля по прежнему
протоколу (200 шагов). Проверены те же 1024 эпизода FC100 и 240 эпизодов
NinaPro у 16 участников. Для aSRR и Dense использовали сохранённые
предсказания после проверки идентичности эпизодов и ответов.

| Метод | FC100, коды | FC100, точность (%) | NinaPro, коды | NinaPro, точность (%) |
|---|---:|---:|---:|---:|
| Dense | 6144 | 37,28 ± 0,52 | 1536 | 73,58 ± 3,03 |
| aSRR после подбора | 3072 | 37,47 ± 0,53 | 1024 | 73,66 ± 3,12 |
| Общий код и случайные исключения, среднее четырёх масок | 3072 | 36,34 ± 0,49 | 1024 | 73,37 ± 3,05 |
| Один код на весь слой | 1 | 26,99 ± 0,40 | 1 | 15,92 ± 2,06 |

Парный выигрыш aSRR над средним четырёх масок составляет **+1,13 п.п.**
на FC100 (95% ДИ от +0,86 до +1,40) и **+0,29 п.п.** на NinaPro
(от +0,03 до +0,54). Интервалы рассчитаны по эпизодам FC100 при
фиксированном наборе классов и по участникам NinaPro. Они относятся
к этим четырём маскам. Индивидуальные точности масок лежат от 36,26%
до 36,47% и от 73,28% до 73,45% соответственно.

На FC100 контроль с одним общим кодом и случайными исключениями
теряет точность при том же бюджете, при котором aSRR остаётся близок
к Dense. На NinaPro точность всех трёх вариантов близка. Сравнение с
этим контролем меняет и размеры групп, поэтому его следует читать
вместе с [контролем с перемешанными группами](../REPORT.md).

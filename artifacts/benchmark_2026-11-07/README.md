# Проверяемый комплект сравнения, 7 ноября 2026

Этот каталог содержит компактный экспорт завершённой серии. Точные
предсказания всех задач сохранены, как и ответы, использованные при
финальном аудите. Генерирующие кодбуки, истинные сдвиги и выходные матрицы
в экспорт не входят. Ответы и синтетические индексаторы в каталогах с
именем `private` предназначены только для аудита завершённых предсказаний.
Они были открыты после фиксации моделей и не использовались при их выборе.

## Пересчёт

Из корня репозитория, без GPU и обучения:

```bash
python -m experiments.paper_structure_benchmark_v1.reporting.evaluate \
  --base artifacts/benchmark_2026-11-07 --phase published-score
MPLCONFIGDIR=/tmp/ibr-mpl-cache \
  python -m experiments.paper_structure_benchmark_v1.reporting.render_report \
  --base artifacts/benchmark_2026-11-07 --paper paper
```

Проверка [publication_integrity.json](report/publication_integrity.json)
зафиксировала побайтовое совпадение с исходными CSV: 10 656 строк переноса,
60 строк структурного аудита и 42 бинарных результата.

## Что сохранено

- Все query-предсказания для всех support-бюджетов и методов.
- Query-ответы и синтетические reference I, необходимые для пересчёта метрик.
- Выбранные дискретные индексаторы и непрерывные базисы конкурентов.
- Индексы зафиксированных банков для проверки покрытия.
- Репрезентативные численные состояния и кривые, используемые в рисунках.
- Протоколы, выбор гиперпараметров, затраты, access receipts и регистрации.
- [Исходный манифест фиксации](report/frozen_results.json) и
  [описание экспорта с контрольными суммами](published_manifest.json).

Из численных состояний каждой модели оставлена первая задача: этого
достаточно для полного счёта параметров и представленных хитмап.
Предсказания при этом сохранены для **всех** задач. Численные состояния
не являются полным набором чекпойнтов для возобновления обучения.

Исходные изображения, полные support-наблюдения и невыбранные состояния
не включены. Полная серия остаётся локально в
`experiments/paper_structure_benchmark_v1/results/20261107/`.
Старые абсолютные пути в регистрациях сохранены как исторический протокол;
для аудита используется отдельный `published-score`, проверяющий экспорт.

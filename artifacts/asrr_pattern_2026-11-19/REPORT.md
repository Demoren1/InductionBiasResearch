# Восстановление индексатора Pattern методом aSRR

19 ноября 2026. Глобальный aSRR из алгоритма 1 не восстановил точный индексатор ни в одном из проверенных прогонов на обученных Dense-сетях. На исходном бинарном Pattern совпали группа и относительный знак у 14–15 из 32 активных связей. Контроль на точных весах выявил две причины ошибок — присвоение свободного кода отключённым связям и сопоставление разных окон при выравнивании скрытых нейронов.

## Постановка

В двоичной строке длины 11 ищем вхождение четырёхбитового шаблона. В эталоне каждый из восьми скрытых нейронов отвечает за одно окно. Первый слой имеет 88 позиций, из них 32 активны и 56 отключены.

- **Исходный бинарный Pattern.** Восстановили исходные 768 обучающих и 256 проверочных строк и список 12 шаблонов из протокола версии 4. На каждый шаблон и каждый из трёх наборов инициализаций обучили восемь Dense-сетей обычным Adam, 1024 шага, шаг обучения 0,03. Использовали исходный код одного плотного раунда до прореживания. Четыре запуска на шаблон отобрали по сбалансированной BCE на проверочных строках. Средняя точность этих сетей на тех же строках составила 95,27–95,48% в зависимости от инициализации. Эталон задаёт четыре кода для четырёх смещений фильтра.
- **Один бинарный шаблон 0110.** Выделили четыре отобранных Dense-запуска этой задачи из каждого набора инициализаций. Эталон задаёт два свободных кода, один для крайних позиций окна и один для средних. На одной задаче идеальные веса равны −1, +1, +1, −1. Их абсолютные значения допускают совпадение двух численных кодов.
- **Вещественный 0110.** Взяли сохранённую исходную Dense Adam-модель задачи 0 из каждой из трёх реплик архивного бенчмарка. Объединили три задачи в один банк для каждого уровня шума отклика. Для выбора опорной сети заново посчитали MSE именно этих весов на исходных 512 валидационных примерах. Параметры генератора в каждой реплике совпали по SHA-256 с исходным манифестом. Два кода в этой постановке меняются между задачами.

Во всех случаях использовали нормировку и венгерское выравнивание из `source_profiles`, затем глобальное дерево и четыре шага определения знаков из `signed_forest`. Бюджет равен числу свободных кодов эталона. Входная ветвь допускает бюджеты, кратные восьми. Эталонные группы и порядок окон использовались при оценке готовых индексаторов и в отдельно обозначенных контролях.

## Результаты на обученных моделях

Обычный aSRR присвоил код всем 88 позициям. Для диагностики взяли разрез того же дерева с одной дополнительной группой и закрепили её значение в нуле. Группу выбрали по наименьшему среднему квадрату нормы профиля, без информации о числе активных связей или размерах окна.

Ошибки индексатора подсчитаны при наилучшем допустимом переименовании кодов, обращении знака целой группы и перестановке скрытых нейронов. В столбце маски перестановка оптимизирует отдельно совпадение активных позиций. Полное восстановление требует правильных нулей, групп и относительных знаков во всех 88 позициях.

## Контроль на точных весах

Для 12 бинарных шаблонов подали аналитические фильтры. При известном соответствии нейронов окнам обычный aSRR правильно сгруппировал **32 из 32** активных связей. Разрез с нулевой группой восстановил **88 из 88** позиций. При штатном венгерском выравнивании и тех же точных весах разрез с нулевой группой дал **16–23 ошибки**. Проверены все 12 вариантов опорного шаблона, точных восстановлений 0 из 12.

У шаблонов `0000` и `1111` нормированные фильтры одного окна имеют скалярное произведение −1, двух непересекающихся окон — 0. Венгерский алгоритм максимизирует сумму этих произведений, поэтому такое сравнение предпочитает разные окна. В вещественном 0110 расположение и знаки фильтра сохраняются при смене задачи. На точных весах всех 16 задач каждой реплики штатное выравнивание и разрез с нулевой группой дали точный индексатор во всех трёх репликах.

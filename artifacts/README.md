# Артефакты

- [Опубликованный компактный комплект сравнения](benchmark_2026-11-07/README.md)
  позволяет пересчитать все итоговые метрики и рисунки без обучения.
- `g34_*_2026-11-08/` содержит дополнительные проверки: таблицы, рисунки,
  регистрации и архивы `audit_arrays.tar.gz` / `audit_records.tar.gz`.
  Предсказания, ранее открытые ответы для аудита и выбранные структуры
  сохранены с исходными байтами; состав и хеши — в
  [манифесте](../archive/2026-11-08/retained_audit_manifest.json).
- [Контроль одного запуска из якоря](anchor_start_2026-11-10/README.md)
  содержит финальные таблицы, хитмапы, выбранные структуры и точные
  предсказания для CPU-аудита.
- Прежний тяжёлый `local/` удалён при
  [очистке 8 ноября](../archive/2026-11-08/README.md).

Новые большие наборы данных, чекпойнты и полные состояния запусков
не следует добавлять в Git. Для публикации используется явный экспорт
`reporting.export_artifacts` с контрольными суммами.
Архивы `audit_*.tar.gz` дополнительных проверок G34 и
`anchor_start_2026-11-10/numerical_state.tar.gz` сохранены локально
на рабочем сервере и исключены из Git; в clone их нет. Сводки, рисунки
и манифесты доступны в репозитории. Основной benchmark и контроль
одного запуска имеют отдельные компактные комплекты для CPU-аудита.

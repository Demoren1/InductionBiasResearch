Архивы `scoring.npz` для текущей статьи содержат ответы и ровно те
предсказания, по которым считались метрики. `scoring_lineage.json`
сохраняет их контрольные суммы и происхождение. Архивы
`selected_indexators.npz` содержат выбранные дискретные группы;
полные непрерывные базисы и промежуточные состояния не публикуются.
Пересчёт всех метрик статьи — из корня репозитория:

```bash
python -m experiments.paper_compact_v1.evidence
```

Новые файлы под `artifacts/` по умолчанию игнорируются Git.
Итоговые отчёты, небольшие сводки, предсказания и выбранные структуры
публикуются отдельным, явно выбранным набором файлов. Датасеты,
чекпойнты и каталоги выполнения хранятся локально.
[Журнал очистки](../archive/2026-11-19/README.md) описывает, какие
временные файлы удалены. Пути в старых регистрациях относятся
к первоначальным прогонам и могут больше не существовать.

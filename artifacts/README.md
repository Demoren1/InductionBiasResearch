# Артефакты

- [Опубликованный компактный комплект сравнения](benchmark_2026-11-07/README.md)
  позволяет пересчитать все итоговые метрики и рисунки без обучения.
- `local/` исключён из Git: здесь находятся сжатые исходные журналы
  прежних серий. Их состав указан в манифесте очистки.

Новые большие наборы данных, чекпойнты и полные состояния запусков
не следует добавлять в Git. Для публикации используется явный экспорт
`reporting.export_artifacts` с контрольными суммами.

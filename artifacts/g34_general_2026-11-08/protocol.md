# G34: расширение на общую синтетику

8 ноября 2026. Дополнение к завершённой проверке Pattern/DeepSets по запросу
пользователя. Результаты прежней проверки уже известны; алгоритм, квоты,
пороги, source selector и target adapter сохраняются без изменений.

## Семейства и данные

Три варианта прежнего general-стенда: local, quartet_mix, random. По две
репликации каждого варианта, D=H=16, четыре независимых кода первого слоя.
Первая репликация имеет один выход и общий внутри задачи hidden bias,
вторая — два выхода и независимые hidden biases. Свободные выходные веса
генерируются независимо для каждого нейрона и задачи в обоих случаях.
Это стратифицированные условия, не две одинаково распределённые репликации.

Local повторяет блоки 2×2 с четырьмя кодами; quartet_mix связывает четвёрки
двухмерных точек с противоположными знаками диагональных блоков; random
имеет независимую вероятность связи 0.55, случайные коды и знаки.
Входы и hidden-нейроны переставляются. Teacher-описание нужно для
воспроизводимости генератора; learner не получает вариант и роли координат.

Свежий seed 27110864019, прежде не использовавшиеся наблюдения и численные
параметры. На семейство 16 source-задач: train4096, numerical selection512,
structure selection1024, sealed query2048. Source noise 0 и 0.2, по одному
ответу на пример; шум не сообщается learner. Train/selection Gaussian
с масштабами 0.5/1/2/4, structure selection/query — стандартный Gaussian.

На семейство восемь свежих target-функций с тем же I, новыми кодами,
сдвигами и свободными головами; один target-набор для двух source noise.
Support64/256/1024, numerical selection16/64/256, query2048. Target-ответы
чистые. True I, teacher-числа и query-ответы не входят в построение,
подгонку и выбор модели. Генератор отдельно сохраняет их хеши.

## Замороженный метод и сравнение

Сравниваются исходный G34, diversity и theory из предыдущей регистрации
27110854013, плюс Dense на targets. Нового development/tuning нет.
Контрольные суммы bank.py и variant.py должны совпасть с прежней
регистрацией ещё до генерации новых данных. Исходное ядро G34 сохраняется.

Dense source:12 Adam starts/2500steps,4 GN starts/32steps,2 revival rounds.
Source bank:32 новых refit,4starts/48GNsteps и общие anchors.
Theory quotas:8 original,12 relations,8 log_positive,4 signs с прежним
правилом заполнения недостающих ветвей. Source meta выбирает I.
Target adapter:18 Adam starts/2000steps,4 GN starts/48steps.
Переносится только I, все числа на targets инициализируются заново.

Primary endpoint — парная clean target MSE1024 после Adam+GN отдельно
для каждого варианта и source noise. Дополнительно показываются N64/256,
NMSE, exact I, ошибки маски/шэринга, наличие истины в pool/refit,
train/selection кривые по шагам и стоимость. Оба страта каждого варианта
показываются отдельно. Нельзя считать восемь target-функций независимыми
подтверждениями извлечения структуры или переносить вывод на любые графы.
Исторические 6/6 clean и 2/6 noisy G34 — другой набор и не baseline
этого сравнения.

## Выполнение и аудит

GPU0–5, один внешний процесс на GPU;6/7 не используются. Одновременно
работает один fleet. Software tests не создаются и не запускаются.
Стоимость proposals и source/search учитывается, равен только лимит refit.
Torch FLOPs не включают NumPy/SciPy и неподдержанные операции.

Сначала фиксируются все source-решения и все 42 target prediction-файла,
контрольные суммы кода и access receipts. Только затем scorer открывает
истинные I и query-ответы. По результатам этого расширения алгоритм не
меняется. Сохраняются отдельный MD-отчёт и компактные таблицы/рисунки;
исходный отчёт Pattern/DeepSets и его артефакты не заменяются.

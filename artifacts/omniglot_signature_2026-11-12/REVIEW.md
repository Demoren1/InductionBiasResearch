# Взвешенные сигнатуры на Omniglot: результат и оценка

Проверен именно первый кандидат по геометрическому критерию для каждого
размера кодбука. Функциональный выбор между сигнатурными структурами не
использовался. Отложенные задачи выбирали размер кодбука и единое правило
обучения новых численных параметров.

Постановка: полносвязная ReLU-сеть 784–16–5, изображения 28×28,
5-way 5-shot, 128 исходных и 128 отложенных задач, 1000 новых итоговых
эпизодов по 75 запросов. Сохранена прежняя аугментация только запросов.
Это отдельный повторный прогон: исходные наблюдения воспроизвели прежние
SHA-256, плотные модели и G34 обучены заново, итоговые эпизоды новые на
прежнем разделении классов. Исторические числа из статьи относятся к
предыдущему прогону.

## Сравнение

| Метод | Точность, 95% интервал | Cross-entropy | Численных параметров на задачу |
|---|---:|---:|---:|
| G34, повторный прогон | 41,02% [40,44; 41,59] | 1,4288 | 165 |
| Dense | 37,07% [36,57; 37,58] | 1,5302 | 12 645 |
| Взвешенная SVD, первый геометрический кандидат; 16 групп | 34,62% [34,10; 35,15] | 1,5040 | 117 |
| Тот же метод, фиксированные 8 групп — дополнительная диагностика | 31,18% [30,52; 31,84] | 1,5366 | 109 |
| Перемешанная выбранная структура, 16 групп | 23,88% [23,52; 24,24] | 1,5993 | 117 |

Число параметров включает кодбук, сдвиги скрытых нейронов, выходные веса
и выходные сдвиги. Для каждого итогового эпизода они инициализировались
заново и обучались только по его support. Исходные численные значения
не переносились.

Основной сигнатурный вариант уступил G34 по точности на **6,39 процентного
пункта**, парный 95% интервал [−7,06; −5,72]. Относительно Dense разница
составила −2,45 пункта [−3,10; −1,80]. При этом его cross-entropy лучше,
чем у Dense, и хуже, чем у G34.

Выбранная структура лучше перемешанного контроля на **10,74 пункта**
[10,16; 11,33]. Перемешивание сохраняло число кодов, общую плотность,
частоты кодов и знаков; каждому методу подбиралось собственное правило
численной адаптации на development. Этот контроль показывает пользу всей
извлечённой схемы; отдельные вклады маски, знаков и привязки кодов здесь
не разделялись.

Интервалы характеризуют вариацию итоговых эпизодов при одной исходной
когорте и одном обучении структуры.

## Что именно нашёл сигнатурный алгоритм

Все **512 комбинаций** маски и ранга завершены. До удаления дубликатов
получены семь полных разбиений; после удаления дубликатов — один кандидат
для 8 групп и пять для 16. Для 32 и 64 групп кандидатов нет. Принудительного
доведения числа компонент до нужного значения не было.

Оба первых геометрических кандидата используют одну маску из 475 связей,
полученную по трём голосам относительно исходного якоря 60.

- **16 групп, ранг 0.** В каждом нейроне ровно одна unsigned-группа;
  каждая группа встречается только в одном нейроне. Получились маски и
  знаковые шаблоны с отдельным кодом для каждого нейрона. Общего численного
  шэринга между разными нейронами этот кандидат не содержит.
- **8 групп, ранг 7.** Одна группа содержит **468 из 475 связей** и
  встречается во всех 16 нейронах. Остальные семь групп — одиночные связи.
  Это почти полное слияние, а не убедительное выделение нескольких
  устойчивых общих классов связей.

Основной выбор development — вариант с 16 группами: cross-entropy 1,5257
против 1,5434 для 8 групп. Для него выбраны 100 Adam-обновлений с LR 0,003;
для 8 групп заранее были выбраны 50 обновлений с LR 0,01.

## Применимость теоретической гарантии

Для кандидата с 8 группами проверена внутренняя согласованность с оценённым
пространством контрастов. Расстояние между соответствующими ортогональными
проекторами равно **0,99905**; достаточная граница устойчивости для этой
гипотетической структуры равнялась бы **0,00578**. Первые семь компонент
содержат 57,62% взвешенной спектральной энергии исходных наблюдений.

Граф повторяющихся пар для большой группы имеет **16 компонент**.
Достаточное условие его связности из теоремы не выполнено. Следовательно,
теорема не даёт гарантии восстановления этого кандидата на этих данных.
Диагностика характеризует согласованность найденной структуры; истинная
нейронная группировка для Omniglot не задана.

## Мой отзыв

В этой постановке я бы оставил G34 основным методом. Сигнатурная ветка
передаёт полезную информацию о структуре и использует мало численных
параметров, но по точности уступает и G34, и Dense. Отдельная проверка
кандидата ненулевого ранга этот вывод не улучшила.

Результат также показывает ограничение перехода от условной теоремы к
обученным плотным классификаторам: одного совпадения числа групп и ранга
недостаточно. Полученные разбиения вырождаются, а для кандидата ненулевого
ранга не выполняются условия теоретической гарантии. Подтверждения
надёжного восстановления общей группировки на Omniglot здесь нет.

Точный поиск пар на полном слое оказался вычислительно тяжёлым. Добавлены
потоковый CPU/GPU-поиск и строгие ранние отбрасывания по компонентам и рангу;
вычислительные поправки сохраняли прежние правила объединения и критерий
выбора. В одной контрольной конфигурации буквальная реализация двух правил
и потоковая версия дали одинаковые восемь групп при 4 784 166 совпадениях
пар сигнатур.

# Theory-guided diagnosis of extracting an index from dense weights

G34 and Pair remain the primary baselines. This study tests whether noisy or underdetermined source weights explain extraction errors. It is a structural audit, not another transfer leaderboard. It does not presume that adding continuous code relationships improves the practical method.

The existing MSR rank1/2/5 source functions are reused, with two precommitted subsets of32 functions each. Within each subset the same functions and nested inputs are used for20/80/200 examples per function. Minimum-norm dense OLS supplies observed weights. Source noise is either additive weight measurement noise after OLS or additive observation noise before OLS, at0/.03/.1 relative RMS. Clean cases are deduplicated between noise modes. Gaussian perturbations have no deterministic finite bound. Known injected noise scales provide only diagnostic measurement standard deviations, not an assertion about confidence calibration in real dense training. At n20 interpolation has an unbounded unidentified component, so sign gating based only on measurement variance is disabled.

G34 projection and ScalarPairs proposal code are reused. Both try the same data-derived energy masks, two initial anchors and budgets3/6/15/30/70/204, with identity-on-retained-mask and full-N endpoints. Source weight reconstruction selects the mask/initialization separately at each reported budget; no true grouping or target error selects it. This structural selection differs from the earlier functional-bank benchmark and is explicitly labelled. G34 runs40 assignment steps with its existing uncertainty0.1. Pair uses the existing threshold grid and local brackets without quantile fallbacks.

The theoretical observation model removes positive neuron scales only when these correspond to a valid representation ambiguity. In the observed-output linear MSR layer they need not be removed. A new signed-profile clustering control therefore fits common codes across all32 functions with fixed output scales, allowing a global scale per function. It uses two initializations and40 Lloyd steps. It is a control for this linear setting, not a general replacement for ReLU extraction. Six auxiliary cases apply unknown positive output-direction gauges with log scale standard deviation1 to the observed descriptors; these diagnose the limitation of the fixed-scale control without calling the gauges a symmetry of the visible linear outputs.

A second, theoretical necessary-condition gate rejects candidate groups with contradictory normalized signs on reliable measurements. Reliability uses6 measurement standard deviations; this is an exploratory rule, not a formal Gaussian-uniform certificate. No structural information from the teacher determines proposals or gates. The complete budget bank and source choices are saved before the teacher file is opened.

After freezing, audit records mask false positives/negatives, false signed merges, missed true sharing pairs, exact grouping up to signed code permutation, dense relative weight error, and projection bias of the generated function family onto each index. True rank1 has3 active equality groups; ranks2/5 have204 singleton groups, despite6/15 underlying continuous coefficients. Their code co-occurrence graph has68 components, so the article's 3-connected uniqueness theorem does not directly apply. Report both recovery and representation bias; neither implies fresh target adaptation quality. The headline structural figure may use the true-budget slice as an explicitly labelled oracle diagnostic; the full budget scan must remain available and must not be described as blind budget selection.

No target-transfer hyperparameters or target predictions are selected in this stage. Any promising extraction modification needs a separate frozen transfer study, including one versus several support observations and oracle-index controls. The current manuscript and original method implementations are left untouched. No software tests are created or run; use minimal lint and actual research execution. Resource use is additive to the running image experiments and avoids the busiest memory-constrained cards initially.

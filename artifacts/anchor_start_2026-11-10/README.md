# Один запуск проекции из каждого якоря

[Итоговый отчёт](REPORT.md) сравнивает полный G34 с двумя упрощениями
на Pattern 0110, синтетическом DeepSets и общей синтетике.
Точное восстановление индексатора: 15/24 у полного поиска, 11/24 у обоих
упрощений. Чистые и шумные source-условия в этих числах объединены.

## Компактный комплект в Git

- `recovery.csv`, `transfer_per_task.csv`, `paired_comparison.csv` — результаты.
- `selected_structures.npz` — выбранные индексаторы и параметры, выравнивание
  для оценки и истинные индексаторы, открытые после фиксации решений.
- `scoring_answers.npz`, `predictions/`, `case_sizes.json` — ответы,
  точные предсказания и размеры моделей для независимого CPU-аудита.
- `PROTOCOL.md`, регистрации, amendments и `records/` — протокол и отбор.
- `bank_diagnostics.*` — разбор ошибок по сохранённым банкам после завершения.
- `*_heatmaps.png` — все исследованные условия.
- `code_snapshot/`, `code_versions/`, `analysis_code/` — исходники на этапах
  регистрации и исполнения. Они сохранены как происхождение результатов.

`published_manifest.json` содержит SHA-256 файлов этого компактного
комплекта. `prediction_manifest.json` связывает экспортированные предсказания
с исходными путями и хешами из `frozen.json`.

## Пересчёт без обучения

Из корня репозитория, с зависимостями `requirements-reporting.txt`:

```bash
python -m archive.experiments.anchor_start_ablation_v1.audit \
  --base artifacts/anchor_start_2026-11-10 \
  --output /tmp/ibr-anchor-start-audit
```

Команда сверяет манифест, заново вычисляет точность индексаторов, масок
и target MSE, сопоставляет их с отчётом и сохраняет таблицы в новый каталог.
GPU и исходные обучающие выборки не требуются.

## Локальные численные состояния

`numerical_state.tar.gz` (82.36 МиБ) сохранён в этом же каталоге на рабочем
сервере и исключён из Git. Состав и хеши — в
`numerical_state_manifest.json`. Он содержит source-модели, исходный банк,
результаты численного refit и target-кривые для следующих исследований.
В clone этого архива нет; для полного повторного обучения нужно заново
подготовить данные по протоколу. Опубликованные метрики пересчитываются
из компактного комплекта выше.

Сырые данные и большие покадровые JSON-истории удалены после сохранения
результатов. Промежуточные отчёты Pattern и DeepSets объединены с финальным;
их фиксация сохранена в `interim_*_amendment.json`.
Журнал организации репозитория — [archive/2026-11-10](../../archive/2026-11-10/README.md).

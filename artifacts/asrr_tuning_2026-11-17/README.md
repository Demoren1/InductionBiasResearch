# Broad aSRR tuning, 17 November 2026

This is a historical study. [REPORT.md](REPORT.md) describes the search
and its numerical costs. [tuned_results.json](tuned_results.json) contains
the published summaries and paired differences. The frozen choices
precede both evaluation cohorts.

The search used the stated class and subject pools. Its primary policy
maximized development accuracy, with a separate cross-entropy policy.
The results compare the declared candidates, rather than solving a global
or equal-compute optimization problem.

The original raw panels, full selection traces and transient fits are
outside this release. Use the [current manuscript audit](../../README.md#воспроизведение-опубликованных-метрик)
for the current paper. The old report generator targets earlier tables.
